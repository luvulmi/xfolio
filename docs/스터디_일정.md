# XFolio 스터디 주차별 일정

- 2026-10-21 적용 상태: 아래 스터디 공통 일정에 맞춰 이 저장소는 5~6주차 주당 15시간·총 30시간 기준으로 아침 브리핑·추가 뉴스와 최소 관리자 사이트를 연결한다. 개발·테스트에는 관리자 승인을 적용하고 안정화 후 자동 검증·게시로 전환한다. 상세 동작은 [운영 정책](운영_정책.md)을 따른다. 뉴스 제공처는 1곳으로 시작하고 부분 게시 실패는 CLI로 확인 후 수동 복구한다. 상세 작업 배치는 [설계서](요구사항.md), 이전 결정 이력은 [재설계 세션](../tasks/discussions/2026-10-15_시장_브리핑_재설계.md)을 따른다.

## 1주차 · 10/3 ~ 10/11

**해야 할 일:** 나만의 Codex 개발 환경 세팅

**발표할 내용:** 각자 Codex 환경을 어떻게 설정했는지 설명합니다.

- `AGENTS.md`에 적은 내용
- 만든 룰 파일과 적용한 규칙

## 2주차 · 10/12 ~ 10/18

**해야 할 일:** 무엇을 만들지 요구사항 문서로 정의합니다.

**발표할 내용:** 작성한 문서를 보여주며 다음 내용을 설명합니다.

- 만들 기능과 범위
- 내 XFolio 에이전트의 예상 모습
- 기술적인 내용 보다는 다이어그램 형식

## 3주차 · 10/19 ~ 10/25

**해야 할 일:** 구현에 필요한 기능과 라이브러리 등을 사전 조사합니다.

**발표할 내용:** 조사한 기술과 선택 후보를 설명합니다.

- 주식 정보를 가져올 수 있는 API
- 뉴스 수집 또는 크롤링에 사용할 수 있는 API 등

❶ 구현에 사용할 기술 스택 소개
    - 기획한 내용과 함께 어느 부분에 어떤 기술을 사용할건지 설명 (예를 들어, 에이전트 개발에는 파이썬을 쓸거고 DB는 AWS PostgreSQL RDS를 쓸 것이다 등)
   - 특히 OpenAI에서 제공하는 SDK나 API를 어떻게 활용할지 고민해볼것

❷ 비용 관점 조사
    - 내가 생각하는 예산대와 예상 월 비용 내역 비교
    - 유료 기능 사용에 대한 대략적인 비용 계산해보기 (전부 무료 기능만 사용하실 경우엔 안 하셔도 됩니당)

## 4주차 · 10/26 ~ 11/1

**해야 할 일:** 구현 방식과 기술 스택을 확정하고, 이후 2주간 개발할 내용과 예상 일정을 구체화합니다.

**발표할 내용:** 자신의 개발 계획을 설명합니다.

- 구현 방식과 사용할 기술 스택
- 5~6주차에 수행할 작업과 간략한 일정
- 예: 5주차에 파이프라인 2개 구현

## 5주차 · 11/2 ~ 11/8

**해야 할 일:** 계획에 따라 개발합니다.

이 저장소의 확정 개발 범위: 두 지수·뉴스 제공처 1곳의 수집부터 AI 생성·검증·관리자 사이트의 아침 호 미리보기·승인과 게시 결과 기록까지 연결합니다. 기능 테스트도 함께 작성합니다.

**발표할 내용:** 구현한 내용과 현재 진행 상황을 설명합니다.

## 6주차 · 11/9 ~ 11/15

**해야 할 일:** 개발을 이어갑니다.

이 저장소의 확정 개발 범위: 추가 뉴스·예약 실행·일일 한도·중복 방지와 관리자 사이트의 상태 조회를 연결하고 두 발행 흐름의 기본 시험을 마칩니다. 6주차 연결 완료와 8주차 프로젝트 완료는 구분합니다.

**발표할 내용:** 구현한 내용과 현재 진행 상황을 설명합니다.

## 7주차 · 11/16 ~ 11/22

**해야 할 일:** 오류가 없는지 확인하고 의도한 방식으로 동작하는지 테스트합니다.

이 저장소는 최소 5개 미국 거래일의 예약 시험과 누락·중복·부분 게시, 관리자 승인 전 게시 차단을 검증합니다.

**발표할 내용:** 발견한 오류와 해결 방법을 공유합니다.

## 8주차 · 11/23 ~ 11/29

**해야 할 일:** 관리자 사이트와 전체 흐름을 마무리합니다. 테스트가 끝나지 않았다면 함께 완료합니다. 이 저장소는 5~6주차에 준비한 공통 기록으로 게시 결과를 조회하고 운영 절차·README·시연을 정리합니다.

**발표할 내용:** 한 주 동안 진행한 작업과 현재 상태를 설명하고 최종 결과를 발표합니다.
