# XFolio 스터디 주차별 일정

- 2026-10-21 적용 상태: 아래 스터디 공통 일정에 맞춰 이 저장소는 5~6주차 주당 15시간·총 30시간 기준으로 아침 브리핑·추가 뉴스와 최소 관리자 사이트를 연결한다. 개발·테스트에는 관리자 승인을 적용하고 안정화 후 자동 검증·게시로 전환한다. 상세 동작은 [운영 정책](운영_정책.md)을 따른다. 뉴스 제공처는 1곳으로 시작하고 부분 게시 실패는 CLI로 확인 후 수동 복구한다. 상세 작업 배치는 [설계서](요구사항.md), 이전 결정 이력은 [재설계 세션](../tasks/discussions/2026-10-15_시장_브리핑_재설계.md)을 따른다.
- 2026-10-28 범위 확정: React·TypeScript·FastAPI·PostgreSQL·Docker/AWS, 아침과 **18시 추가 뉴스 최대 2건**, 중요 장애의 Telegram을 **2주 reviewed MVP**로 연결한다. 날짜·30시간은 유지하고 [세부 일정](../tasks/plans/개발_일정.md)과 [우선순위](../tasks/plans/개발_우선순위.md)를 따른다. auto 활성화는 5거래일·장애 시험 후다.

## 1주차 · 10/3 ~ 10/11

**해야 할 일:** 나만의 Codex 개발 환경 세팅

**발표할 내용:** 각자 Codex 환경을 어떻게 설정했는지 설명합니다.

- `AGENTS.md`에 적은 내용
- 만든 룰 파일과 적용한 규칙

## 2주차 · 10/12 ~ 10/18

**해야 할 일:** 무엇을 만들지 요구사항 문서로 정의합니다.

**발표할 내용:** 작성한 문서를 보여주며 다음 내용을 설명합니다.

- 만들 기능과 범위
- 내 XFolio 에이전트의 예상 모습
- 기술적인 내용 보다는 다이어그램 형식

## 3주차 · 10/19 ~ 10/25

**해야 할 일:** 구현에 필요한 기능과 라이브러리 등을 사전 조사합니다.

**발표할 내용:** 조사한 기술과 선택 후보를 설명합니다.

- 주식 정보를 가져올 수 있는 API
- 뉴스 수집 또는 크롤링에 사용할 수 있는 API 등

❶ 구현에 사용할 기술 스택 소개
    - 기획한 내용과 함께 어느 부분에 어떤 기술을 사용할건지 설명 (예를 들어, 에이전트 개발에는 파이썬을 쓸거고 DB는 AWS PostgreSQL RDS를 쓸 것이다 등)
   - 특히 OpenAI에서 제공하는 SDK나 API를 어떻게 활용할지 고민해볼것

❷ 비용 관점 조사
    - 내가 생각하는 예산대와 예상 월 비용 내역 비교
    - 유료 기능 사용에 대한 대략적인 비용 계산해보기 (전부 무료 기능만 사용하실 경우엔 안 하셔도 됩니당)

## 4주차 · 10/26 ~ 11/1

**해야 할 일:** 구현 방식과 기술 스택을 확정하고, 이후 2주간 개발할 내용과 예상 일정을 구체화합니다.

**발표할 내용 · 2026-10-28 사용자 정정 기준:**

1. 확정한 기획의 큰 그림·구체적 개발 내용과 이전 미결정 항목의 결정 결과. 미해결 조건은 확정 사항과 구분합니다.
2. 각 주차의 작업·산출물·완료 조건. 5~6주차는 주당 15시간·총 30시간 안에서 실제 작업할 수 있게 배분합니다.
3. 현재 구현·검증 결과, 차주 계획과 시행착오. 가상 시험·실제 조회·제품 배포·게시 완료를 구분합니다.

**다음 주까지 준비:** GitHub 계정·XFolio repository, X 계정·개발자 콘솔·게시용 인증, OpenAI·Marketaux 등 필요한 서비스 계정·키. 현재 준비 상태와 완료 조건은 [개발 우선순위](../tasks/plans/개발_우선순위.md)를 따릅니다. 비밀 값은 문서·Git에 남기지 않습니다.
