# XFolio 스터디 주차별 일정

- 기준: 2026-11-03, Asia/Seoul. 기본 개발 목표는08시 아침1회이며14/16시는 선택·기본 꺼짐이다.
- 발표는 해당 주차 마지막 일요일이다. 5~8주차는11/8·11/15·11/22·11/29이며 변경하지 않는다.
- Finnhub 일반 뉴스 제목/링크·BLS/BEA/연준 자체 발표 요약, Lightsail + Tailscale 비공개 관리자를 기준으로 한다. Exa는 초기 필수 경로에서 제외한다.
- 사용자 요청에 따라11/3 착수·11/29 전체 완료를 목표로 **평일 하루5h**로 늘렸다. 5주차 잔여20h·6~8주차 각25h, 총95h를 배정한다. 기존 하루3h·주15h·12월 종료 일정은 대체한다.
- 기존 개발/검증82h에 추가 지연 대응7h·최종 발표/인계 준비6h를 포함한다. 작업별 날짜와 선행 관계는 [WBS](planning/작업_분해_WBS.md)가 기준이다.
- 11/13 관리자/편성,11/20 아침 수신/배포,11/24 오후 기능 인수·기능 동결,11/25 기존82h 범위,11/27 최종 준비 완료를 목표로 한다. 11/28은 필요 시 보충하고11/29 최종 발표한다.
