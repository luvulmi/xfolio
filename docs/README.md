# 프로젝트 문서

현재 목표는 **국내 상장 해외 ETF(기본3·활성총10) + 일반 뉴스 링크·미국 공식 발표 요약 합계최대3건 → 본인 Telegram 자동 전송**이다. 월~금08:00 아침1회를 기본으로 개발하고 한국 거래일14:00·16:00은 모두 선택·기본 꺼짐으로 둔다. KIS는11/3 실전 인증·기본3종목×2일 비수정 종가/주말 휴장을 확인했고 본인 AWS/관리자·본인1명 Telegram·가격90일 보관을 사용자 결정으로 허용해 T01을 완료했다. [T01 완료·T02 계약](../tasks/verification/market/국내_ETF_API_표본_검증.md).

일반 뉴스는 Finnhub Free `general`을 본인 개인용으로 채택한다. 개인 이용 기준을 적용하고 이메일 회신은 필수 조건에서 제외한다. 제목/중복/경유 실패 제외는 시험했으며 운영 기술 검증은 후속이다. 공식 발표는 직접 수집하고 Exa는 초기 필수 경로에서 제외한다. [현재 선정 근거](research/데이터_이용_조건.md).

## 개발·발표 문서 읽는 순서

요구사항 → 운영 정책 → WBS → 관리자 화면 → 기술 구성 순으로 읽는다. API·ERD·시퀀스는 이전 구현 계약으로 표시되어 있으며 T02/T05/T06에서 새 상세 계약으로 개정한다.

T02 국내 시세/거래일·종목/가격90일 DB의 구현·격리 PostgreSQL 시험은 [검증 계약](../tasks/verification/market/국내_시세_어댑터와_종목_DB.md)을 따른다. 관리자/worker/운영 인수는 후속이다.
