# 프로젝트 문서

프로젝트의 현재 기준과 조사 근거를 관리한다. 구현·검증의 수행 내용은 [작업 문서](../tasks/README.md)에 기록한다.

**10/30 현재:** 세 지수와 Fed/BLS/BEA·SEC 주요 기업 10개(20개 확장)를 대상으로 실적·M&A·정책·주요 경제지표를 요약한다. 5~6주차 30시간은 중간 목표다. 7주차 추가 개발·통합 검증, 8주차 초 기능 마무리와 이후 최종 인수를 계획한다. 전체 기준 79시간과 가용 60시간 가정의 차이는 [개발 범위·단계](planning/개발_범위와_단계.md)와 [WBS](planning/작업_분해_WBS.md)를 따른다.

상세 기획: [뉴스 선정 사례](../tasks/verification/news/뉴스_선정_고정_사례.md) · [관리자 화면·승인 API 예시](../tasks/verification/admin/관리자_화면과_승인_API.md). 편성 전체 승인·CLI 수정·저녁 동결 규칙은 요구사항/운영 정책을 기준으로 한다.

문서 파일명은 한글, 폴더명은 영어 `snake_case`를 사용한다. 제품 명세/화면 설계는 `specifications/`, 사용자가 요청한 범위/WBS는 `planning/`, 조사 자료는 `research/`, 이전 이력은 `archive/`에 둔다. 시험 계약·실행 근거는 계속 tasks에 둔다.
