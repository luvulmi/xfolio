# XFolio 스터디 및 개발 개요

## 프로젝트 목표

**XFolio(엑스폴리오)**는 X(구 트위터)와 Portfolio를 합친 이름입니다. 각 크루원이 OpenAI API와 Codex를 활용해 **현재의 주요 주식시장 정보를 수집·분석하고, 읽기 쉬운 콘텐츠를 정해진 시간에 X에 자동 게시하는 AI 에이전트**를 만듭니다.

시장 데이터 수집 + 시장 뉴스 수집 → AI 분석 및 콘텐츠 생성 → 예약 실행 및 X 게시

스터디의 핵심은 주식 지식 자체보다 **기획 → 설계 → 데이터 수집 → AI 분석 → 콘텐츠 생성 → 자동화 → 테스트 → 배포**를 직접 경험하는 것입니다. 이 경험을 업무 자동화, 데이터 분석, 콘텐츠 자동화 등 다른 분야에도 응용하는 것을 목표로 합니다.

## 스터디 방식과 최종 결과물

- **개인별 구현:** 6명이 하나의 서비스를 분담하지 않습니다. 각자 하나씩, 총 6개의 XFolio 에이전트를 만듭니다.
- **공통 흐름, 자유로운 구현:** 전체 작업 단계는 함께 따라가되 언어, 기술 스택, 세부 기능과 자동화 방식은 각자가 선택합니다. 개발이 익숙하지 않은 크루원은 기획·설계 단계부터 리더와 다른 크루원의 도움을 받을 수 있습니다.
- **함께 해결:** 매주 정기 온라인 미팅에서 진행 상황, 선택한 기술과 구조, 막힌 점과 시도한 해결 방법을 공유합니다.
- **최종 결과물:** 개인 XFolio 에이전트, GitHub 레포지토리, 실제 동작 시연, 프로젝트 발표 자료.

## 기능 범위와 데이터 흐름

OT에서 **Market Pipeline, News Pipeline, Upload Pipeline**의 세 가지 파이프라인이 필요하다고 정했습니다. 아래 역할과 입출력은 개발을 시작하기 위한 **설계 초안**입니다. 데이터 소스와 파이프라인의 정확한 경계는 각자 설계할 때 확정합니다.

| 구성 | 맡을 일 | 입력 예시 | 출력 예시 |
| --- | --- | --- | --- |
| Market Pipeline | 현재의 주요 주가지수·경제지표 등 시장 데이터 수집 및 정리 | 기준일, 선택한 데이터 소스 | 출처와 기준 시점이 포함된 시장 데이터 |
| News Pipeline | 금융·시장 뉴스 수집 및 정리 | 기준일, 선택한 뉴스 소스·주제 | 출처와 발행 시점이 포함된 뉴스 목록 |
| AI 분석·콘텐츠 생성 | 수집 결과에서 주요 이슈를 골라 읽기 쉬운 요약 생성 | 시장 데이터, 뉴스 목록, 작성 지침 | 게시 후보 글 |
| Upload Pipeline | 생성한 글을 정해진 시간에 X에 게시 | 게시 후보 글, 게시 일정, X 연결 정보 | 게시 결과 또는 실패 기록 |

**News Pipeline의 범위와 복잡도로 프로젝트 난이도를 조정할 수 있습니다.** 수집 대상과 뉴스 선별 방식은 개인별로 정하고, 선택한 기준을 기록합니다. 구현 과정에서 OpenAI API, 외부 데이터 API, X 연동, 프롬프트 설계, 스케줄링, 배포·운영을 다룹니다.

## 개발 전에 결정할 사항

### 이 저장소의 현재 구현 방향 (2026-10-15 재설계 중)

상태: 핵심 방향·첫 경제지표 범위·독자 범위 합의, 제공처·게시 형식·운영값은 논의 중. 최신 기록은 [미국 시장 브리핑 재설계 세션](../tasks/brain_storm/session_2026-10-15_market_briefing_redesign.md)에 있다.

이 저장소의 개인별 구현은 **S&P500·나스닥100 관련 주가지수·경제지표·뉴스를 수집·정리해 콘텐츠를 생성하고 X에 게시하는 시장 브리핑 에이전트**다. 첫 버전은 미국 두 지수의 마감 결과와 관련 뉴스에 경제지표를 함께 제공한다. 2026-10-15 사용자 결정으로 독자를 **ISA 투자자를 포함해 S&P500·나스닥100에 관심 있는 한국어 개인 투자자**로 확대했다. 첫 경제지표 범위는 **CPI·고용보고서·FOMC 금리 결정**으로 확정했다. 지표별 세부 항목과 게시 형식은 후속 설계에서 정한다. [2주차 발표 초안](../tasks/progress/2026-10-18.md)에 예상 모습을 정리한다.

국내 TIGER·KODEX 4개 ETF의 개별 장중·종가 게시는 후속 단계로 둔다. 이전의 국내 ETF·KOSPI·KOSDAQ 중심 편성은 [이전 설계](isa_etf_publishing_design.md)와 [2주차 결정 이력](../tasks/brain_storm/session_2026-10-12_week2_requirements.md)에 보관한다. 무료 제공처를 우선 조사하며, 수집 가능성과 공개 X 게시 허용 여부를 구분한다. 두 지수의 무료 조회 경로는 확인했으나 정기 공개 게시가 허용된 무료 제공처는 아직 확보하지 못했다. 근거는 [미국 지수 데이터 조사](research/us_index_data_research.md)에 기록한다.

시장·뉴스 수집 → AI 분석·생성 → 예약 X 게시 → 테스트·배포의 전체 흐름 완성을 우선한다. 11/2~11/15의 2주 개발 기간에는 관찰 범위를 좁혀 진행한다. 포괄적인 ETF 추천, 댓글·DM 응답, 계좌 연결, 개인화, 자동 매매와 정기 교육·비교 콘텐츠는 첫 구현 범위에 포함하지 않는다. 아래 OT 목록은 스터디 공통의 **원래 미결정 항목**이며, 이 저장소에서 이미 확정한 독자·대상·게시 형식을 다시 미결정으로 돌리지 않는다.

다음 항목의 구체적인 값과 방식은 OT에서 확정되지 않았습니다. 각자 결정한 내용을 자신의 레포지토리에 기록합니다.

- **대상 시장과 기준 시점:** 어떤 시장을 다룰지, 시장 정보와 뉴스의 기준 시점·시간대를 어떻게 정할지
- **데이터 소스:** 지수·경제지표·뉴스 제공처, 수집 범위, 이용 조건, 출처 표기 방법
- **뉴스 처리 범위:** 수집량, 중복 제거, 관련성 판단, 기사 선정 기준
- **콘텐츠 형식:** 대상 독자, 글의 길이와 문체, 숫자·출처 표기, 게시물 분할 여부
- **자동화 방식:** 실행 시각과 시간대, X 게시 방법, 인증 정보 관리, 배포 환경
- **실패 처리:** 데이터 누락, API 오류, 중복 게시, 게시 실패 시 기록 및 재시도 기준
- **검증 방법:** 분석 내용의 근거 확인, 게시 전 미리보기, 전체 흐름과 예약 실행 시험

수집한 정보와 생성한 글을 대조해, 근거 없는 수치나 뉴스 내용이 게시되지 않도록 확인할 방법도 설계합니다.

## 개발 작업 체크리스트

원래 프로젝트 흐름을 실제 작업 단위로 나눈 **초안**입니다. 개인별 기술 스택과 구현 수준에 맞게 조정할 수 있습니다.

- [ ] 자신만의 Codex 작업 환경과 GitHub 레포지토리를 준비한다.
- [ ] 대상 시장, 독자, 게시 형식, 데이터 소스와 실행 시각을 정한다.
- [ ] Market Pipeline을 만들고 기준일·출처가 포함된 결과를 확인한다.
- [ ] News Pipeline을 만들고 기사 선정 기준과 결과를 확인한다.
- [ ] 수집 결과로 AI 분석과 게시 후보 글을 생성하고 근거와 표현을 검토한다.
- [ ] 게시 전 미리보기 또는 시험 실행으로 전체 흐름을 확인한다.
- [ ] Upload Pipeline과 정기 실행을 연결하고 게시 성공·실패를 확인한다.
- [ ] 실행 방법, 필요한 설정, 테스트 방법, 알려진 제한을 README에 기록한다.
- [ ] 실제 동작을 시연하고 설계 선택과 시행착오를 발표 자료로 정리한다.

**최소 완료 상태:** 정해진 기준일의 시장 정보와 뉴스를 수집해 요약 글을 만들고, 정해진 시간에 X 게시까지 실행할 수 있으며, 다른 사람이 레포지토리의 안내를 따라 실행·검증할 수 있습니다.

## 10-03 오리엔테이션 기록

OT에서는 XFolio에서 만들 에이전트의 큰 흐름과 **Market Pipeline, News Pipeline, Upload Pipeline**의 필요성을 소개했습니다. News Pipeline의 복잡도로 프로젝트 난이도를 조절할 수 있으며, 구현에 필요한 third-party 기능과 함께 공유할 부분·개인별 커스텀 부분을 안내했습니다.

스터디 진행 순서는 **자신만의 Codex 작업 환경 세팅 → 기획·설계 및 리서치 → 개발 → 테스트 및 배포**입니다. 매주 정기 온라인 미팅 전에 각자의 발표 내용을 공유 문서에 작성해 크루원들과 공유합니다.
