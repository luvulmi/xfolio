# XFolio 프로젝트 개요

미국 시장 관심 독자에게 **SPY·QQQ·DIA ETF 종가와 주요 뉴스를 한국어로 전달하는 비상업 정보 공유 프로젝트**다. 근거 확인·버전 승인·예약 게시·장애와 비용 처리를 실제 구현 근거로 설명하는 풀스택 포트폴리오를 목표로 한다.

08:00에 ETF 종가·등락률 1글과 주요 뉴스 최대 3글을 게시한다. 가격은 yfinance, 뉴스는 Exa를 사용하고 기존 BLS CPI를 연결한다. 최대치는 의무 발행량이 아니며 이용 조건·월 예산을 충족한 자료만 다룬다.

React·TypeScript, FastAPI, PostgreSQL과 별도 Python worker를 연결하고 Docker·AWS 운영은 후속으로 진행한다. 기존 Python·Luna·Neon·로그인 자산을 재사용하며 Streamlit은 가상 시험 이력으로 보존한다.

## 스터디와 개인 목표

XFolio(엑스폴리오)는 X와 Portfolio를 합친 이름이다. 이 저장소는 곧 4년차 풀스택 개발자의 이직 포트폴리오이며, 승인·게시·장애 대응을 실제 구현과 검증 근거로 설명하는 것을 목표로 한다.

스터디 참여자 6명은 서비스를 분담하지 않고 각각 하나의 에이전트를 만든다. 공통 흐름은 따르되 언어·기술·기능은 개인이 선택하고, 매주 온라인 미팅에서 진행 상황과 문제 해결을 공유한다. OpenAI API·Codex를 활용한 기획→설계→수집→분석→생성→자동화→테스트→배포 경험을 다른 자동화 분야에도 응용한다. 최종 결과물은 개인 에이전트·GitHub 저장소·동작 시연·발표 자료다.
