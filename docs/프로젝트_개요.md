# XFolio · 개인용 ETF 뉴스레터

- 기준: 2026-11-01, Asia/Seoul. 공개 X 게시에서 본인용 Telegram 뉴스레터로 전환했다.

한국 상장 해외 ETF와 미국 시장 뉴스를 수집·검사·정리해 본인과 봇의 1:1 Telegram 대화로 자동 전달한다. 기본 관심 종목은 TIGER 미국S&P500(360750), KODEX 미국나스닥100(379810), TIGER 미국배당다우존스(458730)이며 활성 종목은 총 10개까지다.

월~금 08:00에는 최근 완료 한국 거래일 종가·등락률과 새 뉴스 최대 3건, 한국 거래일 14:00에는 장중 가격·등락률을 보낸다. 16:00 마감 요약은 선택 기능이며 기본 꺼짐이다. 한국 휴장일 아침은 가격 기준일을 명시하고 새 뉴스 중심으로 구성하며 주말은 보내지 않는다.

관리자는 Google 로그인 후 종목 추가·활성화·순서, 선택 알림, 자동 발송 일시 중지와 발송 이력을 관리한다. 사람의 매회 승인은 필수가 아니며 근거·품질·이용 조건·예산 검사를 통과한 결과만 자동 전송한다.

React·TypeScript + FastAPI + PostgreSQL + 별도 Python worker·APScheduler를 목표로 한다. 국내 시세는 KIS 조건부 채택, 뉴스는 Exa와 기존 BLS CPI를 활용한다. KIS 계좌는 있으나 Open API 신청 전이며 인증 시세 표본·이용 조건 인수는 대기다.

기존 미국 ETF·AM 승인·PM 차단 코드와 시험은 재사용/이행 자산이다. 새 국내 시세·종목 관리·오후 편성·Telegram 자동 발송은 아직 구현하지 않았다. 기존 Streamlit도 과거 시험 자산이다. X·Portfolio에서 유래한 XFolio 이름은 유지한다.
