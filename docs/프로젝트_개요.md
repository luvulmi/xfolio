# XFolio · 개인용 ETF 뉴스레터

- 기준: 2026-11-03, Asia/Seoul. 공개 X 게시에서 본인용 Telegram 뉴스레터로 전환했다.

한국 상장 해외 ETF·일반 뉴스 링크·미국 공식 경제·정책 발표를 수집·검사·정리해 본인과 봇의 1:1 Telegram 대화로 자동 전달한다. 기본 관심 종목은 TIGER 미국S&P500(360750), KODEX 미국나스닥100(379810), TIGER 미국배당다우존스(458730)이며 활성 종목은 총 10개까지다.

기본 목표는 월~금08:00 아침1회, 최근 완료 한국 거래일 종가·등락률과 새 뉴스 최대3건을 보내는 것이다. 한국 거래일14:00 장중 가격과16:00 마감 요약은 모두 선택 기능이며 기본 꺼짐이다. 한국 휴장일 아침은 가격 기준일을 명시하고 새 뉴스 중심으로 구성하며 주말은 보내지 않는다.

관리자는 본인 PC·휴대폰의 Tailscale로 비공개 접속하고 Google 로그인 후 종목 추가·활성화·순서, 선택 알림, 자동 발송 일시 중지와 발송 이력을 관리한다. 사람의 매회 승인은 필수가 아니며 근거·품질·이용 조건·예산 검사를 통과한 결과만 자동 전송한다.

React·TypeScript + FastAPI + PostgreSQL + 별도 Python worker·APScheduler를 목표로 한다. 국내 시세는 KIS 개인용 채택, 뉴스는 일반 기사 원제·출처·원문 링크와 BLS·BEA·Board 자체 발표 AI 요약을 합쳐 최대3건 제공한다. 공식 발표는 기관에서 직접 수집하며 일반 뉴스는 Finnhub Free general을 본인 개인용으로 채택한다. 개인 이용 기준을 적용하고 원매체 링크·운영 기술 인수는 후속이며 Exa는 초기 필수 경로에서 제외한다. 일반 기사 본문 AI 요약·이미지 재배포는 초기 제외한다. KIS는11/3 실전 인증·기본3종목×2거래일 종가/휴장 응답을 확인했다. 본인 AWS/비공개 관리자·본인1명 Telegram 경유·가격90일 보관은 사용자 개인 이용 허용 판단으로 채택해 T01을 완료했다. 제품 연결·실제 송신/배포 인수는 후속이다.

기존 미국 ETF·AM 승인·PM 차단 코드와 시험은 재사용/이행 자산이다. T02 국내 시세·거래일·종목/가격 DB는 구현·격리 시험을 완료했고 관리자 UI/API·오후 편성·Telegram 자동 발송은 후속이다. 기존 Streamlit도 과거 시험 자산이다. X·Portfolio에서 유래한 XFolio 이름은 유지한다.
