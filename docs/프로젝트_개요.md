# XFolio 풀스택 포트폴리오·스터디 개요

## 이 저장소의 개인 목표 · 2026-10-28

곧 4년차 풀스택 개발자의 이직 포트폴리오로, 시장 수집과 생성뿐 아니라 **React/TypeScript 검토 화면·FastAPI 계약·PostgreSQL 버전 승인·정시 게시·장애/비용 처리·Docker/AWS 배포**를 실제 근거로 설명한다. 아침 최대 3글과 낮 감시 후 **18시 최대 2뉴스**, 중요한 오류의 **Telegram 발신 알림**을 2주 MVP로 연결한다.

기존 Python·Luna·Neon 자산을 재사용하고 Streamlit은 가상 시험 이력으로 남긴다. 2주 목표는 reviewed MVP이며 5거래일 검토와 auto 운영 활성화는 후속이다. [확정 기획](요구사항.md) · [30시간 일정](../tasks/plans/개발_일정.md)

## 프로젝트 목표

**XFolio(엑스폴리오)**는 X(구 트위터)와 Portfolio를 합친 이름입니다. 각 크루원이 OpenAI API와 Codex를 활용해 **현재의 주요 주식시장 정보를 수집·분석하고, 읽기 쉬운 콘텐츠를 정해진 시간에 X에 자동 게시하는 AI 에이전트**를 만듭니다.

시장 데이터 수집 + 시장 뉴스 수집 → AI 분석 및 콘텐츠 생성 → 예약 실행 및 X 게시

스터디의 핵심은 주식 지식 자체보다 **기획 → 설계 → 데이터 수집 → AI 분석 → 콘텐츠 생성 → 자동화 → 테스트 → 배포**를 직접 경험하는 것입니다. 이 경험을 업무 자동화, 데이터 분석, 콘텐츠 자동화 등 다른 분야에도 응용하는 것을 목표로 합니다.

## 스터디 방식과 최종 결과물

- **개인별 구현:** 6명이 하나의 서비스를 분담하지 않습니다. 각자 하나씩, 총 6개의 XFolio 에이전트를 만듭니다.
- **공통 흐름, 자유로운 구현:** 전체 작업 단계는 함께 따라가되 언어, 기술 스택, 세부 기능과 자동화 방식은 각자가 선택합니다. 개발이 익숙하지 않은 크루원은 기획·설계 단계부터 리더와 다른 크루원의 도움을 받을 수 있습니다.
- **함께 해결:** 매주 정기 온라인 미팅에서 진행 상황, 선택한 기술과 구조, 막힌 점과 시도한 해결 방법을 공유합니다.
- **최종 결과물:** 개인 XFolio 에이전트, GitHub 레포지토리, 실제 동작 시연, 프로젝트 발표 자료.
