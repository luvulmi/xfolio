## 읽는 순서와 상태

[요구사항 ID·수용 조건](../요구사항.md#요구사항-목록과-수용-조건) → [WBS 추적](../planning/작업_분해_WBS.md#요구사항과-검증-추적) → 시스템/시퀀스 → IA → API → ERD 순으로 읽는다. 7종 산출물과 6개 문서의 대응은 [전체 목차](../README.md#개발발표-문서-읽는-순서)를 따른다.

현행은 코드·OpenAPI·물리 schema로 대조하고 초기 목표·후속 확장·미결정 계약을 구분한다. 신규 프로필·Exa 필드는 [입력 책임의 결정 조건](뉴스_입력과_검증_책임.md#미결정-계약과-결정-조건)을 따른다. 기존 official 프로필·SEC 상세는 후속 공식 자료 보존 설계이며 Exa 공통 계약의 확정값이 아니다. 와이어프레임은 10/29 이전 범위의 시연 자료다.
