# 작업 분해 WBS

- 기준: 2026-10-30, Asia/Seoul · **Fed + BLS + BEA + SEC 10기업 + 세 지수**
- 상태: 4주차 계획. 5~6주차 30h 확정, 7~8주차 30h는 미확정 가정.
- 관련: [단계별 범위](개발_범위와_단계.md) · [요구사항](../요구사항.md) · [발표 요약](../../tasks/presentations/4주차_개발_계획.md)
- 시간은 개발자 1명의 순차 작업 기준이며 관련 단위 시험을 포함한다. A07/B06은 별도 통합 인수다. 외부 조건 대기와 5거래일 관측은 작업 시간과 구분한다.

## 입력 N·M · 기준 24h

**확정:** Fed FOMC 성명·BLS CPI·BEA PCE·SEC 10기업의 8-K 실적·M&A와 세 지수. 기업 구성은 [요구사항](../요구사항.md#sec-10기업)을 따른다. 20기업 확장과 확장 시험은 삭제한다.

**착수 조건:** 공식 법인명·CIK·공시 표본·감시 시작일·이용 범위 대조. 고용·GDP·해외기업 공시·범용 표/PDF는 후속이며 추가하면 다시 산정한다.

| --- | --- | ---: | ---: | --- |
| N01 | 뉴스 API 선택 종료 | 0 | 0~0 | Fed·BLS·BEA·SEC 공식 경로 선택, 추가 제공처 비교 없음 |

## 주차별 배치 · 60h 가정

5~6주차 각 15h만 확정이다. 사용자는 7~8주차 각 15h를 가정으로 유지하기로 했다.

| 기간 | 시간 | 배치 | 주차 말 목표 |
| --- | ---: | --- | --- |
| 5주차 · 11/2~11/8 | 15h 확정 | N02 3h + N03 3h + N04 3h + N07 1h + M01 3h + A01 2h | BLS·Fed·세 지수·기업 목록 입력 기반 |
| 6주차 · 11/9~11/15 | 15h 확정 | N05 4h + N06 7h + A04 4h | BEA·SEC 10기업과 아침 편성 착수 |
| 7주차 · 11/16~11/22 | 15h 가정 | A04 잔여 2h + A02 4h + A03 3h + A05 3h + A08 3h | 편성 마무리·검토/승인·조회·worker |
| 8주차 초 · 11/23~11/24 | 8h 가정 | A06 5h + A07 1h + 추가 여유 2h | 모의 전송·통합 인수 시작, 기능 동결 제안 |
| 8주차 후반 · 11/25~11/29 | 7h 가정 | A07 잔여 3h + C01 4h | 통합 인수·회귀·발표 |
| 합계 | **60h** | **N21 + M3 + A30 + C4 = 58h, 추가 여유 2h** | B 작업은 미포함 |

A08 결함 수정 3h는 핵심 58h에 포함돼 있다. 추가 여유 2h와 중복 합산하지 않는다. 11/15 실제 입력 지원·잔여량을 다시 산정하고, 11/22에는 승인·worker 연결을 점검한다. 11/24 기능 동결은 제안이다. 지연되면 후속 기능을 당겨 넣지 않고 미완료 범위와 검증 일정을 다시 정한다.

## 합계와 재산정 기준

| 구분 | 기준 h | 예상 범위 h |
| --- | ---: | ---: |
| 핵심 · N + M + A + C | **58** | **58~91** |
| 후속 · B | **20** | **20~33** |
| 전체 | **78** | **78~124** |

4기관은 유지하고 20기업 확장 시험 1h만 삭제해 기존 79h에서 78h로 조정했다. N07은 확정 기업의 식별자 검증·목록 설정 1h이며 10기업 완주·누락·중복 시험은 N06에 남긴다.

가용 60h 가정과 전체 기준 78h의 차이는 **18h**다. 추가 여유 2h를 전부 후속 기능에 쓰면 검증 여유가 사라지므로, 실제 진척을 보고 후속 일정을 정한다. BEA GDP·범용 문서 처리·웹 편집·auto 활성화는 기본 합계 밖이다.
