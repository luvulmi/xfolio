# 단계별 개발 범위 · Fed·BLS·BEA와 SEC 10기업

- 기준: 2026-10-30, Asia/Seoul
- 상태: 사용자 범위 변경을 반영한 계획. 제품 구현·실제 연동 완료가 아니다.
- 관련: [요구사항](../요구사항.md) · [WBS](작업_분해_WBS.md) · [관리자 화면](../specifications/관리자_화면_구조.md)

## 현재 범위

| 구분 | 현재 계획 |
| --- | --- |
| 시장 | S&P 500·Nasdaq-100·다우 세 지수 |
| 공식 자료 | **Fed + BLS + BEA + SEC 10기업** |
| 콘텐츠 | 정책·주요 경제지표·기업 실적·인수합병 |
| 제외 | SEC 20기업 확장과 확장 시험 |
| 초기 지원 확정 | Fed FOMC 성명 · BLS CPI · BEA PCE · SEC 미국 국내 발행인 8-K 실적·M&A |
| 착수 전 검증 | 확정 10기업의 공식 법인명·CIK·공시 표본·감시 시작일 |

고용·GDP·범용 표/PDF·6-K·20-F·범용 10-K/10-Q 전체 요약은 현재 시간 배정에 포함하지 않는다. 기존 BLS CPI를 공통 계약에 연결하고 검사·승인 구조를 재사용한다. [확정 기업 목록](../요구사항.md#sec-10기업)

## 먼저 완성할 흐름

**수집 → 근거·초안 저장 → 관리자 검토·승인 → AM worker → 모의 전송·결과 조회**

| 영역 | 완료 조건 |
| --- | --- |
| 공통 입력 | 출처·원문 URL·발표/접수·최초 확보 시각·버전·사건 키 보존 |
| Fed·BLS·BEA·SEC | 허용 실제 표본과 오프라인 회귀 검증, 정상 0건·부분 실패·정정·미지원 구분 |
| SEC 10기업 | CIK 기준 10개 목록·버전 고정, 10개 모두의 완료 범위·누락·중복 확인 |
| 세 지수 | 같은 완료 거래일·기준시각, 다우 누락·부분 실패·한 글 길이 검증 |
| 관리자 | 대시보드·콘텐츠 검토·발행 내역, 근거 비교·정확한 버전 승인·충돌 검사 |
| AM worker | 시각·중복 점유·승인 철회·예산·재시작, partial/unknown 처리 |
| 통합 인수 | 실제 로컬 PostgreSQL/API/브라우저와 강제 모의 송신으로 정상·실패 시연 |

자료별 이용 범위를 확인한 뒤 처리한다. AI 사실 추출과 Python 검사만으로 의미 정확성을 보증하지 않으며 운영자가 원문·조건·초안을 대조한다. 수집 실패를 뉴스 0건으로 처리하지 않는다.

## 시간과 단계

| 단계 | 시간 기준 | 목표 |
| --- | --- | --- |
| 5~6주차 | **30h 확정** | Fed·BLS·BEA·SEC·세 지수 입력과 아침 편성 착수 |
| 7주차 | 15h 가정 | 편성 마무리·검토·조회·worker |
| 8주차 | 15h 가정 | 초반 모의 전송·통합 인수, 후반 회귀·발표 |

핵심 기준 **58h**, 추가 여유 **2h**로 가용 60h 가정에 배치한다. 핵심 예상 범위는 58~91h이며 여유가 초과 가능성을 없애지는 않는다. 전체 목표는 후속 운영 20h를 더해 **기준 78h·예상 78~124h**다. 상세 산식·의존성은 WBS가 기준이다.

11/15에 실제 입력 지원과 잔여량, 11/22에 핵심 연결을 점검한다. 11/24 기능 동결을 추천하며 이후는 검증·결함 수정·발표에 남긴다.

## 후속 제품 목표

18시 편성·수집/운영/설정 조회·Telegram·CLI 수정/복구·Docker/AWS·실제 X 연동 인수는 유지한다. 추가 시간 확보나 핵심 완료 후 진척을 보고 배치하며 60h 안의 완료를 약속하지 않는다.

웹 편집·설정 변경·고급 분석·auto 활성화는 기본 합계 밖이다. auto는 별도 최소 5미국 거래일·장애 시험 이후 판단한다. 종료한 반복 관측은 재개하지 않으며 실제 외부 전송은 기존 승인 정책을 따른다.
