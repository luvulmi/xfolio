- 일정: 5~6주차30시간 확정,7주차와8주차 초까지 추가 개발 가능. 7주15시간·8주초8시간·후반7시간은 미확정 가정이며11/24 기능 동결을 추천한다.

## 확정한 제품 범위

- 지수: **S&P 500·Nasdaq100·다우**.
- 뉴스 입력: **Fed·BLS·BEA의 공식 발표와 SEC 주요 기업 공시**. 뉴스 API 선택 논의는 종료했으며 Marketaux·Alpaca/Benzinga를 신규 구현의 선행 제공처로 두지 않는다.
- SEC 기업은 **10개로 시작해20개로 확장**한다. 구체적인 명단·티커-CIK 매핑·선정 기준을 착수 시 기록한다.
- 요약 주제는 **실적·M&A·정책·주요 경제지표**다. 공식 자료에서 확인할 수 없는 일반 언론 속보나 해설까지 포함한다고 약속하지 않는다.
- 제품 전체 목표인 AM/18시 편성·관리자6메뉴·X·Telegram·AWS는 유지한다. 새 입력 범위로 늘어난 작업량과 시간 배치는 아래에서 구분한다.

## 초기 지원 유형과 완료 조건

기관4곳을 모두 최소 지원하되 각 기관의 모든 문서 유형을 범용 파싱하지 않는다. BLS CPI·Fed FOMC 성명·BEA PCE·SEC 실적/M&A를 초기 지원 유형으로 추천하며 상세 계약과 대조한다. 정책 발표와 연설, M&A 발표와 완료, 전월비와 전년비를 구분한다. 복잡한 표/PDF·비정형 첨부물·재무 계산의 자동 처리는 후속이며 지원하지 않는 자료를 조용히 통과시키지 않는다.

| 범위 | 완료 조건 |
| --- | --- |
| 공통 수집 계약 | 기관·URL·발표/수집/수정 시각·문서 버전·사건 키·수집 상태 기록. 정상0건과 실패/불완전 구분 |
| 공식4기관 입력 | 각 최소 지원 유형의 실제 허용 표본과 오류/정정 사례를 확보하고 어댑터와 근거 추적 검증 |
| SEC10→20기업 | 명단·CIK·선정 기준·버전 명시,10기업 검증 후20기업으로 확장 가능한 설정과 부하/중복 검사 |

기관 자체 자료와 SEC 기업 첨부물의 사용 범위를 구분한다. 공개 열람만으로 모든 첨부 문서의 재사용을 승인하지 않는다. 허용 근거가 없는 문서는 보류한다. AI가 사실 후보와 한국어 초안을 만들더라도 코드의 형식/수치 검사만으로 의미가 검증되었다고 표시하지 않으며 운영자가 근거·조건·새 사실을 대조한다. 신규 적격 발표가 없으면 뉴스0건이다.

## 시간과 우선 배치

전체 목표의 기준 작업량은 **79시간**, 예상 **79~126시간**이다. 공식 다중소스22시간·다우3시간·핵심 통합30시간·확장/운영20시간·최종검증/발표4시간으로 구성한다. 가용시간 가정60시간보다 기준19시간 많다.

**60시간 우선 배치 추천:** 공식4기관·3지수·SEC10기업·AM 검토/모의 전송·통합 인수59시간과 추가 여유1시간을 먼저 확보한다.5~6주차30시간은 어댑터와편성 기반의 중간 목표이며 검토/worker·모의전송을7주차~8주차 초 연결하고8주차 후반 인수한다.4기관을 선택했다는 이유로2주 안에 모두 통합 완료된다고 약속하지 않는다.

다음 B작업20시간은 전체 목표로 유지하되60시간 우선 배치에는 포함하지 않는다.8주차까지 모두 구현하려면 추가시간 확보 또는 범위 재조정이 필요하다. 이는 사용자에게서 기능 취소를 확정받았다는 뜻이 아니다.

| 확장/운영 범위 | 별도 작업이 필요한 이유 |
| --- | --- |
| 수집·운영·설정 독립 메뉴 | 조회 API·이력·비밀 미노출 검사 |
| 낮 수집·18시 편성·양 편성 통합 | 동결·중복·18시/18:10 경계·실패/정상0건 검사 |

웹 편집·설정 변경·범용 표 파싱·고급 분석과auto 활성화는 기본79시간 밖이다. auto는 별도5미국 거래일·장애 시험 이후 판단하고 중단한 반복 관측은 자동 재개하지 않는다.
