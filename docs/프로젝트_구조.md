## 로컬 생성물과 비밀

`.venv/`, `.cache/`, `.pytest_cache/`, `.ruff_cache/`, `frontend/node_modules/`, `dist/`, 시험 report는 생성물이다. `data/`는 로컬 데이터이고 `.env`·`.streamlit/secrets.toml`은 비밀 설정이다. 이번 구조 정리에서 이동·삭제하지 않았다. 런타임 결과를 문서 폴더에 자동 섞지 않는다.

## 파일을 추가할 위치

- 제품의 결정·요구사항은 docs, 남은 실행 작업은 tasks/plans, 시험 계약·근거는 tasks/verification의 해당 주제, 실제 수행은 tasks/logs에 둔다.
- 뉴스 조사 기준은 research/뉴스_수집.md 하나로 유지하고 이전 추천은 archive로 보낸다.
- 코드 모듈은 현행 import 경로를 유지했다. 뉴스 공급자와 worker의 실제 책임이 확정될 때 패키지 재편을 별도로 판단한다. jobs/가 없는 현재 상태를 구현 완료로 표시하지 않는다.
- 이동할 때 문서 상대 링크·코드 출력 경로·시험·자동화 참조를 함께 바꾼다. 로그/발표의 당시 결론은 바꾸지 않고 링크만 보정한다.
