# 기술 구성

- 기준일: 2026-10-24, Asia/Seoul
- 범위: 현재 기술 선택과 구현 상태. 기능 범위는 [요구사항](요구사항.md), 시간·한도는 [운영 정책](운영_정책.md)을 따른다.

| 적용 위치 | 선택한 기술 | 상태 |
| --- | --- | --- |
| 언어·패키지 | Python3.12·uv | 구성됨 |
| 지수 수집 | yfinance · ^GSPC·^NDX | CLI 구현·실제 두 지수 응답 확인 |
| 거래일·마감 | pandas-market-calendars · NYSE·NASDAQ | 휴장·서머타임·조기 마감 판정 구현 |
| 뉴스 수집 | httpx·제공처1곳 | Marketaux 우선 시험 후보, 최종 선정 전 |
| AI 분석·생성 | OpenAI Python SDK·Responses API·GPT-5.4 Mini | 초기 구성 선택, 실제 품질·토큰 실측 전 |
| 공통 데이터 | Pydantic·pydantic-settings | 지수 출력 모델 구현, 나머지 계약 후속 |
| 공통 저장 | SQLite·기본 sqlite3 | 선택 확정, 앱 스키마·백업 경로 후속 |
| 관리자 사이트 | 선택 의존성 Streamlit·초기 localhost | 화면 골격, 로그인·승인·결과 연동 전 |
| 실행·예약 | 기존 Windows PC·작업 스케줄러 | 운영 구성 선택, 제품 예약 등록 전 |
| 게시 | X API | 계정·권한·실제 과금·게시 검증 전 |
| 개발 검사 | pytest·Ruff, GitHub Actions는 CI 용도 | 지수 단위 테스트·정적 검사 실행 가능 |

별도 클라우드 VM·관리형 DB·사이트 호스팅은 초기 구성에 추가하지 않는다. 예약 동작에는 PC 전원·인터넷이 필요하다. 뉴스·AI·게시·승인·예약은 구현 전이며 지수 조회 성공과 전체 파이프라인 완성을 구분한다.
