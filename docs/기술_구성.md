# 기술 구성

- 기준일: 2026-10-25, Asia/Seoul
- 범위: 현재 기술 선택과 구현 상태. 기능 범위는 [요구사항](요구사항.md), 시간·한도는 [운영 정책](운영_정책.md)을 따른다.

| 적용 위치 | 선택한 기술 | 상태 |
| --- | --- | --- |
| 언어·패키지 | Python3.12·uv | 구성됨 |
| 지수 수집 | yfinance · ^GSPC·^NDX | CLI 구현·실제 두 지수 응답 확인 |
| 거래일·마감 | pandas-market-calendars · NYSE·NASDAQ | 휴장·서머타임·조기 마감 판정 구현 |
| 뉴스 수집 | httpx·제공처1곳 | Marketaux 우선 시험 후보, 최종 선정 전 |
| AI 분석·생성 | OpenAI Python SDK·Responses API·GPT-5.4 Mini | 초기 구성 선택, 실제 품질·토큰 실측 전 |
| 공통 데이터 | Pydantic·pydantic-settings | 지수 출력 모델 구현, 나머지 계약 후속 |
| 공통 저장 | Neon Free PostgreSQL·선택 의존성 psycopg, 로컬 개발 SQLite | Neon 가상 초안 저장·조회·중복 및 가상 SQLite 복사/재실행 확인. 실뉴스 커서·근거·승인·게시 원장 이전은 후속 |
| 관리자 사이트 | Streamlit Community Cloud·Google OIDC, 로컬 개발 진입점 별도 | 비공개 배포·본인 로그인·로그아웃 후 차단·화면의 Neon 가상 저장·중복 방지 검증. 실제 승인 기능은 후속 |
| 실행·예약 | Cloud Run Jobs·Cloud Scheduler 목표 | 가상 DB 시험 명령·컨테이너 준비. 결제 계정 미연결로 사용자 요청에 따라 Cloud Run 보류. 이미지·job·예약 실행 전 |
| 게시 | X API | 계정·권한·실제 과금·게시 검증 전 |
| 개발 검사 | pytest·Ruff, GitHub Actions는 CI 용도 | 지수 단위 테스트·정적 검사 실행 가능 |

현재 전환은 가상 관리자 앱까지 검증했다. Neon Free의 가상 자료 왕복·복사와, 비공개 Streamlit의 Google 로그인·가상 저장·중복 방지를 확인했다. 앱 역할은 가상 표 SELECT·INSERT로 제한한다. Google 전용 프로젝트는 `xfolio-512616`이며 결제 계정은 연결하지 않았다. 실기사 AI·실제 승인·X 게시·예약·백업을 포함한 전체 운영 파이프라인은 후속이다.
