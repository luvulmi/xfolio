- 상태 표시는 **사용 중 / 일부 구현 / 도입 예정 / 운영 검증 전**을 구분한다. 설치된 패키지가 모든 기능의 완료를 뜻하지 않는다.

ETF 등락률은 `auto_adjust=False`의 Close로 계산하고 AI에 계산을 맡기지 않는다. Exa는 시장 전체의 완전한 뉴스 피드가 아니며 제목만 있음·본문 절단·시각 미상·권리 미확인을 따로 처리한다. Fed·BEA·SEC 자동 수집은 후속이다. [입력 책임](specifications/뉴스_입력과_검증_책임.md)

| 기술 | 맡는 일·선택 이유 | 현재 상태 |

| **PostgreSQL 점유·사건 키·비용 예약** | worker 중복 실행·재시작·승인 철회 경쟁에서 중복 발행 차단 | DB 기반 일부 구현, 실제 전송 연결 예정 |
| **X API adapter · HTTPX** | 승인 버전 전송·글별 ID/성공/부분/unknown 기록 | 모의 경계와 실제 adapter 구현 예정 |
| **OAuth 1.0a 사용자 인증** | 본인 X 계정의 요청 서명 | 키 로딩 확인. 초기 추천이며 실제 인증/게시 인수 전 |
| **Telegram Bot API · DB outbox** | 중요 장애·예산 알림, 재시도·중복 억제 | 봇 테스트 수신 확인, 운영 outbox는 후속 |

worker는 단일 프로세스·replica=1을 목표로 하지만 DB 점유 없이 중복 방지가 끝났다고 보지 않는다. LLM은 승인·예산·게시 시각·전송 도구를 변경하지 못한다. unknown은 자동 재전송하지 않는다. [예약 정책](research/예약_실행.md)

## 5. 운영 배포·검증

| 기술 | 맡는 일·선택 이유 | 현재 상태 |
| --- | --- | --- |
| **Docker Compose · AWS Lightsail Linux** | VM 한 대에 web/api/worker를 함께 운영. 작은 서비스의 배포 구성 단순화 | 목표, 새 Compose/AWS 배포 미구현 |
| **Caddy HTTPS** | React 정적 파일 제공, `/api` 역방향 프록시, 같은 origin | 도입 예정. 도메인·TLS·callback 검증 필요 |
| **Neon 외부 PostgreSQL** | VM 재시작과 저장을 분리 | 최소 권한·운영 백업/복원 인수 예정 |
| **pytest · Ruff** | Python 기능/오류/동시성·정적 검사/포맷 | 테스트·명령 존재 |
| **Vitest · Testing Library · Playwright** | React 상태/상호작용·브라우저 승인 흐름·API/DB 통합 | 기존 UI/E2E 시험 자산 |
| **GitHub Actions** | `uv sync --locked`, Ruff/pytest, OpenAPI 차이, npm test/build/E2E | CI 정의 존재. 이번 문서 작업에서 원격 실행하지 않음 |

CI PostgreSQL은 이미지 `postgres:17`, Node는 22로 정의돼 있다. 이를 Neon 운영 버전의 확인 결과로 간주하지 않는다. Python 패키지의 세부 버전은 uv.lock, 프론트는 package-lock.json이 기준이다. 이번 작업은 버전 업그레이드를 수행하지 않았다.

Lightsail 1GB·IPv4 $7/월은 메모리 검증 전 가정이다. 부족하면 2GB와 예산을 재검토한다. 단일 VM은 단일 장애 지점이며 무중단·다중 AZ를 제공하지 않는다. Redis/Celery·Kubernetes·RDS/ECS·Next.js는 현재 구성에 추가하지 않는다.
