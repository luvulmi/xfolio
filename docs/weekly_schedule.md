# XFolio 스터디 주차별 일정

| 주차 | 기간 | 주요 작업 | 스터디 발표 |
| --- | --- | --- | --- |
| 1주차 | 10/3 ~ 10/11 | Codex 개발 환경 세팅 | 개인별 설정 방법 |
| 2주차 | 10/12 ~ 10/18 | 요구사항 정의 | 요구사항 문서와 에이전트 구상 |
| 3주차 | 10/19 ~ 10/25 | 필요한 기술 리서치 | 조사 결과 |
| 4주차 | 10/26 ~ 11/1 | 구현 계획 확정 | 기술 스택과 2주 개발 일정 |
| 5주차 | 11/2 ~ 11/8 | 개발 | 구현 내용과 현재 상황 |
| 6주차 | 11/9 ~ 11/15 | 개발 | 구현 내용과 현재 상황 |
| 7주차 | 11/16 ~ 11/22 | 테스트 | 발견한 오류와 해결 방법 |
| 8주차 | 11/23 ~ 11/29 | 대시보드 개발 및 마무리 | 진행 상황과 최종 결과 |

## 1주차 · 10/3 ~ 10/11

**해야 할 일:** 나만의 Codex 개발 환경 세팅

**발표할 내용:** 각자 Codex 환경을 어떻게 설정했는지 설명합니다.

- `AGENTS.md`에 적은 내용
- 만든 룰 파일과 적용한 규칙

## 2주차 · 10/12 ~ 10/18

**해야 할 일:** 무엇을 만들지 요구사항 문서로 정의합니다.

**발표할 내용:** 작성한 문서를 보여주며 다음 내용을 설명합니다.

- 만들 기능과 범위
- 내 XFolio 에이전트의 예상 모습
- 기술적인 내용 보다는 다이어그램 형식

## 3주차 · 10/19 ~ 10/25

**해야 할 일:** 구현에 필요한 기능과 라이브러리 등을 사전 조사합니다.

**발표할 내용:** 조사한 기술과 선택 후보를 설명합니다.

- 주식 정보를 가져올 수 있는 API
- 뉴스 수집 또는 크롤링에 사용할 수 있는 API 등

## 4주차 · 10/26 ~ 11/1

**해야 할 일:** 구현 방식과 기술 스택을 확정하고, 이후 2주간 개발할 내용과 예상 일정을 구체화합니다.

**발표할 내용:** 자신의 개발 계획을 설명합니다.

- 구현 방식과 사용할 기술 스택
- 5~6주차에 수행할 작업과 간략한 일정
- 예: 5주차에 파이프라인 2개 구현

## 5주차 · 11/2 ~ 11/8

**해야 할 일:** 계획에 따라 개발합니다.

**발표할 내용:** 구현한 내용과 현재 진행 상황을 설명합니다.

## 6주차 · 11/9 ~ 11/15

**해야 할 일:** 개발을 이어갑니다.

**발표할 내용:** 구현한 내용과 현재 진행 상황을 설명합니다.

## 7주차 · 11/16 ~ 11/22

**해야 할 일:** 오류가 없는지 확인하고 의도한 방식으로 동작하는지 테스트합니다.

**발표할 내용:** 발견한 오류와 해결 방법을 공유합니다.

## 8주차 · 11/23 ~ 11/29

**해야 할 일:** 대시보드를 개발하고 프로젝트를 마무리합니다. 테스트가 끝나지 않았다면 함께 완료합니다.

**발표할 내용:** 한 주 동안 진행한 작업과 현재 상태를 설명하고 최종 결과를 발표합니다.
