## 조사 결과

**장중·일별 시세 조회 기능은 확인했지만, 현재 확보한 개인 API 이용 조건만으로 정기 X 자동 게시를 허용할 근거는 없다.** 코스콤 FAQ의 개인 게시 예외는 비정기적인 부분 발췌에 관한 것이며, KRX는 개인의 재배포 목적 이용에 별도 계약이 필요하다고 안내한다. 이 서비스에 적용되는 허가·계약을 확인해야 한다.

| --- | --- | --- |

금융위원회 페이지는 메타데이터의 갱신주기와 일부 소개 문구에 ‘실시간’을 표시하지만, 상세 유의사항에는 비실시간·다음 영업일 갱신이라고 명시한다. 따라서 장중 제공 가능 근거로 쓰지 않는다. KRX 분배상품의 전송시각도 무료 OPEN API의 갱신시각으로 대입하지 않는다.

## 개인 공개 게시에 직접 관련된 근거

1. [코스콤 FAQ: 데이터 정보를 개인 블로그나 카페에 올릴 수 있나요?](https://www.koscom.co.kr/portal/main/contents.do?menuNo=200643)는 최종 이용자의 제3자 게시를 원칙적으로 제한한다. 예외는 일부 정보의 발췌, 비상업 목적, 비시스템적·비정기적 전달을 함께 충족하는 경우다. 매일 보내는 정기 제공이나 원래 정보 서비스를 대체할 수 있는 제공은 허용 사례에 포함하지 않는다.
2. [KRX 데이터 수신방법](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA003.jsp)은 개인이 실시간·20분 지연·종가를 참고하는 경우와 재배포 등 다른 목적으로 이용하는 경우를 구분하고, 후자는 별도 계약이 필요하다고 안내한다.
3. [KRX 데이터 라이센스](https://openapi.krx.co.kr/contents/OPP/DATA/OPPDATA004.jsp)는 제3자 제공 권한이 있는 일반 이용계약과 내부 이용을 위한 최종이용사용 계약을 구분한다. 따라서 시세의 공개 제공 자체가 항상 불가능한 것은 아니며, 허용 범위를 갖춘 계약이 필요하다.

**이 프로젝트에 대한 해석:** 정해진 ETF의 가격을 매일 자동 게시하는 구성은 비정기적 개인 발췌라는 예외에 의존할 수 없다. 비상업·4종목·20분 지연만으로 별도 계약이 면제된다는 근거도 찾지 못했다. 실제 SNS 제공 분류와 소규모 예외 여부는 코스콤의 서면 확인이 필요하다. ETF 브랜드 선택과 시세 재배포 권한은 별개다.

KRX 페이지에 연결된 [정보이용정책 PDF](https://data.krx.co.kr/inc/datasale/Market%20Data%20Usage%20Polices_ko.pdf)는 2024-01-01 판이다. 외부 제공 옵션을 설명하지만 X 정기 게시의 허가를 직접 명시하지 않는다. PDF가 안내한 최신 정책 페이지는 이번 도구로 열리지 않았으므로, 최신 계약 내용과 비용까지 확정한 것으로 기록하지 않는다.

KIS 고객 약관은 공식 안내가 연결한 원문을 이번 도구로 열지 못했고, 키움 고객 약관은 공식 이용안내상 로그인 후 API 신청 과정에서 확인한다. 두 제공사의 개인 API 약관 원문을 검증한 것으로 기록하지 않으며, 비공식 게시물의 약관 인용도 판단 근거로 사용하지 않는다. 따라서 두 API의 외부 게시 허용 여부는 미확인으로 유지한다.

## 설계에 반영할 판단

- 장중 게시에는 조회 시점의 최근 체결가, 전일 종가 대비 가격 등락률, 시세 기준 시각, 지연 여부가 필요하다. 게시 시각을 시세 기준 시각으로 대신하지 않는다.
- 종가 게시에는 해당 거래일의 확정 종가와 제공처의 확정·갱신 조건이 필요하다. 자료가 도착하지 않으면 이전 거래일 가격으로 채우지 않는다.
- 최대 20분 지연 허용은 `grill-me` Q2에서 사용자 결정으로 확정했다. 제공처의 실제 지연 수준과 공개 게시 허가는 별도로 확인한다.
- 지연 시세나 일별 종가라도 외부 재게시가 자동 허용된다고 보지 않는다. 가격 대신 등락률만 게시하는 방식도 허용된 우회로로 가정하지 않는다.
- 장중 게시의 실제 추가 여부는 조회 기능, 공개 게시 조건, 비용, 데이터 기준 시각을 확인한 뒤 결정한다.

## 다음 확인과 결정 순서

제공처 확인에는 개인 비상업 공개 X 계정, 관찰 상품 수, 장중·종가 게시 횟수, 상품명·가격·등락률·기준 시각 표시, 게시물 보관 조건을 구체적으로 제시해야 한다. 장중 1회와 종가 1회는 현재 제안이며 정확한 시간·빈도·비용 상한은 인터뷰에서 정한다.

확인 항목은 공개 SNS 제공 허용 여부, 별도 정보이용계약과 비용, 지연·EOD 정보의 조건, 출처 표시, 과거 게시물 보관, 당일 종가 제공 시점이다. 사용자는 게시 권한 확인을 다음 기능·운영 질문보다 우선하도록 요청했다.

결정 순서는 `4개 상품·최대 20분 지연 확정 → 공개 게시 허가·계약·비용 확인 → 허용 조건에 맞춰 제공처·게시 시간·빈도 결정`이다. 현재 두 번째 단계이며 게시 허가는 미확정이다.

6. 적용되는 최신 정책·약관과 본 용도에 허용되는 수신 경로를 안내해 주실 수 있는지요?
