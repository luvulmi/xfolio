# 공식 발표·SEC 공시 수집 근거

- 기준: 2026-10-30, Asia/Seoul. 사용자 선택 완료: Fed·BLS·BEA·SEC 주요 기업 10개 고정.
- 요약: 실적·인수합병·정책·주요 경제지표. Marketaux·Benzinga·Alpaca 등 뉴스 API 비교는 종료한다.
- 공식 문서 조사와 제품 구현을 구분한다. 이번에는 데이터 API 호출·유료 모델·실제 게시를 하지 않았다.

## 공식 진입점과 확인 사항

| 출처 | 근거 | 개발에 적용할 사실 |
| --- | --- | --- |
| BLS | [API 안내](https://www.bls.gov/developers/) · [발표 일정](https://www.bls.gov/schedule/) · [CPI 수정](https://www.bls.gov/cpi/seasonal-adjustment/) | 발표문/통계 API 역할 분리. 최신 API 수치가 과거 발표 당시 값과 같다고 보장하지 않음. 계절조정 CPI는 과거 수치 수정 가능 |
| Fed | [RSS](https://www.federalreserve.gov/feeds/feeds.htm) · [FOMC 일정](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) | RSS는 발표 발견용, 성명 원문이 근거. 정례 FOMC 연8회이며 매일 새 정책이 발생하는 것은 아님 |
| BEA | [API/RSS](https://www.bea.gov/resources/for-developers) · [발표 일정](https://www.bea.gov/news/schedule) · [GDP 개정](https://www.bea.gov/news/gdp-release-additional-information) | PCE 월별 발표, GDP 추정 차수·개정과 대상 분기를 구분. 같은 기간의 새 추정을 단순 중복으로 폐기하지 않음 |
| SEC | [EDGAR API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) · [접근·수정 안내](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data) · [개발자 안내](https://www.sec.gov/about/developer-resources) | submissions는 API키 없이 CIK별 조회. 과거 목록과 접수시각을 보존. 공통요청 한도·User-Agent 준수, 수정/삭제 고려 |

SEC 공식 한도는 동일 사용자 모든 머신 합산 최대10요청/초이며 프로젝트 초기값은1요청/초 순차를 추천한다. User-Agent에 프로젝트/기관 식별과 실제 연락처를 설정한다. 403/429에서 다른 키·주소로 우회하지 않는다. [공식 접근 안내](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)

[Form8-K](https://www.sec.gov/files/form8-k.pdf)의2.02는 실적 발표,1.01은 중요 계약,2.01은 자산취득/처분 완료,9.01은 재무제표/첨부물이다. 따라서1.01/2.01만으로 M&A라고 단정하지 않는다. 통상 제출 기한은 사건 후4영업일이나 예외가 있으므로 사건일·접수시각·발견시각을 분리한다.

## 확정한 초기 지원과 현재 코드

초기 지원은 Fed FOMC 성명·BLS CPI·BEA PCE·SEC 8-K 실적/M&A의 제한 형식으로 확정했다. 고용·GDP·해외기업 공시·복잡한 표/PDF는 후속이다. [확정 기업 목록](../요구사항.md#sec-10기업)의 공식 법인명·CIK·표본 검증은 착수 작업이다.

- 기존 BLS 코드는 CPI 첫 PRE의 월간/연간 두 주장과 시각·해시를 지원한다. 범용 BLS 수집기가 아니다.
- SEC 시험은 사람이 대조해 작성한3개 사실 카드의 한국어 미리보기다. submissions polling·자동 첨부 선택·M&A추출·10기업 커서는 미구현이다.
- Fed·BEA 제품 어댑터는 미구현이다. 확정 기업의 공식 CIK 목록은 검증 대기다.
- 지수는 기존2개 코드에다우추가가필요하다. [지수 조사](지수_데이터.md)

새 발표가 없는 정상0건과 수집 실패는 분리한다. 기관·기업 범위는 [수집 설계](../specifications/공식_발표와_공시_수집_설계.md), 권리 검토는 [이용 조건](데이터_이용_조건.md), 작업량은 [WBS](../planning/작업_분해_WBS.md)를 따른다.
