### Exa가 1순위인 이유와 남은 조건

추가 비용 없이 작은 개발 표본을 시험할 수 있고, 날짜·도메인·본문을 한 검색에서 다룬다. 실제 Intel 사건에서 공식 IR·CNBC·보도자료를 찾았고 공식 발표에 매출 $16.5B, GAAP EPS $0.60/non-GAAP $0.52, Q4 전망 $15~16B가 반환됐다. 기존 짧은 발췌의 한계를 줄일 기술적 가능성이 있다. 검색어를 서비스에 맞게 구성한 소량 표본이므로 제공처 간 객관적 승률이나 전체 회수율은 아니다.

다음 조건은 아직 통과하지 않았다.

1. **공개 이용:** 짧은 한국어 자체 문장·출처 링크·외부 AI 추론·30일 근거 보관에 ToS §4.2(a)가 어떻게 적용되는지 확인한다. API 기능을 문서화한 사실만으로 이 조항의 예외를 단정하지 않는다. Exa의 답변이 원매체 권리 전체를 대신하지도 않는다.
2. **시각과 근거:** API `publishedDate=00:00Z`를 원기사의 실제 자정 발행으로 확정하지 않는다. 실시간 기사의 변경 본문을 과거 기간 검색의 당시 버전으로 오인하지 않는다. 20,000자 상한·유료벽·297자 발췌 등은 충분성 판정 대상이다.
3. **범위:** 검색은 순위 상위 결과이므로 시장 전체를 수집 완료했다고 표시하지 않는다. 설정 질의의 요청 완료와 후보 근거 합격을 분리한다. 보도자료 재배포는 독립된 여러 출처로 세지 않는다.

기사에는 사실·보도기관의 표현·전망·해석이 함께 들어 있다. 출처 링크를 붙였다는 이유만으로 모든 요약이 허용 또는 금지된다고 단정하지 않는다. 실제 공개 방식(비수익 개인 X, 짧은 한국어 자체 문장, 외부 AI 추론, 보관 기간)을 제시해 적용 조건을 확인해야 한다. 문의 발송은 아직 하지 않았다.

### 표본 및 결정 연결

[실제 기사·API 대조](../../tasks/verification/news/뉴스_API_재검토_표본과_예산.md)에 10/29 시장 마감과 Intel 실적 사례를 기록한다. MarketNewsAPI는 이번에도 일부 일반 기사 body가 반환되어 문서상 `body=null`과 불일치했다. 해당 body는 길이만 검사했고 내용 열람·모델 입력·파일 저장은 하지 않았다.

**현재 결정:** 개발 제공처는 Exa 1개. 표본을 제품 계약으로 연결하고 공개 이용 조건을 확인한 뒤 실제 운영을 시작한다. 기존 두 API 표본 비교는 완료했다. BLS CPI만 핵심 자동 수집에 남기며 다른 공식 자료는 필요할 때 검토자가 대조하고 자동 어댑터는 후속으로 구현한다.

## 공식 자료의 핵심·후속 범위

BLS CPI는 핵심에 유지한다. Fed FOMC·BEA PCE·SEC 10기업 8-K 실적/M&A는 지원 대상 설계를 유지하되 자동 수집을 후속으로 이동했다. 뉴스 발견은 기존10기업을 우선 관찰하며 목록 밖 시장·업종 중요 사건도 허용한다.

SEC 공식 한도는 동일 사용자 모든 머신 합산 최대10요청/초이며 프로젝트 초기값은1요청/초 순차를 추천한다. User-Agent에 프로젝트/기관 식별과 실제 연락처를 설정한다. 403/429에서 다른 키·주소로 우회하지 않는다. [공식 접근 안내](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)

## 확정한 초기 지원과 현재 코드

초기 지원은 Fed FOMC 성명·BLS CPI·BEA PCE·SEC 8-K 실적/M&A의 제한 형식으로 확정했다. 고용·GDP·해외기업 공시·복잡한 표/PDF는 후속이다. [확정 기업 목록](../요구사항.md#sec-10기업)의 공식 법인명·CIK·표본 검증은 착수 작업이다.

- 기존 BLS 코드는 CPI 첫 PRE의 월간/연간 두 주장과 시각·해시를 지원한다. 범용 BLS 수집기가 아니다.
- SEC 시험은 사람이 대조해 작성한3개 사실 카드의 한국어 미리보기다. submissions polling·자동 첨부 선택·M&A추출·10기업 커서는 미구현이다.
- Fed·BEA 제품 어댑터는 미구현이다. 확정 기업의 공식 CIK 목록은 검증 대기다.
- 가격 입력은 기존 두 지수에서 SPY·QQQ·DIA ETF로 전환할 계획이다. [ETF 조사](ETF_가격_데이터.md)

새 발표가 없는 정상0건과 수집 실패는 분리한다. 기관·기업 범위는 [수집 설계](../specifications/공식_발표와_공시_수집_설계.md), 권리 검토는 [이용 조건](데이터_이용_조건.md), 작업량은 [WBS](../planning/작업_분해_WBS.md)를 따른다.
