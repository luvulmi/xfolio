- 기준: 2026-10-30, Asia/Seoul. 별도 Python worker·APScheduler 3.x를 계획한다. 아직 의존성 추가·제품 worker·예약 배포를 구현하지 않았다.
- 현재 편성은 **08:00 한 번, ETF 1글+뉴스 최대 3글**이다. 새 PM 작업·낮 정기 감시는 범위에서 제외한다.

| --- | --- |

| 07:30 | 기사·ETF 근거 확보, 정보 기준 고정 |

Exa 하루 1회×3질의는 [비용 가정](월_비용.md)이며 호출 시각·조회창·상한은 N08에서 검증한다. 필수 수집 실패는 전체 보류하고 정상 뉴스 0건은 ETF만 게시한다. 새 완료 미국 거래일이 없으면 아침 호를 생략한다.

API 프로세스와 worker를 분리한다. worker replica=1을 기본으로 하되 DB의 편성/사건 키·정확 버전·원자적 점유·한도 예약으로 중복을 막는다. 재시작 후 unknown을 자동 재전송하지 않는다. 기존 PM 이력은 조회용으로 보존하고 잔여 예약은 전송 없이 보류한다.
