# R8 · 월 비용과 3만 원 예산 비교

- 확인일: 2026-10-22, Asia/Seoul
- 상태: 공개 단가와 가정 사용량을 이용한 견적. 실제 청구·계정별 요금·환율·세금 미검증
- 기준: [조사계획](../../../tasks/week3_research_plan.md)

## 결론

2026-10-23 [yfinance](yfinance_index_collection.md) 채택에 따라 지수용 일반 조회료·라이브러리 사용료는 계획상0원이며 유료 웹 검색료는 기본 구성에 더하지 않는다. 이전 검색안의 월22일·하루2번 도구료 $0.44(약799원)와 약22,185원 견적은 비교 이력이다. 현재 X·AI·로컬 구성의 부분 견적은 약21,387원이며 공개 자료 이용 비용까지 확정된 총액은 아니다.

이 문서는 변경 전 편성의 비교 견적이다. 이후 사용자가 [초기 비용 절감 구성](../../minimum_cost_configuration.md)을 선택했으며 현재 기준은 기존 PC·기업 하루 1건·아침 링크 통합, 가정 부분 견적 **21,387원**이다. 아래 2회·VM 금액을 현재 운영 구성으로 적용하지 않는다.

현재 최대 편성에 가까운 사용량으로 URL을 담은 X 게시를 지속하고 $7 VM을 운영하면, **지수·뉴스 이용료를 제외해도 월 약 4.8만 원**이다. 환율 여유와 세금 가정까지 포함하면 약 5.8만 원이다. 따라서 월 3만 원으로 운영 가능하다고 결론 내릴 수 없다. 무료 데이터의 공개 게시 권한도 별도 해결해야 한다.

이는 매일 최대량을 반드시 게시한다는 뜻이 아니다. 실제 선정 기사가 적으면 줄어든다. 추가 발행 수를 줄이거나 게시 방식·배포안을 바꾸는 것은 제품 변경 대안이며 현재 요구사항을 임의 변경하지 않는다.

## 계산 가정

- 아침 운영일 22일·기업 운영일 22일을 각각 가정한 비교용 월이다. 실제 달력의 두 운영일은 다를 수 있다.
- 달러당 1,500원은 **현재 환율 조회값이 아닌 계산 가정**이다. 계획 환산은 환율 여유 10%와 세금 10%를 가정해 `1,500 × 1.1 × 1.1 = 1,815원/USD`로 계산한다. 실제 세금·환율·카드 수수료는 결제 시 대조하며 수수료는 여유금에서 별도 고려한다.
- 정상 시나리오는 아침 5개 글(기사 URL 포함 3개+기타 2개), 기업 뉴스 2건을 각 1개 글로 게시한다. URL 포함 110개·기타 44개·전체 154개다.
- 증가 시나리오는 기업 2건을 각 2개 글로 게시한다. URL 포함 110개·기타 88개·전체 198개다. 추가 글에 URL을 반복하면 그 글도 URL 단가를 적용해야 한다.
- 게시 결과 조회는 전체 게시물당 일반 read 1회로 보수적으로 잡는다. 다른 리소스·추가 확인·중복 실행 호출은 별도다. URL 게시 응답 자체에 담긴 ID만으로 완료하면 조회 수가 줄 수 있다.

## OpenAI 사용량 산식

정상 사용량은 다음 **예시 가정**이며 측정값이 아니다.

| 처리 | 월 호출 | 호출당 입력 | 호출당 청구 출력 가정 | 월 입력/출력 |
| --- | --- | --- | --- | --- |
| 기사 분류·근거 추출 | 20기사/일 × 22일 = 440 | 1,000 | 120 | 440,000 / 52,800 |
| 생성·검증 | 3발행/일 × 2단계 × 22일 = 132 | 2,000 | 400 | 264,000 / 52,800 |
| 합계 | 572 | — | — | **704,000 / 105,600** |

`0.704 × 0.75 + 0.1056 × 4.50 = $1.0032`다. 입력에는 지침·스키마·근거도 포함해야 하고 출력에는 추론 토큰을 포함해야 한다. 증가 시나리오는 기사·문맥 사용량 3배에 재처리까지 총 2배를 적용한 6배($6.0192)다. 이는 가정 시나리오이며 무한 호출의 상한을 증명하지 않는다. 실제 운용 전 토큰·호출 한도를 별도 설정한다.

다른 모델로 같은 가정 사용량을 계산하면 Terra는 `0.704 × 2 + 0.1056 × 12 = $2.6752`다. 품질 향상을 측정한 수치가 아니다. 내장 웹 검색·파일 검색·에이전트 호스팅 비용은 사용하지 않는 구성으로 잡았다. [AI 조사](openai_usage.md)

## 시험·재시도와 미확정 비용

- 실제 게시 시험·오류 정정·추가 결과 조회 예산을 $5로 가정하면 계획 환산 9,075원이 추가된다. 이는 예약할 여유 예시이며 실제 사용료가 아니다.
- 지수·뉴스 계약료는 소계에 포함하지 못했으므로 위 금액은 완성된 서비스 총액이 아니다. 무료 플랜의 이용 권한이 없으면 유료 가격을 더해야 한다. [지수](market_data_api.md) · [뉴스](news_sources.md)
- Supabase Pro $25 등 별도 관리형 DB를 추가하면 비용이 커진다. 무료 DB 조합은 운영 조건과 안정성 제한을 확인해야 하며 지수·뉴스 권한 문제를 해결해주지 않는다. [저장 조사](storage_admin.md)
- 예산이 3만 원으로 고정이면 먼저 데이터 권한·실제 URL 글 수·계정별 과금·서버 비용을 확인해 운영 가능한 더 작은 편성을 제시해야 한다. 소계가 초과된 상태에서 무료일 것이라는 가정으로 운영을 시작하지 않는다.

## 후속 검증 · 현재 로컬 구성의 비용 민감도

사용자는 API 계정·키가 아직 없으며 공개 자료·로컬 검증부터 진행하도록 답했다. 실제 청구 자료 없이 사용량 가정을 실측값으로 바꾸지 않는다. 현재 선택한 기업 하루1건·아침 링크 통합·기존 PC 기준으로 다시 계산했다.

| 비교용 운영일 | X(하루 $0.49 가정) | AI(22일 $1.0032를 비례 배분) | 1,815원/USD 계획 환산 |
| --- | --- | --- | --- |
| 20일 | $9.80 | $0.9120 | 19,442원 |
| 22일 | $10.78 | $1.0032 | 21,387원 |
| 23일 | $11.27 | $1.0488 | 22,359원 |

원래의 두 편성은 운영일이 다를 수 있어 위 표는 같은 일수로 단순 비교한 것이다. 실제 달력·발행 글 수·인증 API 응답으로 교체해야 한다. 산식과 반올림을 실행 확인했으며 데이터 권한·전기·백업·시험 비용은 제외다.

22일 정상 가정의 잔여 예산은 `30,000−21,386.508 = 약 8,613원`이다. 새 뉴스 후보 MarketNewsAPI Pro $15는 같은 환산 기준 27,225원이므로 그것만으로 잔여 예산을 넘는다. 거시 뉴스도 지원하지 않아 현재 단일 제공처 조건에 부적합하다. [뉴스 후속 조사](news_sources.md)

기존 증가 시나리오의 AI $6.0192만 현재 X $10.78에 더하면 `16.7992 × 1,815 = 30,491원`이다. 즉 정상 가정이 예산 안이라는 사실이 모든 재시도·추가 분석까지 감당한다는 뜻은 아니다. 실제로는 요청 전 누적 비용·예약액·입력/출력 상한으로 기존 3만 원 중단 규칙을 적용해야 한다. 새 임계값이나 호출 생략을 임의 확정하지 않는다.

**이번에 해소한 항목:** 로컬 구성의 글 수별 X 비용, 운영일 변화, AI 사용량 증가 시 초과 가능성. **계정 후 남은 항목:** 실제 X 단가·크레딧·조회량, OpenAI usage·청구 출력량, 지수·뉴스 허가 견적, 결제 환율·세금·수수료. 계정이 없으므로 이 미확정 비용을 $0으로 채우지 않는다.
