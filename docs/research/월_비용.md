## 현재 예산: 월 50,000원 · AWS 풀스택 MVP

[10/28 확정 범위](../../tasks/discussions/2026-10-28_풀스택_MVP와_18시_뉴스_편성.md)는 React/FastAPI·단일 AWS Lightsail VM·기존 Neon과 Telegram이다. 낮에 후보를 모아 18시에 최대 2뉴스를 발행한다. 아침 최대3글·하루최대5글은 유지한다. 다우를 지수1글 안에 넣는 길이 검증 전이며, 성공하면 글 수 기반 X 비용 가정은 동일하다. GCP·Streamlit 호스팅료와 5분 승인 polling 계산은 새 견적에서 제거한다.

아래는 이전 토큰량을 유지한 비교용 부분 견적이다. Fed·BLS·BEA·SEC 10기업의 실제 문서량/정정 조회·AI 토큰·저장·처리시간은 재측정해야 하므로 새 구성의 확정 견적이 아니다.

월 22일 매일 최대 게시, 계획 환산 **$1=1,815원**을 유지한 부분 견적이다. 이는 실시간 환율이나 확정 청구액이 아니다.

도메인·DNS·이미지 보관·백업·초과 전송·테스트/재시도와 실제 세금/환율 차이는 미산정이다. **전체 5만 원 충족 판정은 보류**한다. 1GB가 부족해 2GB $12가 필요하면 같은 소계는 약 **55,641원**으로 이미 상한 초과다. 후보 80/일 AI 스트레스 가정에서는 1GB 소계도 약 **46,885원**이다. [배포 계획](../../tasks/plans/클라우드_전환.md)에서 메모리·부대비용을 먼저 확인하고 예산을 자동 증액/증설하지 않는다.

고정 인프라 비용을 원장에 선반영하고 40,000원 경고·50,000원 초과 예상 유료 요청 차단을 Telegram과 연결한다. 앱 원장은 공급자 계정 전체 실청구 조회가 아니고 AWS 고정 청구를 중지하는 기능도 아니다. 기관/SEC 자료별 이용 범위·완전 수집이 미충족이면 해당 공개 운영을 켜지 않는다. 아래는 **이전 비용 가정과 조사 이력**이다.
