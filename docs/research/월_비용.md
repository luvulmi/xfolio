# 개인 Telegram 뉴스레터 월 비용과 예산

- 단가 확인·갱신일: 2026-11-06, Asia/Seoul.
- 대상: 국내 상장 해외 ETF 최대10종목·뉴스 최대3건·본인1명 Telegram, 월22거래일 아침1회. 한국 휴장 평일/주말과 기본 꺼짐인 오후 알림은 발송량에서 제외한다.
- **추천 계획액 월33,000원, 예상 범위30,000~35,000원, 기존 상한50,000원.** 유료 신청·인프라 배포를 실행한 결과가 아닌 계획 견적이다.
- [기획서 6번](../프로젝트_기획서.md#6-예상-운영-예산-및-비용-관리) · [운영 정책](../운영_정책.md) · [이전 X 견적 보존](../archive/2026-11-06_이전_X_월_비용.md).

## 공통 가정

정상 월의 비용을 비교하기 위해 **USD1=2,000원**, 과세 항목은 **부가세10%**를 가정한다. 보수적 계획 환율이며 현물 환율·개별 카드 환산액·실제 세율을 확인한 값이 아니다. AWS 무료 체험·제공처 크레딧을 매월 반복되는 할인으로 넣지 않는다.

Lightsail Linux·공인IPv4 포함2GB/2vCPU·60GB 디스크 서버1대, React 정적 화면/FastAPI/worker/Caddy/Tailscale Serve, 별도 Neon DB를 가정한다. 서버의 메모리 적정성은 배포 시험에서 확인한다. DB는 유휴 시 정지하고 계속 조회해 깨우지 않도록 구성하는 것이 무료 견적의 전제다. 서버 디스크를 DB 백업 파일에도 사용하고 스냅샷의 **누적 실제 과금 저장량20GB**를 가정한다. 할당 디스크60GB 전체와 스냅샷 사용량을 동일하게 보지 않으며, 여러 버전의 보관량도 합산한다.

부가세 가정과 예비비10%는 별개다. 추가 도메인·Lightsail 관리형 DB·로드밸런서·Exa·X API는 기본 구성에 넣지 않는다. Tailscale 주소를 사용한다. 개발 인건비는 WBS 공수로, 개발 도구 구독·기존 PC/회선 요금은 개인 기존 지출로 구분하며 위 서비스 운영비에 합산하지 않는다. OpenAI 초기 충전은 월 사용료와 별개인 잔액 선납이다.

## Telegram 발송은 무료인가

이 구성의 **일반 발송은 메시지당 과금이 없다.** 공식 FAQ는 무료 대량 발송 범위를 약30건/초로 안내하며, 별도 활성화한 paid broadcasts에서 그 범위를 넘는 전송에0.1 Stars/건을 부과한다. 현재 코드는 `allow_paid_broadcast`를 사용하지 않는다. 본인1명·아침1회는 해당 유료 기능을 필요로 하지 않는다. 짧은 본문으로 한 메시지에 보내며, 길어져 나뉘어도 일반 호출의 속도 제한을 따른다. Telegram Premium도 필요하지 않다. 통신사 데이터 요금과 서버 통신 비용은 별개다.

## AI 산정과 한계

[OpenAI 공식 가격](https://developers.openai.com/api/docs/pricing)의 `gpt-6-luna` Standard·짧은 문맥 입력은100만 토큰당 **$0.10**, 출력은 **$0.50**이다. 도구 없는 텍스트 Responses 호출을 가정한다. 일반 기사 본문은 보내지 않고 선정된 최대3개 제목을1회로 묶어 번역하며, 공식 발표만 근거를 요약한다.

현재 추정 원화 단가 입력550원/100만·출력1,100원/100만은 환율2,000원과 입력 cache write/지역 처리 가산 가능성을 보수적으로 반영한 호출 예약용 값이다. 기본 Standard 단가 환산 입력200원/출력1,000원과 구별한다. 최대16,000 입력·1,000 출력이면 `(16,000×550 + 1,000×1,100) / 1,000,000 = 9.9원`이다. 월88회가 전부 상한을 써도871.2원이다.

88회는 공식 요약을 하루3건 성공시키고 제목 묶음을1회 번역하는 **정상 사용량 견적**이며 코드의 일별 호출 제한이 아니다. 앞선 후보의 요약 실패·추가 수동 시험·새로운 준비 실행은 횟수를 늘릴 수 있다. 월 비용 원장에는 불명 요청의 예약도 남기고 추가 유료 호출 전에 월 한도를 확인한다. 실제 토큰량이 작으면 정산액은 더 작다. 결과 미확인 예약액을 실제 청구액이라고 보고하지 않는다. 가격 유효기간이 끝나면 호출을 막으므로 배포 전 단가 갱신이 필요하다.

## 무료 DB와 비용이 늘어나는 경우

- Neon Free는 프로젝트당100 CU-hour/월·저장1GB·외부 전송5GB가 기준이다. 5분 유휴 후 자동 정지한다. 기본0.25 CU라면 약400시간 활성 상태에 해당한다. 한도 소진 시 compute가 다음 주기까지 정지하거나 쓰기가 제한될 수 있어 이용량 경고·90일 삭제·백업을 확인해야 한다. 무료 한도 초과가 자동으로 유료 전환된다고 가정하지 않는다.
- 유료 Launch 단가 $0.106/CU-hour·$0.35/GB-month로0.25 CU를24시간×30일 유지하면 `180×0.106 + 1×0.35 = $19.43`, 원화 세금 가정 포함 **42,746원**이다. 다른 옵션/최소 청구 조건에 따른 차이는 별도이며, 기본 구성에 이것만 더해도 상한을 넘는다. worker/관리자의 잦은 DB 조회로 유휴 정지가 불가능하면 무료 견적을 적용하지 않는다.
- Lightsail 1GB의 $7 대안은 같은 백업/AI 가정에서 예비비 포함 **20,460원**이다. 메모리 부족 시 안정성을 위해2GB를 우선한다. 4GB $24로 증설하면 같은 조건에서 **61,600원**이므로5만원 범위에 맞지 않는다.
- 스냅샷 누적량이20GB가 아닌60GB이면 백업만6,600원이며, 전체 예비비 포함 **37,400원**이다. 보관 버전·실제 사용량에 따라 조정한다. 서버 전송량 초과·추가 디스크·보관기간 확대·선택 오후 알림·유료 뉴스 플랜도 별도 재산정한다.
- KIS 약관은 수수료 기준을 별도로 두므로 계정 요금을0원으로 확정하지 않았다. 현재 개인 계정 신청 조건/데이터 요금을 배포 전에 확인하고, 실제 별도 요금이 있으면 이 예산에 더한다. [이용 조건](데이터_이용_조건.md)을 따른다.

## 예산 관리 계획

월40,000원 경고·50,000원 초과 예상 시 새 유료 작업/플랜 확대 보류를 기준으로 한다. AI의 월별 확정/예약/추정액은 원장과 잠금으로 관리한다. 호출별 max token·마감·가격 유효기간도 검사한다. 신규 제목 번역도 같은 원장을 사용한다.

AWS 서버/백업·외부 유료 플랜은 AI 원장만으로 자동 차단되지 않는다. 배포 전에 AWS 비용 경고·무료 DB 이용량·백업 보관량을 연결하고 청구서를 대조해야 한다. AWS Budgets 경고는 서버를 자동 중지하는 기능으로 취급하지 않는다. 실사용료·계정 잔액·결제 세금까지 인수한 것으로 표시하지 않는다.
