- 변경 이유: 무료 라이브러리로 간단하게 시작하려는 사용자 선택에 따라 yfinance로 지수 수집을 확정했다. 10월 22일 검색 우선안은 대안 이력으로 두고 기존 게시 모드는 유지한다.

## Market Pipeline의 현재 선택

**yfinance로 S&P 500(`^GSPC`)·Nasdaq-100(`^NDX`)의 일별 종가를 조회한다.** 일반 가격 조회용 API 키 발급은 필요하지 않으며, 상세 선택과 검증 범위는 [yfinance 채택 문서](../research/ETF_가격_데이터.md)에 기록했다. 무료 라이브러리 선택과 데이터의 정기 공개 게시 조건 확인은 구분한다.

`아침 예약 실행 → yfinance로 두 지수 일별 종가 조회 → 최근 완료 거래일 확인 → 전 거래일 대비 등락률 계산 → 검증 → 게시 후보`

첫 버전은 yfinance로 진행한다. 뉴스 제공처1곳 조건은 별도로 유지한다. 검색·FRED·다른 API로 자동 대체하는 기능은 이번 선택에 포함하지 않는다.

1. 한국 아침의 가장 최근 완료 미국 거래일을 먼저 정한다. 전일은 단순 달력상 어제가 아니라 최근 완료 거래일이다. 새 마감이 없으면 아침 호를 쉬며 휴장·서머타임을 반영한다.
2. yfinance로 `^GSPC`·`^NDX`의 일별 가격을 조회한다. `interval="1d"`, `auto_adjust=False`와 `Close`를 사용하며 장중 가격 감시는 하지 않는다.
3. 응답의 심볼·거래일을 확인한다. Nasdaq Composite·ETF·선물·미완료 거래일의 값을 대체값으로 쓰지 않는다.
4. 지수별 `index_id / symbol / trade_date / close / previous_trade_date / previous_close / change_pct / provider / source_url / retrieved_at`을 공통 출력에 남긴다. 출처는 Yahoo Finance, 수집 수단은 yfinance로 구분하고 없는 갱신 시각을 만들어 넣지 않는다.
5. 최근 완료 거래일과 직전 거래일 종가로 `(close / previous_close - 1) × 100`을 코드에서 계산하고 기존 표시 자릿수·반올림 기준을 적용한다.
6. 두 지수 중 하나라도 필수 날짜·종가가 없거나 결측·충돌·호출 오류를 해결하지 못하면 아침 호를 보류한다. 다른 날짜의 값·AI 추정으로 보충하지 않는다.

2026-10-23 선택에 따라 R08은 yfinance의 연속 완료 거래일 종가로 등락률을 계산하는 기준을 적용한다. 라이브러리 사용 허가가 데이터 공개 게시 허가를 대신하지 않으며, 공개 전환 전에 해당 이용 범위를 확인한다.

### 이전 선택 이력

2026-10-22에는 마감 검색 → 원문 확인 → 지수명·거래일·종가·등락률 추출을 우선하기로 했다. 이후 무료 조회와 공개 이용 조건이 별개임을 재확인하고, 사용자가 단순한 무료 라이브러리 수집을 선택해 yfinance로 변경했다. 검색 경로는 현재 구현 전제가 아니다. 기존 파일 경로는 참조 링크의 연속성을 위해 유지한다.

## 개발·테스트와 안정화 후 운영

이 모드는 아침 호와 추가 기업 뉴스 모두에 적용한다. 관리자 사이트는 안정화 뒤에도 모니터링·근거·결과·보류 사유를 보여 주지만 정상 발행마다 승인을 요구하지 않는다.

| 모드 | 처리 흐름 | 외부 게시 조건 |
| --- | --- | --- |
| dry_run | 수집·생성·검증·미리보기·모의 결과 기록 | X 전송 없음 |
| reviewed | 검증 통과 후보를 관리자 확인·승인/보류 | 승인된 정확한 버전만 기존 시간·일일 한도 안에서 게시 |
| auto | 수집·생성·자동 검증 후 예약 게시 | 검증된 현재 버전이 시간·한도·비용·중복·운영 조건을 만족하면 건별 승인 없이 게시 |

개발은 dry_run에서 시작하고 실제 게시가 필요한 테스트는 reviewed에서 수행한다. 안정화 기준을 충족하면 운영 설정을 auto로 전환한다. 이는 제품의 예정된 운영 방식이며 이 문서 작성으로 실제 X 요청을 보내거나 설정을 바꾼 것은 아니다.

### auto 전환 기준

기존 안정화 시험을 재사용한다. 별도 장기 승인 절차를 추가하지 않는다.

- reviewed에서 대상 미국 거래일 기준 연속5개 거래일 동안 예약·검증 결과를 운영자가 대조한다. 뉴스가 없거나 휴장일에 정상 생략한 것은 정상 동작으로 구분한다.
- 원문 지수명·날짜·종가·등락률·기사 사실·출처와 게시 후보가 일치하고, 무승인 시험 게시·중복·마감 위반·한도 초과·근거 없는 핵심 주장은0건이어야 한다.
- 원문 누락·지수 혼동·기준일 오류·기사 근거 부족·길이 초과·부분 게시·성공 불명·재시작·비용 중단 시험에서 예상대로 보류·중단·복구한다.
- 실제 허용된 자료의 사용 조건, 사용할 계정/키, 게시 결과 기록, 수동 중단·정정 절차가 준비되어야 한다. 기존 실제 게시 확인 기준을 충족한다.

앱 설정의 모드·전환 시각·적용 규칙/프롬프트 버전과 통과한 시험 기록을 남긴다. 화면의 승인 버튼을 누르지 않았다는 이유만으로 auto 후보를 차단하지 않는다. reviewed의 승인 기록과 auto의 검증 통과 기록은 구분한다.

### 안정화 후 실패 처리

- 검증 실패·자료 누락은 해당 발행을 보류하고 기록한다. 자동 운영이 실패한 사실을 감추기 위해 임의 값으로 채우지 않는다.
- 성공 불명·부분 게시·이미 게시한 사실 오류는 기존 자동 재전송 중단·운영자 복구·수동 정정을 적용한다. 정상 건의 자동 게시와 오류 복구는 구분한다.
- 숫자/사실 오류·중복·한도 위반 같은 중대한 운영 결함이면 자동 게시를 중단하고 reviewed로 돌린 뒤 수정·회귀 시험을 거쳐 재개한다.
- 후보 내용·근거가 바뀌면 reviewed는 재승인, auto는 재검증한다. 검증되지 않은 새 버전에 이전 승인/검증 상태를 재사용하지 않는다. 모드 변경으로 재시도·횟수·마감을 초기화하지 않는다.

## 실행·비용과 남은 기술 확인

기존 Windows PC·SQLite·로컬 Streamlit·작업 스케줄러·기업 하루1건·아침 출처 통합·총3만 원 상한을 유지한다. yfinance 수집도 07:00 준비·07:30 뉴스 정보 기준·08:00 목표·09:00 아침 마감을 따른다. 시장 종가의 대상 거래일과 뉴스의 정보 기준 시각은 별도로 기록한다.

현재 기본 구성은 yfinance 일반 조회료·라이브러리 사용료 0원으로 계획하고 지수용 유료 검색 도구는 사용하지 않는다. 기존 X·AI·로컬 실행의 약21,387원 부분 견적을 유지한다. 실제 자료 이용료·시험·전기는 별도이며 확정 월 총액은 아니다.

이전 검색안은 월22일·하루 유료 검색2회일 때 도구료 약799원과 검색 내용 토큰을 추가하는 비교안이었다. yfinance 채택 후에는 이 검색료를 현재 기본 비용에 더하지 않는다. 검색을 다시 도입할 경우 별도로 단가·사용량을 재검토한다.

Market의 yfinance 의존성·두 심볼 조회·거래일·종가·등락률 검증과 CLI는 2026-10-24 구현했다. [수집 작업 문서](../../tasks/plans/ETF_수집.md)에 구현 계약·오류 처리를 기록한다. 다음은 오전 자료 도착·뉴스와 생성 연결·모드별 게시 차단/허용 구현과 시험이다. Upload Pipeline은 아직 골격이며 조회 성공을 실제 게시 완료로 기록하지 않는다.
