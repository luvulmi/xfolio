# R2. 뉴스 제공처·수집 방식 조사

## 2026-10-29 Benzinga 거절 회신 이후 대안

**최신 상태:** 사용자가 Benzinga로부터 불가 답변을 받았다고 알렸다. 회신 원문·정확한 적용 범위는 보지 않았으며 모든 고객/용도에 대한 금지라고 일반화하지 않는다. 다만 XFolio의 현재 용도에서는 Benzinga와 이를 공급받는 Alpaca 뉴스의 우선 검증 추천을 철회한다. 다른 중개 API로 같은 콘텐츠를 받는 것만으로 허가 문제가 해결된다고 보지 않는다. 아래 Alpaca 추천/문의 초안은 이 답변 전 이력이다.

### 현재 제안 — 범위 변경 미확정

1. **현재 예산 유지:** BLS CPI/고용과 Fed 통화정책 발표 등 기관 자체 자료를 직접 수집하는 방안을 추천한다. BEA GDP/PCE는 후속 확장 후보다. 통계 API와 발표문은 구분하고, 발표 탐지는 공식 RSS/일정, 근거는 공식 발표문과 표에서 확보한다. Fed의 [공식 RSS](https://www.federalreserve.gov/feeds/feeds.htm), BEA의 [API/RSS 안내](https://www.bea.gov/resources/for-developers)를 확인했다. 이번에 실제 파서를 실행하거나 구현하지 않았다.
2. **폭넓은 언론 기사 유지:** 공개 요약 용도의 별도 라이선스 견적을 받는 경로다. [Tiingo 뉴스 제품](https://www.tiingo.com/products/news-api)은 일반 Free/Power/Commercial을 internal use로 구분하고 배포는 별도 견적을 안내한다. 반환 필드도 제목/설명/URL 등으로, 본문 추출 문제까지 해결된 후보가 아니다. [GNews](https://gnews.io/faq)는 유료 본문과 월€49.99부터의 요금을 안내하지만 [약관 §3.3](https://gnews.io/legal/terms-of-service)은 제3자 콘텐츠 권리를 부여하지 않는다. 단순 가입 추천 대상이 아니다.
3. [NewsData.io](https://newsdata.io/pricing)는 Free12시간 지연, Basic 월$199.99로 현재 예산/시의성에 맞지 않는다. 기존 MarketNewsAPI의 별도 공개 요약 라이선스 경로도 남아 있지만 무료/Pro만으로 허용되었다는 근거는 없다.

[BLS 저작권 안내](https://www.bls.gov/bls/linksite.htm)는 기존 저작권 사진/삽화를 제외한 자체 발행 자료의 public domain 이용을 안내한다. [Fed 안내](https://www.federalreserve.gov/disclaimer.htm)는 달리 표시되지 않은 자료의 복제/배포를 허용하고 제3자 자료·로고를 구분한다. [BEA 안내](https://www.bea.gov/help/faq/145)도 별도 표시 없는 자료의 허가 없는 재사용을 안내한다. 이는 기관 자체 텍스트/데이터 중심의 요약 근거이며, 링크된 언론 기사나 기업 제출 문서까지 포괄 허용하는 근거가 아니다.

**차이와 한계:** 공식 발표 중심은 뉴스 API 한 곳 교체가 아니라 수집 범위 변경이다. 광범위한 기업/업종 속보·해설을 대체하지 못하고, 발표 없는 날은 뉴스0건일 수 있다. 기존 BLS 자산을 활용할 수 있으나 Fed/BEA의 파서·정정·기준시각 검증은 추가 작업이다. 30시간 WBS 안에 자동 포함하지 않는다. 기업 공시/IR은 문서별 사용 조건을 따로 검토하며 SEC 공개 열람을 모든 첨부물의 재사용 허가로 간주하지 않는다. 사용자가 선택하기 전 요구사항·기술 구성의 Marketaux 경로는 임의 변경하지 않는다.
