# 뉴스 제공처 검토 이력

이 문서는 당시 조사·추천을 보존한다. 현재 기준은 [뉴스_수집](../research/뉴스_수집.md)이다. 과거 가격·허용 판단·제공처 추천을 현재 결정으로 사용하지 않는다.

## 2026-10-29 API 선택 재검토

**상태: 공식 문서 재확인·대체 후보 제안. 제공처 변경은 미확정.** 사용자는 뉴스 API 선택을 선행 고민으로 제시했다. 기존 Marketaux 개발 경로와 아래의 이전 조사 이력을 운영 채택 완료로 해석하지 않는다. 이번에는 공개 문서만 확인했고 인증 API 호출·신규 가입·구독·문의 발송·정기 관측 재개는 하지 않았다.

### 제안과 아직 필요한 결정

- API 이름보다 **요약할 원문 근거를 API에서 확보할 수 있는지**를 우선한다. Marketaux를 확정한 채 관리자 구현을 더 진행하기보다 Alpaca의 뉴스 접근 요금·사용 범위를 먼저 확인하고, 통과하면 알려진 거시/기업 사건의 제한 표본을 비교하는 순서를 추천한다. 이 추천은 사용자 채택 결정이 아니다.
- 표본에서는 알려진 사건 발견 여부, 기사 본문 유무와 수치/기간/조건의 근거 충분성, 수록 시각과 페이지 소모를 구분한다. 본문 존재만으로 정확성·중요성·전체 사건 포괄성을 합격 처리하지 않는다. 추가 표본 작업의 시간은 기존30시간에 묵시적으로 더하지 않는다.
- [기존 월 비용](../research/월_비용.md)의 조건부 소계46,566원은 현재 예산 여유가 작다는 계획 근거이며 이번에 전체 단가를 재검증한 견적은 아니다. 유료 뉴스 도입은 별도 라이선스 견적과 전체 예산 재계산이 필요하다.
- **현재 확인한 후보 중 무료·충분한 본문·필요 사건 범위·공개 한국어 X 요약 허용을 모두 입증한 API는 없다.** Alpaca가 요금/사용 조건에서 맞지 않으면 공개 운영 예산을 조정할지, 공식 발표 중심으로 범위를 좁힐지 결정해야 한다. 기존 Marketaux 단일 경로를 임의로 BLS/SEC 다중 수집기로 교체하지 않는다.

## 이전 선택과 조사 이력

### 2026-10-29 Alpaca 요금·AI·X 게시 조건 추가 확인

**판정: 기술 후보 유지, 공개 운영 채택 보류.** 공식 공개 문서 확인으로 확정할 수 있는 부분과 공급자 답변이 필요한 부분을 구분한다. 계정별 뉴스 권한 조회나 문의 발송은 수행하지 않았다.

- **뉴스 요금:** [2022년 출시 안내](https://alpaca.markets/blog/introducing-news-api-for-real-time-fiancial-news/)의 무료는 한시적 beta 안내다. [현재 시장 데이터 요금표](https://docs.alpaca.markets/us/docs/about-market-data-api)의 Free/$99는 주식 데이터 표이며 뉴스 전용 견적으로 사용할 수 없다. 무료 paper 계정으로 MCP를 시작할 수 있다는 안내도 뉴스 본문·실시간 권한 전체의 무료 보장은 아니다. 현재 뉴스 REST/stream 요금·지연·본문 권한·한도는 미확정이다.
- **AI 처리:** [뉴스 개요](https://docs.alpaca.markets/us/docs/historical-news-data)는 감성 분석 모델 활용을 소개하고, [공식 MCP](https://docs.alpaca.markets/us/docs/trading-api-mcp)는 뉴스 도구와 AI 클라이언트 연결을 안내한다. 따라서 AI 사용 전부 금지라고 해석하지 않는다. 그러나 외부 OpenAI API에 본문을 보내 한국어 요약을 만드는 용도와 공급자 측 보관 조건까지 허용하는 개별 계약 근거는 찾지 못했다. 모델 학습과 추론용 입력은 구분해 확인해야 한다.
- **X 공개 요약:** [일반 약관 p.2 Content](https://files.alpaca.markets/disclosures/library/TermsAndConditions.pdf)는 개인·비상업 이용을 기본으로 하고 게시·공개 표시·번역·전송·배포에 사전 서면 동의를 요구한다. 한국어 자체 사실 요약이 이 조항 아래 어떤 허가를 필요로 하는지와 Benzinga 별도 허가 필요 여부는 확인되지 않았다. 원문 링크·출처 표기 또는 비수익 개인 계정만으로 허가 완료라고 판단하지 않는다.
- **선택에 미치는 영향:** 본문 지원 때문에 검증할 기술적 가치는 있으나, 월5만원 전체 예산으로 공개 운영 가능한 제공처라는 추천은 아직 할 수 없다. 조건 확인 전에 어댑터 구현이나 유료 구독부터 진행할 이유는 없다.

### 검색 기능과 평가 기준

[문서](https://www.marketaux.com/documentation)는 `symbols`, `industries`, `search`, `language`, `published_before/after`, `limit`, `page`, 유사 기사 묶기를 제공한다. 모든 날짜는 UTC다. `description`은 메타 설명이고 `snippet`은 짧은 본문 일부다. [FAQ](https://www.marketaux.com/faq)도 기사 전문을 제공하지 않는다고 명시한다.

- 거시·정책: 기업 태그를 필수로 하지 않고 정책·물가·고용 키워드 검색을 시험한다. 태그 없는 거시 기사가 기업 필터 때문에 빠지지 않게 한다.
- 업종: 업종 태그는 기사 속 기업의 업종일 수 있으므로 업종 전반의 변화인지 AI·운영자 검토로 구분한다.
- 기업: 최대 10개 관찰 티커를 묶어 검색하고 기업 이름만 등장한 기사는 별도 사건 기준으로 거른다.
- 기사별로 주체·실제 변화·시점이 발췌에 있는지 확인한다. 부가 수치를 생략해도 충분하지 않으면 제외하며 제목으로 내용을 만들어내지 않는다.

이 기준으로 인증 표본을 판독했으며, 검색식의 충분성·누락률을 검증 완료한 것은 아니다. 문서의 감성 점수를 사건 중요성이나 미래 가격 영향으로 쓰지 않는다.

### 시간·버전·수집 성공

공개 응답 필드에서 최초 발행 시각은 확인했으나 수정 시각·과거 버전 조회·07:30 시점 스냅샷 보장은 확인하지 못했다. `published_before=07:30`에 해당하는 UTC 조건만으로 수정 후 내용을 기준 이전 내용으로 볼 수 없다. 허용된 요약을 07:30 전에 확보해 버전과 수집 완료 시각을 남기는 방식이 가능한지 검증한다. 자료가 없으면 기존 Q14대로 아침 기사에서 제외한다.

페이지 응답은 found/returned/limit/page를 제공하고 검색 결과 집합의 상한을 안내한다. **무료는 한 번에 3기사이므로 18회 확인을 18개 요청으로 단정하면 안 된다.** 페이지가 남았는데 무료 한도가 소진되면 정상 0건이 아닌 불완전 수집이다. 조회 구간·재조회 방법은 실제 수록 지연과 검색량을 본 뒤 정하며 72시간·24시간 겹침 규칙을 새로 도입하지 않는다.

| RSS | XML 파싱은 단순하지만 제공처별 필드·보관 범위·수정 이력·검색 기능 차이 | API가 부적합하면 단일 제공처 RSS의 주제 범위·이용 조건을 조사한 뒤 대안 제시. 이번에 특정 RSS를 운영 허가 후보로 검증하지 않음 |
| 원문 크롤링 | 페이지 변경·유료벽·렌더링·요청 제한·본문 추출·매체별 조건 처리 부담 | 총 30시간 구현 계획에서 우선하지 않음. API가 준 원문 링크를 자동으로 읽어도 된다는 전제로 확장하지 않음 |

RSS 공개나 robots.txt 접근 가능만으로 요약·공개 게시·보관이 허용된다고 결론내리지 않는다. 충분한 요약을 얻기 위해 여러 매체를 별도 크롤링하면 “제공처 1곳”의 단순한 연동 범위도 달라진다. 필요하면 먼저 범위 변경 이유를 정리한다.

## 남은 확인과 발표 문장

1. 표본·증분·평일 재생·한도 판정을 완료했다. 다음은 좁힌 질의의 전 페이지 확보·중요 사건 근거와 최초 수록/수정 지연 시험이다. 키 발급과 HTTP 성공만으로 운영 채택으로 전환하지 않는다.
2. Marketaux의 API 적용 조건, 한국어 요약 공개·상업 여부·LLM 전달·근거 저장/삭제 조건을 명시 자료로 확인한다. 필요한 문의는 별도 사용자 지시 후 진행한다.
3. 07:30 이전 버전을 저장할 수 있는지와 수정·정정 탐지 방법을 확인한다. 지원되지 않는 부분은 보류 규칙으로 처리 가능한 기사 비율을 평가한다.
4. 후보가 필수 조건을 못 맞추면 무료라고 확정하지 않고 단일 제공처 RSS 또는 별도 라이선스 대안을 조사한다. 뉴스 전용 본문 수집을 구현 완료로 표시하지 않는다.

발표 문장: “Marketaux를 개발 연동 대상으로 정하고 실제 검색·증분·사용량을 시험했다. 짧은 발췌의 근거 부족과 넓은 검색의 무료 한도 초과가 확인돼, 수집 범위를 좁히고 이용 조건을 확인한 뒤 공개 운영을 판단한다.”

### 2026-10-22 예비 조사 이력

1. **Marketaux 공식 문서 예시:** 최초 조사에서 열람한 응답 예시는 description·snippet·published_at·URL·ID를 포함했다. 제목이 “검토/협상”인 사례는 확정 사업 변화 근거로 부족하며, 짧은 description만으로 매출·기간·비교 기준까지 검증할 수 없다. 문서 예시 판독이며 실제 계정 응답·현재 기사 표본은 아니다. 후속 문서 재열람은 도구 시간 초과로 실패했으므로 새 성공 호출로 표시하지 않는다.
2. **Alpha Vantage 공식 데모:** [NEWS_SENTIMENT AAPL 데모](https://www.alphavantage.co/query?function=NEWS_SENTIMENT&tickers=AAPL&apikey=demo)를 열었으나 JSON은 키 발급을 안내하는 `Information` 필드뿐이었다. 반환 기사 0건이 아니라 기사 데이터 미확보다. [공식 문서](https://www.alphavantage.co/documentation/)에 거시·통화/재정·업종·기업 뉴스 필터가 있지만 현재 Premium 기능이며 [약관](https://www.alphavantage.co/terms_of_service/)상 공개 활용의 서면 합의가 남아 무료 대안으로 채택하지 않는다.

이 예비 단계에서 원문 전문·피드·개인 계정 데이터는 저장하지 않았다. API의 HTML 200 또는 JSON 수신만으로 기사 목록 조회 성공으로 처리하지 않았다. 이후10/24에는 인증 표본을 판독했으며 현재 충분성·증분/한도 판정은 문서 상단과 연결한 실제 시험을 따른다.

### 대안 조사: MarketNewsAPI · 10/22 이력과 10/24 재확인

새 후보의 [Terms §7](https://marketnewsapi.com/legal/terms)·[Acceptable Use Policy §2~4](https://marketnewsapi.com/legal/acceptable-use)를 실제 열람했다. 뉴스레터·봇에서 제목/요약/메타데이터를 출처와 함께 표시하고 요청 절감을 위한 캐시를 허용한다. 유료 플랜에는 자기 모델이 단일 기사에서 만드는 요약을 제품 입력으로 쓰는 예가 명시돼 있어 기존 후보보다 용도 설명이 구체적이다. 하지만 아카이브 복제·원 피드 재판매·일반 기사 전문 재게시는 제한하며 서비스 종료 뒤 라이선스가 끝난다. 30일 근거 보존과 영구 게시물의 종료 후 처리까지 허용됐다고 확정하지 않는다.

[AI Policy](https://marketnewsapi.com/legal/ai)는10/22 직접 열람에 실패해 공식 검색 결과로 확인했으나10/24에는 본문 직접 열람에 성공했다. Terms·AUP의 현재 표시 갱신일은10/23이다. 외부 assistant의 처리·보관은 해당 제공자 조건을 따르며 연결 자체가 라이선스를 넓히지 않는다고 설명한다. 요약은 AI 생성이고 모델 변경에 따라 달라질 수 있다. 한국어 번역·OpenAI API 직접 전달·X에 남는 게시물의 구체적 조건은 별도 확인이 필요하다. MCP 허용을 모든 제3자 전달의 무조건 허가로 해석하지 않는다.

다만 이 후보는 **현재 설계의 단일 제공처로는 부적합**하다.

- [공식 Coverage](https://marketnewsapi.com/coverage)는 미국 주식·ETF 영문 뉴스·보도자료·법률 공지에 한정하며 “Crypto, forex, and macro news are not in the feed”라고 명시한다. 10/24 재열람에서도 거시 미지원을 확인해 필요한 아침 거시·정책 범위를 충족하지 못한다.
- [요금](https://marketnewsapi.com/pricing)은 Free $0·100회/일·15분 지연, Pro 월 $15 또는 연 $162다. 무료의 가벼운 운영 허용과 유료 모델 요약 제품 예시를 근거 없이 합쳐 무료 X 자동 요약을 허용했다고 보지 않는다.
- 현재 [비용 구성](../research/월_비용.md)의 월 잔여 약2,824원보다 $15 기본료가 크다. 정확한 세후 총액 이전에도 현재 비용 구성에 추가 채택할 후보가 아니다.
- [공식 REST 문서](https://marketnewsapi.com/docs/rest)는 `/v1/status`를 무키 공개 상태 확인으로 안내하지만 실제 도구 열람은 접근 불가였다. 상태 API가 성공하더라도 기사 내용 확보를 뜻하지 않는다. 뉴스 API는 키가 필요하며 사이트 라이브 피드를 대신 크롤링하지 않았다.

따라서 이 대안은 **명확한 라이선스 설명을 비교할 참고 사례**로 남기며 후보를 바꾸거나 뉴스 제공처를 두 곳으로 늘리지 않는다.

### 후속 판정과 바로 준비할 항목

- **공개 자료로 확인 완료:** NewsAPI 개발 요금제 운영 제한, Finnhub의 파생 결과·재배포 서면 승인 및 종료 후 삭제, Marketaux 짧은 발췌 제공과 API 적용 계약의 부족, 새 후보의 거시 미지원.
- **공개 자료만으로 미해결:** Marketaux 무료에서 OpenAI API 전달·한국어 자체 요약의 X 게시·30일 근거/백업 보관·영구 게시물 보존 허용 여부, 실제 내용 충분성·수록 지연·수정 이력.
- **준비 상태:** 시험 키는10/24 사용자가 등록해 실제 인증에 사용했다. 남은 준비는 제공처의 API 적용 계약 또는 서면 답변, 좁힌 질의의 거시/업종/기업 표본·완주·충분성이다. 표본은 허용된 범위에서만 보존하고 키는 로그·문서에 남기지 않는다.
- **서면 확인에 넣을 구체적 용도:** 입력을 OpenAI API에 보내 요약·분류에 쓰는지, 하루 아침 최대1기사·기업 최대2사건을 한국어 자체 문장으로 X에 공개하는지, 원문 링크·출처·시각 표기, 근거 요약30일·최소 게시/승인 이력·백업·서비스 종료 후 게시물/근거 처리. 문의 발송·가입·구독 변경은 실행하지 않았다.

최신 로컬 구성 견적은 [월 비용](../research/월_비용.md)을 따른다. **권한을 확인한 지수·뉴스 제공처까지 포함한 운영 총액은 미확정**이다. 무료 API 키만 확보하면 공개 운영이 가능하다는 결론으로 전환하지 않는다.
