## 1. 미국 지수 마감 브리핑의 무료 데이터 조사


- 조사일: 2026-10-15, Asia/Seoul
- 상태: 무료 제공처 우선 조사. 두 지수의 정기 X 재게시가 허용된 무료 경로는 아직 미확인.
- 범위: 공식 웹페이지·이용 조건 확인. API 인증 호출, 가입, 결제, 외부 문의, X 게시 미실행.

## 현재 결정

2026-10-23 후속 확정: 지수 수집은 [yfinance](../research/지수_데이터.md)의 `^GSPC`·`^NDX`로 진행한다. 아래는 10월 15일 제공처 비교 이력이다. 설치·실제 응답·오전 도착·공개 게시 조건 검증은 후속 과제로 두며, 현재 기술 선택을 다시 미정으로 취급하지 않는다.

`grill-me` Q4에서 사용자는 첫 버전을 미국 두 지수의 마감 결과와 관련 뉴스로 좁히는 방향에 동의했다. 여기서 두 지수는 기존에 정한 **S&P500과 나스닥100(NASDAQ-100)**이다. 나스닥 종합지수(NASDAQ Composite), 미국 상장 ETF인 SPY·QQQ, 국내 상장 TIGER·KODEX ETF의 가격과 구분한다.

TIGER·KODEX 4개 ETF의 개별 장중·종가 게시는 후속 단계로 미룬다. 기존 최대 20분 지연 허용 결정은 장중 ETF 기능의 조건이며, 이번 일별 종가 자료가 20분 안에 도착한다는 뜻이 아니다. 미국 거래일과 자료 제공 시각을 확인한 뒤 한국 시간 게시 시각을 정한다.

Q5에 대한 사용자 지침은 **무료 위주로 확인**이다. 유료 이용이나 결제를 승인한 것은 아니다. 경제지표 발표 중심으로 전환하는 이전 제안은 사용자가 스터디 개요와 맞지 않는다고 거절했다. 시장 수치·뉴스 수집 → AI 분석·생성 → 예약 X 게시라는 공통 흐름을 유지한다.

## 현재 결론과 남은 확인

이번에 확인한 무료 후보 중 **두 지수의 일별 종가·전일 대비 등락률을 정기적으로 X에 자동 게시할 권한까지 확보된 경로는 없다.** 모든 무료 경로가 존재하지 않는다는 결론은 아니다. 무료 열람·다운로드 가능과 정기 외부 게시 허용을 따로 확인한다.

공개 게시 가능 여부를 확정하려면 권리자·제공처의 명시적 무료 허용 조건 또는 이 사용 방식에 대한 허가가 필요하다. 지연 자료, 종가, AI 요약이나 등락률 계산으로 바꾸는 것만으로 원천 데이터 조건이 사라진다고 가정하지 않는다.

현재 결정 순서는 `두 지수 마감+뉴스 방향 동의 → 무료 수집·공개 게시 경로 검증 → 게시 시각·뉴스 제공처·표현 방식 확정`이다. 데이터 경로가 미확정인 상태에서 다시 다른 시장이나 경제지표 전용 서비스로 변경하지 않는다.

## 결론

**2026-10-23 사용자 확정: 지수 수집 수단은 yfinance다.** S&P 500 `^GSPC`·Nasdaq-100 `^NDX`의 일별 종가와 직전 거래일 값을 조회해 등락률을 계산한다. 상세는 [yfinance 채택 문서](../research/지수_데이터.md)를 따른다. 아래 FRED·FMP·Twelve Data·Alpha Vantage는 비교 이력이며 FRED 우선 후보 결론보다 이번 선택을 우선한다. 설치·실제 응답·오전 제공 시각·공개 게시 조건 검증은 미완료다.

2026-10-23 재확인: [FRED 공개 게시 조건·아침 제공 시각](../research/지수_데이터.md)에 두 질문의 근거와 확인 한계를 모았다. 개인 SNS 일반 허용과 지수별 사전 승인 조건을 구분했으며, 공개 갱신 표시를 API 최초 수록 실측으로 취급하지 않는다. 공개 허가 취득과 오전 도착 시험은 여전히 미완료다.

표현 정정: **무료 API 조회 경로는 있다.** FRED의 무료 API와 정확한 두 계열이 확인됐으며 계정에서 키를 발급받아 응답을 시험할 수 있다. 아직 확보하지 못한 것은 공개 게시·보관 권한과 아침 목표 시각을 충족하는 운영 경로다. 이를 ‘무료 API 조회 자체가 어렵다’고 일반화하지 않는다. API 키·실제 응답 시험이 없으므로 운영 적합성이 확인된 것은 아니다.

권한을 별도로 재점검한 [공개 이용 권한 문서](../research/데이터_이용_조건.md)에 최신 판단을 정리했다. Nasdaq EOD 성과에 GDA 요구의 제한적 예외가 있지만 종가 원값·공급 경로·기타 계약을 포괄 면제하지 않아 현재 구성은 별도 확인이 필요하다.

정확한 S&P500·Nasdaq-100 종가를 얻는 문서상 경로는 있지만, **월 3만 원 안에서 정기 X 게시 권한과 아침 도착 시각까지 확인한 제공처는 없다.** 조사 당시 FRED를 내부 개발 후보로 검토했으나 현재 구현 선택은 yfinance다. FMP와 Twelve Data도 대안 비교 이력으로 남긴다. 이는 모든 무료 경로가 불가능하다는 결론이 아니다.

종가는 가격지수의 같은 거래일 값으로 맞추며 Nasdaq Composite·SPY·QQQ·선물·총수익지수를 대체값으로 쓰지 않는다. 호출 성공·데이터 제공·공개 게시 허용을 각각 확인한다.

## 구현에 사용할 데이터 형태

[FRED observations](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)는 `series_id`, `observation_start/end`, `sort_order`, `file_type=json`을 지원한다. 응답 관측값에는 `date`, `value`와 실시간 기준 필드가 있다. 아래는 요청 형태 설명이며 실제 호출 응답이 아니다.

```text
GET /fred/series/observations
  series_id=SP500 또는 NASDAQ100
  observation_start=<직전 값까지 포함하는 시작일>
  observation_end=<대상 미국 거래일>
  file_type=json
  api_key=<비밀 저장소의 등록 키>
```

내부 공통 필드는 `index_id`, `trade_date`, `close`, `previous_trade_date`, `previous_close`, `provider`, `source_url`, `retrieved_at`, `provider_updated_at`으로 둔다. 이는 구현 제안이며 제공처가 모든 필드를 직접 반환한다는 뜻이 아니다. 지수 값은 Decimal로 보존하고 `(close / previous_close - 1) × 100`으로 계산한다. 날짜가 없거나 결측이면 전일 값을 오늘 값으로 복사하지 않는다.

종가 확정 플래그·수정 이력·갱신 SLA는 각 제공처에서 미확인이다. 시리즈의 `realtime_start`를 장중 최초 공개 시각으로 해석하지 않는다.

공식 `release/dates` 설명도 원출처의 발표일과 FRED에서 실제 이용 가능한 시점이 다를 수 있다고 명시한다. 따라서 Next Release Date를 수록 약속으로 쓰지 않는다. `series` 응답의 `last_updated` 역시 관측값별 최초 수록 시각 기록이 아니다. [발표일 API 설명](https://fred.stlouisfed.org/docs/api/fred/release_dates.html), [시리즈 메타데이터 예시](https://fred.stlouisfed.org/docs/api/fred/series.html).

계정·키가 없는 현재 상태에서는 인증 API의 오전 도착 시험을 완료할 수 없다. 실제 확인은 최소 5개 유효 거래일 동안 한국 시간 07:00·07:30·07:50에 두 계열을 조회해 최신 유효 관측값의 거래일이 예상 미국 거래일과 같은지 기록한다. 마지막 관측값의 점(`.`)·휴장·오래된 날짜를 새 종가로 받아들이지 않는다. 07:50은 이 시험에서 준비 여유를 보기 위한 점검 시각이며 기존 발행 목표를 변경하지 않는다. 표본 통과도 매일의 도착 보장은 아니다. [관측값 API](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)

## 현재 선택에 미치는 영향

FRED를 무료 개발 후보로 유지할 수 있지만, **현재 근거로는 종가를 포함하는 오전 8시 X 브리핑의 운영 제공처로 확정할 수 없다.** 공개 권한 확인과 아침 도착 시험은 서로 별개다. 검색 방식 역시 원문 제공자의 조건을 따라야 하므로 이 결과만으로 검색을 무조건 우월한 대안으로 확정하지 않는다.
