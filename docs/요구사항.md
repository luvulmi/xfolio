# 요구사항 · 공식 발표와 공시 기반 시장 브리핑

- 기준: 2026-10-30, Asia/Seoul. [이번 결정](../tasks/discussions/2026-10-30_4주차_개발_계획_가독성_개선.md). Fed·BLS·BEA·SEC는 유지하고 SEC를 10기업으로 고정한다.
- 목적: 미국 시장 정보를 근거와 함께 요약하고 React 관리자→FastAPI 버전 승인→예약 게시·장애 대응을 연결하는 풀스택 포트폴리오.
- 기존 Marketaux 단일 뉴스 API 범위를 아래 공식 자료 범위로 대체한다. [이전 기준](archive/official_sources_transition/README.md)은 이력이다.

## 확정 콘텐츠 범위

| 구분 | 범위 |
| --- | --- |
| 지수 | S&P 500·Nasdaq-100·다우존스 산업평균(DJIA)의 최근 완료 미국 거래일 종가·전 거래일 대비 등락률 |
| 공식 발표 | Fed·BLS·BEA의 정책·주요 경제지표 |
| 기업 공시 | SEC EDGAR의 주요 기업 **10개로 고정** |
| 요약 유형 | 실적, 인수합병, 정책, 주요 경제지표 |
| 독자·관리자 | 미국 시장에 관심 있는 개인 투자자, 운영자1명·X계정1개 |

수집 범위 내 주요 사실을 요약한다. 전체 미국 뉴스·모든 기업·모든 정책의 전수 수집 서비스가 아니다. 매일 확인하되 새 발표가 없으면 정상0건이며 게시량을 채우기 위해 이전 발표를 재사용하지 않는다. 언론 기사·분석가 전망·목표가·루머·일상 홍보·가격 등락 나열은 뉴스 후보에서 제외한다.

## 확정한 초기 지원

- Fed: FOMC 정책 성명. 연설·의사록 등은 후속이다.
- BLS: CPI, BEA: 개인소득·지출 발표의 PCE 물가. 고용·GDP는 후속이다.
- SEC: 미국 국내 발행인의 8-K 실적·인수합병 관련 항목과 필요한 첨부. 해외기업의 6-K·20-F, 범용 10-K/10-Q 전체 요약·복잡한 표/PDF는 후속이다.
- SEC 감시 규모는 10기업으로 고정한다. 20기업 확장과 확장 시험은 계획에서 삭제한다.

## SEC 10기업

2026-10-30 사용자 선택으로 아래 기업 구성을 확정했다. 기술 분야에 금융·헬스케어·에너지를 더해 콘텐츠 주제를 분산한다. 이는 투자 추천이나 특정 지수 편입·시가총액 순위의 판정이 아니다.

| 콘텐츠 주제 | 선택한 기업 |
| --- | --- |
| 기술·플랫폼·전기차 | NVIDIA · Apple · Microsoft · Amazon · Alphabet · Meta · Tesla |
| 금융 | JPMorgan Chase |
| 헬스케어 | Johnson & Johnson |
| 에너지 | ExxonMobil |

**착수 전 검증:** 공식 법인명·CIK·티커 매핑, 지원 공시 표본, 자료별 이용 범위와 감시 시작일. 브랜드명을 실제 EDGAR 등록 법인으로 추정하지 않는다. 검증 전 서버 감시 목록을 설정 완료로 표시하지 않는다.

여러 주식 종류가 같은 CIK이면 한 기업으로 센다. 검증한 목록은 적용일과 버전을 보존하고 교체 시 새 버전으로 기록한다. 현재 목록 밖 사건을 수집했다고 표현하지 않는다.

## 제품 흐름과 편성

`세 지수 / 기관 발표·공시 → 출처별 수집 결과 → 원문 버전·사실 후보 → 코드 검사 → 한국어 초안 → 운영자 근거 대조·버전 승인 → 예약 → X 결과·비용·Telegram 기록`

| 편성 | KST 정보·게시 시각 | 글 수 |
| --- | --- | --- |
| AM | 07:30 기준 전 확보,08:00 목표·09:00 신규전송 마감 | **세 지수1글**+뉴스0~2글, 최대3글 |
| PM | 17:30까지 공개된 후보를17:45까지 확보·동결,18:00 목표·18:10 마감 | 서로 다른 사건0~2글 |

최대5글/일·월5만원·거래일·버전 승인·partial 보류 등 기존 [운영 정책](운영_정책.md)을 유지한다. 다우 추가로 지수 글을 자동 분할하거나 게시량을 늘리지 않는다. 세 지수1글의 실제 X 가중 길이를 검사하고 초과하면 문안 축약 또는 보류한다.

## 사실·근거·수집 완주

- `source_id`는 fed/bls/bea/sec, 원자료별 ID는 별도다. 시각·버전·원문 URL·근거 위치·출처별 수집 범위를 보존한다.
- 발표일·SEC 접수시각·사건 발생일·효력 발생일·실적 대상 기간을 구분한다. 기준 후 처음 확보한 자료를 과거 호에 소급하지 않는다.
- 실적은 회계기간·통화·단위·GAAP/non-GAAP·실제/회사전망 구분, 인수합병은 제안/계약/승인/완료·조건·당사자를 유지한다. 공식 공시도 내용의 미래 실현을 보증하지 않는다.
- 지표는 기준월/분기·전월/전년비·계절조정·잠정/확정/수정치를 구분한다. 서로 다른 수치를 자동 비교·합산하지 않는다.
- 수집 성공은 설정된 지표·기업·문서 유형·조회 창을 완주했다는 뜻이다. Fed·BLS·BEA·SEC와 활성 기업별 상태를 분리한다. 필수 범위 partial/failed면 해당 편성을 보류하며 정상0건으로 표시하지 않는다.
- 한 자료의 이용 제한·미지원 형식은 근거 제외 사유로 남긴다. 발견 목록을 읽지 못한 수집 실패와 구분한다. 중요한 사건의 필수 근거 충돌/미확보는 편성 보류로 처리한다.
- 기관 자체 텍스트와 제3자 자료·기업 제출 문서를 구분한다. SEC 공개 열람은 모든 첨부물의 AI 전송·재게시 허가가 아니다. [사용 범위](research/데이터_이용_조건.md)를 따른다.

## 관리자와 검증 책임

1단계는 허용 fixture로 연결을 검증하고, 선택한 유형의 실제 어댑터로 전환한다. 실제 제품 목표를 사전작성 fixture만으로 완료 처리하지 않는다. AI 사실 추출 결과는 후보이며 자동으로 사전 검토 완료 상태가 되지 않는다. 숫자·형식 검사를 통과해도 의미 정확도는 운영자가 근거와 대조한다.

| 메뉴 | 역할 |
| --- | --- |
| 대시보드 | 세 지수 상태·기관별 완주·승인 대기·조치 필요 |
| 콘텐츠 검토 | 발표/공시 원문·사실·조건·초안 비교, 편성 전체 버전 승인/보류 |
| 발행 내역 | 글별 결과·버전·출처·승인/전송 이력·unknown |
| 수집 현황 | Fed/BLS/BEA/SEC·기업별 수집 창/커서·정정·제외 이유 |
| 운영 현황 | 실행·장애/알림·비용 상세 |
| 설정 | 지수3개·기관/지표·10기업 목록·버전·시각/한도의 읽기 전용 조회 |

운영자·세션·CSRF·정확 버전·길이·근거·기한·중복·예산 검사는 서버 책임이다. UI 체크만으로 차단을 해제하지 않는다. 웹 편집·설정 변경·공급자 키 입력·게시 버튼·다중 사용자·완전 자동 선정은 초기 범위 밖이다. CLI 수정·복구와 나머지 메뉴의 단계는 [WBS](planning/작업_분해_WBS.md)를 따른다.

## 일정·완료 조건

5~6주차30시간은 중간 목표이며7주차 추가 개발·통합 시험,8주차 초 기능 마무리,후반 최종 인수·발표를 계획한다. 다중기관·SEC·다우 추가 작업량은 [WBS](planning/작업_분해_WBS.md) 하나에서 관리한다. 7~8주차 추가 시간과 동결일은 가정이며 전체 기능 완료 약속이 아니다.

현재 코드의 두 지수·BLS CPI·기존 로그인/DB 시험을 재사용하지만 다우·Fed·BLS·BEA·SEC 자동 수집과 worker/실제 게시를 구현 완료로 취급하지 않는다. 기관별 최소 실자료/오프라인 회귀·수집 불완전·정정·근거·승인 경쟁·중복/unknown·세 지수 길이와 거래일을 검증해야 한다.

reviewed로 시작하며 auto는 별도5미국 거래일 및 장애 시험·유형별 검증 후 판단한다. 실제 X/Telegram 전송은 명시적 요청 범위에서만 수행한다. RDS/ECS·Redis/Celery·고급 차트·무인배포는 추가하지 않는다.
