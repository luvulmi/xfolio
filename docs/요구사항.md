# 요구사항 · 미국 시장 뉴스와 ETF 브리핑

- 기준: 2026-10-31, Asia/Seoul. 최신 사용자 변경: 08시 단일 편성·ETF 1글+뉴스 최대 3글.
- 목적: 비상업 정보 공유용 한국어 브리핑을 운영자 검토·버전 승인 후 X에 게시한다.
- 가격은 **yfinance**, 뉴스는 **Exa API**를 사용한다. 개발 채택·실측과 제품 구현·공개 이용 허가는 구분한다.

## 상태와 읽는 법

요구 확정과 구현·검증 상태는 별개다. 아래 ID는 기능의 안정 식별자이며 WBS 작업 ID를 대체하지 않는다. `일부 구현`은 기존 범위의 자산이 있다는 뜻이며 최신 목표의 인수 통과가 아니다. 후속은 기능 도입 순서이며 미결정 계약은 [입력 책임](specifications/뉴스_입력과_검증_책임.md#미결정-계약과-결정-조건)에서 관리한다.

## 확정 콘텐츠 범위

| 구분 | 현재 요구사항 |
| --- | --- |
| ETF | **SPY · QQQ · DIA**의 최근 완료 미국 거래일 종가(USD)와 전 거래일 대비 가격 등락률 |
| 뉴스 | 미국 시장·업종·주요 기업의 실적·M&A·정책·경제지표·주요 사업 사건 |
| 공식 입력 | 기존 BLS CPI 연결 유지. Fed FOMC·BEA PCE·SEC 10기업 자동 수집은 후속 |
| 독자·관리자 | 미국 시장 관심 독자, 운영자 1명·X 계정 1개 |

SPY·QQQ·DIA는 각각 S&P 500·Nasdaq-100·DJIA를 추종하는 ETF다. ETF 시장가격을 지수 포인트나 지수 수익률로 표시하지 않는다. 조정 종가·배당 재투자 수익률과도 구분한다. 미국 휴장일의 ‘전일’은 직전 완료 거래일을 뜻하며 날짜를 명시한다.

## 편성과 상한

| 편성 | KST 기준 | 최대 게시량 |
| --- | --- | --- |
| 아침 AM | 07:30까지 근거 확보, **08:00 게시**, 09:00 신규 전송 마감 | **ETF 3종 종가·등락률 1글 + 주요 뉴스 0~3글** |

**하루 1회, 뉴스 최대 3건·ETF 1글·전체 최대 4글**이다. 오후 편성은 제품 범위에서 제거한다. 각 뉴스는 서로 다른 사건이며 과거 게시와 중복을 검사한다. 중요한 새 사실은 다음 아침에 근거와 함께 재검토한다. 적격 뉴스가 없으면 ETF만 게시하고 필수 수집 실패는 정상 0건으로 처리하지 않는다. 새 완료 미국 거래일이 없으면 아침 호를 만들지 않는다.

월 **50,000원 상한은 유지**한다. 월 22게시일의 부분 견적은 약 45,860원이며 부대비용을 확인해야 전체 예산 충족을 판단할 수 있다. [월 비용](research/월_비용.md) · [운영 정책](운영_정책.md)

## SEC 10기업

우선 관찰 기업은 NVIDIA · Apple · Microsoft · Amazon · Alphabet · Meta · Tesla · JPMorgan Chase · Johnson & Johnson · ExxonMobil이다. 목록 밖도 미국 시장·업종에 영향이 큰 사건이면 Exa 검토 후보로 허용한다. 회사명만으로 중요성을 통과시키지 않으며 루머·투자 추천·단순 홍보는 제외한다.

SEC 자동 수집은 후속이다. 착수 전 공식 법인명·CIK·티커·자료 표본·감시 시작일을 대조한다. 복수 주식 종류가 같은 CIK이면 한 기업으로 세고 목록 버전을 보존한다. 20기업 확장은 제외한다. 기업 목록은 지수 편입·시가총액 순위나 투자 추천의 판정이 아니다.

## 입력·검증·관리자

`ETF / Exa 뉴스 / BLS CPI → 출처·시각·권리·근거·사건 검사 → 한국어 초안 → 운영자 대조·버전 승인 → 08:00 예약 → 글별 결과·비용 기록`

- 출처·원문 URL·발행/확보 시각·원문 버전·근거 위치와 수집 범위를 보존한다. 날짜만 있는 기사·본문 절단·권리 미확인·필수 요청 실패를 별도 상태로 남긴다.
- 기사/보도자료, 실적/회사 전망/분석가 예상, 사실/매체 해석을 구분한다. 실적 기간·통화·GAAP, 거래 단계·조건, 지표 기준월·전월/전년비·수정치를 보존한다.
- 검색 상위 결과는 시장 전체 포괄을 뜻하지 않는다. 설정된 필수 요청이 partial/failed이거나 중요한 근거가 충돌하면 해당 편성을 보류한다.
- AI 추출은 후보이며 Python 형식·수치 검사만으로 의미 정확성을 보증하지 않는다. 운영자가 근거와 초안을 대조하고 현재 버전에 확인을 기록한다.
- React의 초기 메뉴는 대시보드·콘텐츠 검토·발행 내역이다. 수집/운영/설정 조회는 후속이며 인증·CSRF·정확 버전·길이·근거·기한·중복·예산 검사는 FastAPI가 담당한다.
- 웹 편집·설정 변경·브라우저 공급자 키 입력·직접 게시 버튼·다중 사용자·완전 자동 선정은 초기 범위 밖이다. CLI 수정·복구는 후속이다.

## 완료와 미완료의 경계

기존 코드는 `^GSPC`·`^NDX` 두 지수, 제한된 BLS CPI, 로그인·DB·승인을 지원한다. **ETF 전환·Exa 제품 어댑터·아침 worker·X 전송은 아직 구현하지 않았다.** 기존 시험을 새 범위의 합격 근거로 쓰지 않는다.

아침 편성 전체를 모의 전송으로 검증한다. 현재 승인 코드의 AM 최대 3글과 DB reserved_count 0~3·publication_posts.position 1~3 제약을 4글 목표에 맞게 변경해야 한다. PM 이력·기존 CPI 시험은 보존하되 새 PM 생성·승인·예약·전송은 제품 경로에서 차단한다. 개발은 dry_run→reviewed 순서이며 실제 X·Telegram 전송은 명시 요청 범위에서 수행한다. auto는 별도 5미국 거래일과 장애 시험 후 판단한다. 5~6주차 30h 확정·7~8주차 30h 가정과 상세 공수는 [WBS](planning/작업_분해_WBS.md)가 기준이다.

ETF 전환·차트 가공·비상업 목적·요약과 출처 링크만으로 공개 이용 허가가 확보되지는 않는다. 적용 범위는 [이용 조건](research/데이터_이용_조건.md)에서 확인한다.
