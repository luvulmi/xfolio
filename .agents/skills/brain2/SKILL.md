# Brain2

`tasks/brain_storm/session_<id>.md`에서 사용자가 확정한 사항을 지속적으로 참조할 문서에 반영한다.

1. 사용자가 지정한 세션 ID 또는 파일을 읽는다. 현재 대화에서 이어진 세션이 분명하면 그 파일을 사용한다. 대상이 모호하면 확인한다. 관련 `docs/`, `tasks/`, 저장소 지침을 읽어 기존의 기준 문서와 충돌·중복 여부를 확인한다.
2. 세션의 `사용자가 확정한 사항`만 추린다. 제안, 자신의 추천, 미결정 질문은 확정 사항으로 옮기지 않는다. 확정 내용에 필요한 값이나 범위가 빠져 있으면 그 부분만 사용자에게 확인하고, 명확한 항목은 계속 진행한다.
3. 기능·범위·입출력 기준은 관련 `docs/` 요구사항 문서에, 기술·구조 선택과 이유는 관련 설계 문서에 반영한다. 적절한 문서가 없을 때만 영어 `snake_case` 이름으로 새 문서를 만든다. 실행할 작업은 해당 `tasks/` 주제 문서에 연결하되, GitHub Issues로 관리 중이면 동일 목록을 중복 작성하지 않는다. `tasks/progress/`에는 실제 완료한 작업만 기록한다.
4. 반영한 내용에는 결정, 이유, 상태와 날짜(Asia/Seoul), 원본 세션 링크를 간결하게 남긴다. 기존 설계 초안이나 미결정 사항을 별도 근거 없이 확정으로 바꾸지 않는다. 결정이 바뀌었다면 기존 기록과 새 결정을 연결해 변경 이유를 남긴다.
5. 세션 파일에 `반영 결과`를 추가해 각 확정 사항의 대상 문서 링크와 반영 상태를 기록한다. 반영하지 못한 사항은 이유와 필요한 확인 내용을 명시한다. `tasks/README.md`의 새 작업 문서 링크와 변경한 모든 링크를 점검한다.
6. `git diff --check`와 변경 내용에 필요한 검증을 실행하고, 반영한 사항과 보류한 사항을 보고한다. 커밋·푸시는 명시적 요청이 있을 때만 수행한다.
