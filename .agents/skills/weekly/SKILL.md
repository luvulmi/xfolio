# 주차별 발표 메모

XFolio 스터디 발표를 준비할 때 `docs/weekly_schedule.md`에서 해당 주차의 발표 주제를 확인하고, 실제 작업을 근거로 한국어 메모를 작성한다.

1. 사용자가 지정한 주차를 우선한다. 지정하지 않았다면 현재 날짜(Asia/Seoul)가 속한 주차를 일정에서 찾는다. 주차를 판단할 수 없으면 확인을 요청한다.
2. `tasks/progress/`의 기존 메모, 관련 `docs/`·`tasks/` 문서와 실제 코드·검증 결과를 확인한다. 필요하면 Git 변경 내역도 살핀다. 같은 주차의 발표 메모가 있으면 그 파일을 갱신하고, 없으면 사용자가 지정한 날짜 또는 작성일(Asia/Seoul)의 `tasks/progress/YYYY-MM-DD.md`를 만든다.
3. 발표 주제에 맞춰 목표, 완료한 작업과 근거, 주요 결정과 이유, 막힌 점과 현재 상태, 다음 작업을 간결하게 정리한다. 말로 발표하기 쉬운 흐름을 만들되 발표 시간이나 형식이 지정되었다면 따른다. 확인되지 않은 완료·테스트·결정은 주장하지 않고 예정 또는 미확정으로 표시한다. 일정의 계획을 실제 성과로 취급하지 않는다.
4. 새 파일을 만들거나 이름을 바꿨다면 `tasks/README.md`의 진행 기록 링크가 해당 파일을 가리키는지 확인하고 필요하면 고친다. 기존 기록의 사실관계와 사용자 변경 사항을 보존한다.
5. 변경한 문서의 링크와 `git diff --check`를 확인하고 결과를 보고한다. 커밋·푸시는 사용자가 요청한 경우에만 수행한다.
