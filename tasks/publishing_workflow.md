# X 게시 흐름

## 작업

- [ ] 게시 형식과 실행 시각·시간대를 정한다.
- [ ] 게시 전 미리보기 또는 시험 실행 방법을 정한다.
- [ ] 관리자 사이트를 `로그인 → 대시보드(메인) → 검증 화면`으로 구성하고, 대시보드의 후보 선택 시 검증 화면으로 이동한다.
- [ ] 검증 화면에서 후보·근거·자동 검증 결과를 보여주고 검증 통과 후보의 승인·보류를 기록한다.
- [ ] 승인 전·검증 실패·마감 후 미승인 후보가 게시되지 않는지 확인한다.
- [ ] 중복 게시 방지와 성공·실패 확인 방법을 정한다.
- [ ] 게시 실패 시 기록 및 재시도 기준을 정한다.

실제 X 게시에는 사용자의 명시적 요청 또는 승인이 필요합니다. 확정한 요구사항과 설계 결정은 `docs/`에 기록합니다.
