## ❶ 확정 기획 · 0:00~1:15

XFolio는 미국 시장의 지수와 공식 발표를 모아 한국어 브리핑을 X에 게시하는 서비스입니다. AI가 초안을 만들면 운영자가 원문과 비교해 승인하고, 예약 작업이 승인한 버전만 처리합니다.

아침 8시에 세 지수 한 글과 중요 뉴스 최대 두 글을 목표로 합니다. 저녁 6시 뉴스와 자동 알림은 후속입니다. 하루 최대 다섯 글, 월 예산은 5만 원입니다.

이번에는 미정이었던 수집 범위를 확정했습니다. 지수는 S&P 500, Nasdaq-100, 다우입니다. 공식 자료는 Fed의 FOMC 성명, BLS의 CPI, BEA의 PCE, SEC의 실적·인수합병 8-K부터 지원합니다. SEC는 기술 기업 일곱 곳에 금융·헬스케어·에너지 기업을 더한 열 곳으로 고정했고, 20기업 확장은 삭제했습니다.

관리자는 React와 TypeScript, API는 FastAPI, DB는 기존 Neon PostgreSQL을 사용합니다. 기존 API 여덟 개와 테이블 여덟 개를 재사용하고, 발행 조회 API 두 개를 추가합니다. 첫 완료 목표는 아침 브리핑의 수집부터 승인, 모의 전송 결과 확인까지입니다.

## ❷ 주차별 개발 계획 · 1:15~3:15

5주차와 6주차는 각각 15시간이 확정됐습니다. 7주차와 8주차는 각각 15시간을 가정합니다. 화면에는 실제로 보고 작업할 수 있도록 시간과 완료 기준을 적었습니다.

5주차에는 공통 입력과 기존 API·DB 계약 대조에 5시간, BLS 재사용과 Fed 연결에 6시간, 다우 추가에 3시간, 기업 식별자 대조에 1시간을 씁니다. 주말까지 출처와 시각이 남는 입력을 만들고 정상 0건, 실패, 지수 누락을 구분하겠습니다.

6주차에는 BEA PCE 수집에 4시간, SEC 열 기업 수집에 7시간, 아침 편성 착수에 4시간을 씁니다. 공시 발견뿐 아니라 본문 근거와 첨부 연결, 열 기업 전체 조회와 중복 검사까지 확인합니다. 11월 15일에는 실제 지원 범위와 남은 작업량을 다시 계산합니다.

7주차에는 아침 편성을 마무리하고 관리자 세 메뉴와 조회 API 두 개를 연결합니다. worker는 승인 버전, 게시 시각, 중복을 검사하도록 만듭니다. 연결 과정의 결함 수정에 3시간을 따로 배정했습니다.

8주차 초에는 실제 로컬 DB·API·브라우저와 모의 송신을 연결해 정상 처리, 중복 차단, 부분 성공, 결과 불명을 확인합니다. 11월 24일 기능 동결을 제안하며 후반은 회귀 검사와 최종 발표에 씁니다.

총 60시간 가정에 핵심 58시간과 여유 2시간을 배치했습니다. 실제 X 게시와 AWS 배포 등 후속까지는 기준 78시간이므로 같은 기간에 전부 끝난다고 약속하지 않고 핵심 진척을 보고 조정하겠습니다.

## ❸ 현재 진행 상황·시행착오 · 3:15~4:05

현재 두 지수 조회와 관리자 목록·상세·승인, API·DB 기반이 있습니다. 실제 Google 로그인과 세션 유지·로그아웃을 로컬 HTTPS에서 확인했고, BLS CPI의 제한된 수치 검사부터 초안·편성·관리자 승인까지 시험했습니다.

10월 29일 기록은 pytest 419건, UI 10건, Playwright 2건 통과입니다. 당시 구현과 모의 조건의 결과이며 새 4기관 통합이나 실제 X 게시 완료를 뜻하지 않습니다.

Google callback 불일치와 HTTPS 연결 지연을 수정했고, AI 출력은 형식 검사만으로 부족해 수치·기간 검사와 사람의 원문 확인을 나눴습니다. 차주에는 공통 입력 계약부터 시작하겠습니다.

## ⭐ 준비 상태와 비용 · 4:05~5:00

GitHub 저장소는 웹과 Git 읽기 접근을 확인했습니다. 발표에는 10월 30일 최종 점검을 반영한 최신 자료를 사용합니다.

X 계정은 ringXFolioBot으로 확정했고, 쓰기 권한과 키 네 개의 환경 로딩을 확인했습니다. 실제 API 인증·게시는 후속입니다. Telegram은 봇 인증과 환경 설정에 더해 테스트 알림 한 건의 실제 수신까지 확인했습니다.

개발 비용은 OpenAI 월 2달러 한도와 기존 5달러 충전 잔액 사용, X는 청구 주기 2달러 한도와 첫 유료 시험 직전 5달러 충전으로 정했습니다. 자동 충전은 사용하지 않습니다. 이 금액은 계획이며 콘솔 적용과 X 결제는 시험 전에 합니다.

AWS는 ringXFolio 계정을 사용하되 무료 대상에서 제외돼 유료 동의·활성화는 배포 준비 때 진행합니다. 공식 자료 경로와 이용 조건 문서는 정리돼 있고, 연락처 설정과 기업 CIK·표본 대조는 수집 착수 전에 완료하겠습니다.

### SEC의 어떤 공시를 지원하나요?

미국 국내 발행인의 8-K를 초기 범위로 확정했다. 실적은 Item 2.02와 근거 첨부, 인수합병은 Item 1.01/2.01과 관련 첨부를 검토한다. Item 1.01은 다른 중요 계약, 2.01은 자산 취득·처분도 포함하므로 번호만으로 인수합병이라고 판정하지 않는다. EX-99.1이라는 이름만으로 실적 본문이라고 단정하지 않는다.

기업 구성은 확정했지만 법인명·CIK·적합한 공시 표본과 감시 시작일은 아직 검증해야 한다. Alphabet의 복수 주식 종류는 CIK 기준 한 기업으로 센다. [수집 설계](../../docs/specifications/공식_발표와_공시_수집_설계.md)

### 매일 뉴스가 나오나요?

공식 발표는 일정이나 사건에 따라 나오므로 새 적격 자료가 없는 날도 있다. 모든 필수 수집 범위를 확인한 정상 0건이면 아침은 지수만, 저녁은 생략한다. 누락이나 수집 실패가 있으면 해당 편성을 보류한다.

### 실제 게시와 무인 운영은 언제 하나요?

모의 전송으로 정상·부분 성공·성공 여부 불명, 중복·마감·한도 차단을 먼저 검증한다. 실제 X·Telegram은 인증·예산·명시적 발송 요청이 준비된 범위에서 확인한다. auto는 별도 최소 5미국 거래일과 장애 시험 후 판단한다. [운영 정책](../../docs/운영_정책.md)

### 공식 자료의 이용 범위와 비용은 어떻게 확인하나요?

기관 자체 자료와 제3자 자료·기업 제출물을 구분하고 보관·외부 AI 처리·공개 요약의 근거를 확인한다. SEC에 공개됐다는 사실만으로 모든 첨부물의 이용이 허용된다고 보지 않는다.
