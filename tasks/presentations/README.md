# 주차별 발표

각 발표 당시의 기획과 성과를 보존한다. 최신 일정은 [스터디 일정](../../docs/스터디_일정.md), 최신 개발 범위는 [단계 문서](../../docs/planning/개발_범위와_단계.md)다.

- [5주차 아침 뉴스레터 구현](5주차_개인용_뉴스레터_전환.md) · [5분 대본·시연·예상 질문](5주차_발표_대본.md) — **11/8 발표, 11/5 기준**. T01~T06 구현/격리 검증·관리자5메뉴·뉴스 중요도·실통신/유료1건, 실제 정시 수신·AWS 운영 인수는 후속

**4주차 발표와 계정·API 준비 마감은 2026-11-01(일)이다.** 10/30 최신 요청에 따라 **08시 ETF 1글+주요 뉴스 최대 3글**로 바꿨다. 기획 → 서비스 흐름 → 기술스택 → 개발 일정 → 현재 성과 → 준비 사항 순서로 화면 자료와 5분 대본을 구성했다. 기술은 역할별 짧은 표로 나누고 [아침 흐름도](assets/4주차_아침_흐름.svg)와 [기술 구조도](assets/4주차_기술_구조.svg)로 설명한다. 1~3주차는 당시 발표 이력으로 유지한다.
