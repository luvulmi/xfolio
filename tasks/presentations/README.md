# 주차별 발표

각 발표 당시의 기획과 성과를 보존한다. 최신 일정은 [스터디 일정](../../docs/스터디_일정.md), 최신 개발 범위는 [단계 문서](../../docs/planning/개발_범위와_단계.md)다.

**4주차 발표와 계정·API 준비 마감은 2026-11-01(일)이다.** 10/30 기준으로 확정 기획과 결정 결과, 5~8주차 구체적인 작업·시간·완료 기준, 현재 성과·차주 계획·시행착오, 11/1까지 준비할 사항 순서로 화면 자료와 대본을 구성했다. 1~3주차는 당시 발표 이력으로 유지한다.
