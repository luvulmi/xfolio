# 주차별 발표

각 발표 당시의 기획과 성과를 보존한다. 최신 일정은 [스터디 일정](../../docs/스터디_일정.md), 최신 개발 범위는 [단계 문서](../../docs/planning/개발_범위와_단계.md)다.

**2026-10-30 현재는 4주차 작업 중이다.** 4주차 화면 자료와 대본에 세 지수·공식 4기관·SEC 10→20기업, 실제 로그인/CPI 검증, 5~8주차 개발 계획을 반영했다. 1~3주차는 당시 발표 이력으로 유지한다.
