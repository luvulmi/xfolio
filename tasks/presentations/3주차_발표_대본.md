# 3주차 발표 대본 | XFolio 기술 스택과 월 비용

- 발표 주차: 2026-10-19~10-25 · 갱신일: 2026-10-25
- 화면 자료: [3주차 기술 조사](3주차_기술_조사.md)
- 예상 시간: 약 3분. *기울임꼴은 발표 동작이며 읽지 않는다.*

## ❶ 어떤 XFolio인가 · 약 35초

*첫 번째 항목을 보여준다.*

제가 만들 XFolio는 미국 시장에서 확인된 중요한 변화만 한국어로 정리해 X에 게시하는 에이전트입니다. 아침에는 S&P 500과 Nasdaq-100의 전날 종가와 등락률을 **한 글**로 묶습니다. 중요한 뉴스가 있을 때만 근거와 원문 링크를 담은 글 하나를 추가합니다. 기업은 처음에 NVIDIA, Apple, Microsoft의 실적 공시부터 살펴보고 중요한 사건만 하루 최대 두 글을 게시합니다. 관리자는 초안과 근거, 보류 이유 및 게시 결과를 확인합니다.

## ❷ 전체 기술 스택 · 약 1분 30초

*하나의 세로 Mermaid 흐름도를 위에서 아래로 짚는다.*

예약 실행은 Cloud Scheduler와 Cloud Run Jobs를 목표로 하고, 실제 처리 순서는 **Python 3.12 고정 워크플로**가 관리합니다. 왼쪽 Market Pipeline은 `yfinance`로 두 지수 종가를 가져와 거래일과 등락률을 확인합니다. 오른쪽 News Pipeline은 `httpx`로 BLS의 CPI 발표와 SEC의 기업 실적 공시를 수집하는 구상입니다. 두 지수 조회와 BLS CPI 파서는 구현했지만 SEC 자동 수집은 아직 전입니다.

뉴스의 관련성 판단과 한국어 초안에는 **OpenAI Python SDK·Responses API와 `gpt-6-luna`**를 쓰기로 확정했습니다. `Pydantic` 구조화 출력으로 값을 받고, Python이 시각·수치·근거·중복·길이와 비용을 다시 확인합니다. AI에는 게시 권한을 주지 않습니다. Luna는 같은 가상 뉴스 여섯 건의 기계 검사를 통과했습니다. SEC 사실 카드 세 건은 이전에 Mini로 시험했으므로, Luna의 실제 공시 문안은 구현 단계에서 별도로 확인합니다.

근거와 초안, 게시 결과는 **Neon Free PostgreSQL**에 저장하고, **Streamlit Community Cloud와 Google 로그인**을 관리자 화면으로 사용합니다. 비공개 관리자 Google 로그인과 Neon 가상 저장·조회·중복 방지를 확인했습니다. 기본 주소의 로그인 후 로딩 문제는 남아 있고 Cloud Run은 보류했습니다. 관리자 승인 기능, 예약, X API 게시는 아직 연결하지 않았습니다.

## ❸ 비용 · 약 55초

*비용 표와 현재 상한을 가리킨다.*

현재 확정된 월 예산 상한은 **3만 원**입니다. 월 22일, 하루 최대 네 글을 매번 게시한다면 X API 생성·조회는 약 **13.97달러**, 같은 월 토큰량을 적용한 Luna는 약 **0.12달러**입니다. 모델보다 X API 자동 게시 비용이 훨씬 큽니다.

Cloud Run 작업 3,418회가 모두 1분이면 무료 한도 안이라는 가정에서 전체 약 **2만 5천 6백 원**, 모두 2분이면 **3만 1천 원**, 3분이면 **3만 8천 원**입니다. 2분 가정부터 현재 예산을 넘으므로 **월 4만 5천 원을 변경 제안**합니다. 실제 클라우드 실행 시간과 X 계정 청구를 측정한 값은 아닙니다. 유료 뉴스 API 가입은 보류했습니다.

## 마무리 · 15초

다음에는 SEC 자동 조회와 수정·중복 처리를 구현하고, Luna 초안을 관리자 승인 화면에 연결하겠습니다. 실제 실행 후 사용량으로 월 비용을 다시 계산하겠습니다.

## 예상 질문과 답변 · 발표 후 참고

**Q. 왜 Agents SDK 대신 Python과 Responses API를 쓰나요?**

A. 수집→검증→초안→승인→게시 순서가 정해져 있어 Python이 실행 순서와 권한을 관리합니다. OpenAI는 관련성 판단과 문안 작성에만 사용합니다.

**Q. Luna를 확정했는데 실제 공시 품질은 검증하지 않았나요?**

A. 맞습니다. 모델 선택은 비용과 동일한 가상 여섯 건의 시험을 바탕으로 확정했습니다. 실제 SEC 세 사건의 요약 시험은 Mini로 수행했으므로 Luna 문안의 사실·한국어 표현 검사는 구현 단계에서 추가합니다. 실패한 문안은 게시하지 않습니다.

**Q. 뉴스 제공처는 정했나요?**

A. 첫 범위는 BLS 공식 CPI와 SEC EDGAR의 세 회사 실적 공시를 근거로 제안했습니다. BLS 파서는 구현했고 SEC 자동 조회는 후속입니다. 일반 뉴스 전체를 확보했다고 보지는 않습니다.

**Q. 3만 원과 4만 5천 원 중 확정 예산은 무엇인가요?**

A. 현재 확정 상한은 3만 원입니다. 4만 5천 원은 클라우드 실행 시간을 반영한 변경 제안이고, 실제 청구를 제한한다는 보장은 아직 없습니다.

**Q. X 웹사이트에 직접 쓰는 비용도 포함되나요?**

A. 아니요. X 비용은 API 자동 게시와 결과 조회에 대한 계획 견적입니다.
