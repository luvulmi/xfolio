## 1. 무엇을 만들까?

**미국 두 지수의 마감과 주요 뉴스를 모아 한국어로 X에 게시하는 에이전트**입니다.

- **아침:** S&P 500·Nasdaq-100 종가와 등락률 + 거시·정책·시장/업종 뉴스 최대 3건
- **추가 뉴스:** 관찰 기업 최대 10개 중 중요한 기업 소식을 하루 최대 1건 게시
- 개발·테스트에는 관리자 확인, 안정화 후 자동 검증·게시로 전환

`예약 실행 → 지수·뉴스 수집 → AI 요약 → Python 검증 → X 게시 → 결과 저장`

## 2. 주식·뉴스 데이터는 어디서 가져올까?

| 구분 | 조사한 기술·후보 | 선택과 이유 |
| --- | --- | --- |
| 지수 | **yfinance — 채택 확정** | 무료 Python 라이브러리. S&P 500 `^GSPC`·Nasdaq-100 `^NDX` 종가 조회, 일반 가격 조회용 키 불필요 |
| 지수 대안 | FRED·FMP·Twelve Data | 기능·이용 조건을 비교했고, 간단하게 시작하기 위해 yfinance 선택 |
| 뉴스 | **Marketaux — 우선 시험 후보** | 무료 100회/일·요청당 3기사. 키워드·기업 검색과 기사 설명·발췌·원문 링크 제공 |
| 뉴스 대안 | NewsAPI·Finnhub | NewsAPI 무료 플랜은 개발 전용. Finnhub는 공개 배포 조건·비용 확인이 필요해 우선순위 낮춤 |

뉴스는 **API 1곳으로 시작**합니다. 개별 사이트 크롤링은 페이지 변경·본문 추출에 대응할 부담이 있어 후순위로 검토합니다. Marketaux가 거시·기업 뉴스와 요약 근거를 충분히 주는지 샘플 확인 후 최종 선택합니다.

조사 근거: [yfinance 채택](../../docs/research/week3/yfinance_index_collection.md) · [뉴스 API 비교](../../docs/research/week3/news_sources.md)

## 3. 어느 부분에 어떤 기술을 쓸까?

| 적용 위치 | 사용할 기술 | 맡길 일 |
| --- | --- | --- |
| 전체 에이전트 | **Python 3.12·uv** | 수집·분석·검증·게시를 하나의 파이프라인으로 연결 |
| Market Pipeline | **yfinance** | 두 지수 종가 수집·등락률 계산 |
| News Pipeline | **httpx·뉴스 API** | 기사 조회·출처·발행 시각 수집 |
| AI 분석·생성 | **OpenAI Python SDK·Responses API·GPT-5.4 Mini** | 기사 분류·선정 이유·한국어 요약·X 초안 생성 |
| 데이터 검증 | **Pydantic·Python** | 응답 형식, 숫자·날짜·중복·글 길이 검사 |
| 저장·관리자 화면 | **SQLite·Streamlit** | 기사·초안·게시 이력 저장, 개발·테스트 검토와 결과 조회 |
| 예약·게시 | **Windows 작업 스케줄러·X API** | 기존 PC에서 정시 실행, 스레드 게시·결과 확인 |

**OpenAI 활용:** 수집한 기사 → 관련성·중요도 분류 → 한국어 요약 → 문장별 출처 ID를 포함한 구조화 출력으로 받습니다. SDK의 `responses.parse`와 Pydantic을 연결해 일정한 형식으로 처리할 계획입니다.

등락률 계산과 숫자·날짜·중복 검사는 Python이 맡습니다. AI의 재검사만으로 사실 정확성을 보장하지 않고 원자료와 대조합니다. 첫 버전은 SDK로 단계별 호출을 연결하는 단순한 구성을 사용합니다.

## 4. 예산과 예상 월 비용은?

**목표 예산은 월 30,000원, 현재 구성의 부분 견적은 약 21,387원**입니다.

월 22일, 아침 최대 5개 글 + 기업 뉴스 1개 글을 가정합니다. 출처 링크를 모아 하루 URL 포함 글 2개·일반 글 4개로 계산했습니다.

| 항목 | 월 계산 | 예상 비용 |
| --- | --- | --- |
| X 게시 | URL 포함 44개 × $0.200 + 일반 88개 × $0.015 | $10.12 |
| X 결과 조회 | 게시물 132개 × $0.005 | $0.66 |
| OpenAI Mini | 입력 704,000 × $0.75/100만 + 출력 105,600 × $4.50/100만 | $1.0032 |
| 지수·뉴스 조회 / 서버·DB | yfinance·Marketaux 무료 플랜 사용 가정 / 기존 PC·SQLite | $0 |
| **합계** | **$11.7832 × 1,815원** | **약 21,387원** |

환산은 1,500원/USD에 환율 여유 10%·세금 10%를 가정한 **1,815원/USD**입니다. 실제 청구 환율은 아닙니다.

비용을 줄이기 위해 기존 PC와 SQLite를 사용하고, 아침 출처 링크는 마지막 글에 모으며 기업 뉴스는 하루 1건으로 제한했습니다. 지수 수집에 유료 검색 도구는 사용하지 않습니다.

예산 대비 약 **8,613원**이 남습니다. 다만 데이터 공개 이용료·전기·시험·재시도 비용은 미포함이고, 뉴스 무료 플랜의 운영 적합성도 확인 중입니다. **2.1만 원 정액이나 최종 운영 총액으로 확정한 금액은 아닙니다.**
