# 국내 ETF API 표본 검증

- 기준·수행일: 2026-11-01, Asia/Seoul
- 판정: **공개 식별 표본 통과 / 인증 종가·장중 시세·이용 조건 대기**. 시세 API 실응답 통과가 아니다.
- 조건: 사용자에게 한국투자증권 계좌는 있고 Open API 신청은 필요하다. 환경/루트 .env·.env.local에서 알려진 KIS 키 설정을 찾지 못했다. 비밀 값은 출력하지 않았다.

## 11/3 현재 준비 상태

사용자가 Open API 신청과 발급정보의 로컬 `.env` 등록 완료를 알렸다. 실제 값은 기록하지 않는다. 인증 성공·기본3종목 종가 조회·이용 조건 인수는 아직 검증하지 않았으며 다음 작업에서 확인한다. 아래11/1 조건은 당시 관측 이력이다.

## 실제 수행

1. KIS 공식 현재가/일별/종목 파서를 확인했다. [조사·링크](../../../docs/research/국내_ETF_시세.md)
