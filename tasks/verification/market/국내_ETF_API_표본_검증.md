### 거래일·휴장 실제 응답

`BASS_DT=20261030`으로 휴장일 API1회만 요청하고11/3까지의 허용 필드를 보존했다. 조회시각22:53:42.111495 KST. 10/30·11/2·11/3 `opnd_yn=Y`, 10/31·11/1 `opnd_yn=N`이었다. **주말에도 `tr_day_yn=Y`이므로 이 필드만으로 개장일을 판정하면 안 된다.** 공식 예제도 `opnd_yn` 사용을 안내한다. 최신 완료일까지의2개 개장일은 로컬 달력의 완료일11/2·11/3과 일치했다.08시에는 오늘 개장 예정이Y라도 아직 완료되지 않았으므로 그 전 완료일까지 비교한다(무통신 회귀 추가). 공휴일 시점에 실제 조회한 시험은 아니며 주말 휴장 행을 포함한 밤 조회다.

### 계산·공급자 기준 대조

`Decimal`, precision28, `(latest / previous - 1) * 100`, 마지막 표시에서만 `ROUND_HALF_UP` 소수2자리. 분배금·NAV·환율·총수익률을 더하지 않았다. 두 종가의 차이는 각각 -345/-650/+30원이며11/3 행의 `prdy_vrss`·부호와 일치했다. 같은 응답 `output1`의 현재가/전일종가/전일대비율도 위 두 가격과 표시율에 일치했다. 이는 **동일 API 내부의 일관성 대조**이며 HTS 화면·독립 거래소 원본과 별도 대조한 것은 아니다.

모든 실제 행의 `flng_cls_code=00`, `prtt_rate=0.00`, `mod_yn=N`, `revl_issu_reas`는 빈 문자열이었다. 공식 예제의 필드명은 확인했으나 락/재평가 enum 전체 의미·빈 값 해석을 인수하지 않았으므로 `00` 등을 근거로 분배락 없음·직접 비교 적격을 확정하지 않는다. 원종가 계산값은 진단용으로 보존하고 `publishable_change_pct=null`, `event_basis_status=review_required`로 둔다. 실제 분배락/분할일 표본은 이번2일에 입증하지 않았다. 합성 분할/락 시험은 발송용 수익률을 보류하는 동작의 증거다.

## T01 완료 판정과 T02 인계

11/3 사용자 최종 결정으로 가격 보존을90일로 확정했다(이전1년→30일 논의 대체). T01 완료는 유지한다. 운영 가격 스냅샷의 최초 수집/저장시각부터90일이며 같은 스냅샷 재조회로 연장하지 않는다. 편성/발송 payload의 중복 가격도90일 만료·삭제/마스킹한다. 가격 없는 전송 메타데이터/설정 감사는1년이다. 삭제/캐시/복원 후 만료 검사 구현은 T02/T08이며 이 문서의 개발 검증 증거를 운영 DB로 취급하지 않는다.

- **인수한 기술 계약:** 기본3종목 문자열 코드, KRX/KRW·일봉D·비수정1·정확한 완료일2행·양수 Decimal, 날짜/가격시각/조회시각/달력 마감시각 분리, `opnd_yn` 확인, 오류/부분 성공·재시도 경계. [현재 이용 조건](../../../docs/research/데이터_이용_조건.md#2-kis--개인-이용과-제3자-제공).
- **T02에서 이어갈 일:** 제품 어댑터/토큰 만료·동시성/캐시, 거래일 공식 대조·공휴일/특수 개장, 종목 DB/migration/활성10개, 락·분할 enum·빈 값과 실제 사건일 표본·발송용 가격 변동률 채택. 기존 미국 ETF/AM 계약의 완료 근거를 전용하지 않는다.
- **T01 이용 범위 인수:**11/3 사용자가 본인 AWS/비공개 관리자·본인1명 Telegram 경유·가격90일 보관을 허용하도록 결정했다. 개인 이용 조항에 대한 프로젝트 운영 판단으로 채택하며 공급자 별도 명시 허가/회신을 취득했다고 기록하지 않는다. 별도 문의를 T01 완료의 선행 조건으로 두지 않는다. 계정별 한도 구현은 T02, 요금·비용/운영 보존·삭제는 T08에서 확인한다. 무료·무제한 또는 모든 용도의 허용을 확인한 것은 아니다.
- **범위 밖:** 08시 실제 제품 수신 T07, AWS 인수 T08, 선택14/16시 T09. 이번에 송신·배포·커밋/푸시하지 않는다. T02의 DB/합성·수집 구현은 위 잔여 조건과 독립적으로 착수 가능하다.

재현: `uv run python scripts/experiments/kis_market_probe.py --mode check-config`는 무통신 설정 확인, `--mode close --environment real`은 인증/휴장일/시세 실호출이다. 무인 반복 실행용이 아니며 토큰을 저장하지 않아 재실행마다 인증한다. 휴장일 API는 공식 권장1일1회를 지켜 같은 날 불필요하게 반복하지 않는다.
