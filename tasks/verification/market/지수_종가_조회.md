# 지수 종가 조회 구현 계약·검증

- 기준일: 2026-10-24, Asia/Seoul
- 결과: [첫 실제 조회 기록](../../logs/2026-10-24_지수_조회.md) · [오전 도착 시험](지수_오전_도착.md)

`uv run xfolio market-close`는 두 지수 종가·등락률을 표시하고, `--json`은 후속 파이프라인용 구조화 결과를 출력한다. 일반 조회용 API 키는 필요하지 않다.

- 실행 시작 UTC 시각을 기준으로 NYSE·NASDAQ 달력에서 마감한 최근 두 거래일을 고른다. 거래일은 미국 현지 날짜이며 주말·휴장·서머타임·조기 마감은 달력의 UTC 마감 시각으로 판정한다.
- 심볼별 yfinance `history`를 `interval="1d"`, `auto_adjust=False`, `back_adjust=False`, `repair=False`, `rounding=False`로 조회한다. 시작은 직전 거래일, 배타적 종료는 최근 완료 거래일 다음 날이다.
- 같은 완료 거래일에 대한 두 지수의 ID·심볼·이름·종가·직전 거래일/종가·등락률·출처·URL·수집 수단·수집 UTC 시각·달력상 마감 UTC 시각을 보존한다.
- 종가는 `Decimal(str(value))`로 정밀도를 보존한다. 등락률은 `(close / previous_close - 1) × 100`, 표시는 소수 둘째 자리 `ROUND_HALF_UP`이다. 음의 0은 0.00으로 통일하고 JSON의 원본 소수는 문자열로 남긴다.
- 빈 응답·Close 누락·잘못된 날짜·필수 거래일 누락·중복·NaN/무한대/0 이하 가격·통신 오류는 전체 결과 보류와 종료 코드1이다. 낡은 값·장중 값·ETF·다른 지수·AI 추정으로 대체하지 않는다.
- CLI 자동 재시도는 없고 운영 파이프라인의 기존 재시도·마감 제어와 분리한다. 반복 조회는 게시를 만들지 않으며 게시 중복 방지는 Upload Pipeline의 후속 구현이다.
- 달력상 장 마감은 제공처의 확정치 보증이 아니다. 종가 확정 플래그·갱신 시각을 만들어 넣지 않으며 달력의 긴급 휴장 갱신은 운영 전 공식 일정과 대조한다.

외부 API 없는 시험은 정상 계산·휴장·서머타임·조기 마감·누락·잘못된 가격·중복·통신 실패·CLI 출력을 포함한다. 조회 한 번의 성공은 오전 제공 보장이나 X 공개 게시 권한의 확인을 뜻하지 않는다.
