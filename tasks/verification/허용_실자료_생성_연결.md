# 허용 근거의 생성·검증·저장 연결

- 기준: 2026-10-28, Asia/Seoul
- 상태: 초기 연결 구현·모의 단위 시험·격리 PostgreSQL 저장/예산 시험 완료. 외부 실자료 조회·유료 모델 호출·실제 게시 없음.
- 관련: [BLS 기존 범위](BLS_파서와_제공처_채택.md) · [뉴스 선정 사례](뉴스_선정_고정_사례.md) · [MVP 계약](2주_MVP_구현_계약.md)

## 입력·권한 계약

기존 `SourceRecord.permission_scope=bls_public_text`는 BLS CPI 자체 설명문 저장 범위의 근거이며 외부 AI 전송·공개 요약의 전체 허가로 승격하지 않는다. 이번 연결은 기존 BLS CPI `first PRE narrative; tables excluded` 범위만 지원한다. 표·사진·PDF·다른 제공처는 허용하지 않는다. Marketaux는 공개·AI·보관 조건 미확인 상태를 유지한다.

호출자는 `PermissionReview`로 provider·source ID·URL·내용 해시·텍스트 범위, 검토자·정책 근거·검토/만료 시각을 정확히 결합하고 보관·AI 전송·공개 요약의 각 용도를 `permitted`로 확인해야 한다. 누락·다른 버전·만료·미확인은 생성 요청 전에 차단한다. fixture 검토는 실제 자료에 사용할 수 없다. 이 검토 레코드는 실행 설정값이며 코드가 이용 조건을 법적으로 판정한 결과가 아니다.

## 생성·비용·저장 계약

- `GenerationClient`를 주입한다. [OpenAI 어댑터](../../src/xfolio/news_generation.py)는 외부에서 받은 SDK의 Responses `parse`만 연결하고 client/키를 만들지 않는다. `store=false`, `tools=[]`, `reasoning.effort=none`, 구조화 출력과 최대 출력 토큰을 명시하고 SDK 자동 재시도는 0회·timeout은 30초로 제한한다. 외부 주소는 조회하지 않고 입력 URL 식별 검증에만 쓴다.
- 기존 `EvidenceBundle`·`EvidenceClaim`의 source hash·근거 위치·숫자/단위/기간 연결 검증을 재사용한다. 현재 지원 주장은 CPI-U 월간 계절조정·연간 비조정 상승/하락이다.
- 생성 결과는 source ID/버전·모든 claim ID·정확한 근거·한국어 필수 표현·새 숫자를 검사한다. 숫자/표현 검사는 새로운 인과·해석이 없음을 증명하지 못하므로 의미 검토를 남긴다.
- 고정 요청은 payload·instructions·출력 JSON schema의 UTF-8 bytes + protocol overhead 512를 합친 보수적 토큰 상한과 출력 최대 토큰으로 제한한다. tokenizer 실측은 아니며 워크플로와 어댑터가 같은 함수로 요청 전에 검사한다. 유효기간이 있는 토큰 단가를 명시하고 기본 0원으로 두지 않는다. 실제 usage가 예약 상한을 넘으면 정산 완료로 처리하지 않고 예약을 유지한다.
- PostgreSQL의 기존 월 예산 잠금을 공유하고 고정비 예상액(`estimated`)·미정산 예약(`reserved`)·확정액(`confirmed`)을 합산해 요청 최대액을 `usage_ledger`에 먼저 예약한다. 오류·불명 usage는 예약을 유지한다. 유효 usage는 실제 계산액으로 정산하며 잘못된 생성 결과도 비용을 누락하지 않는다. 자동 재시도는 없다.
- SQLAlchemy Core의 기존 `evidence_bundles`·`content_drafts`·`usage_ledger`·`operations_events`만 사용한다. 근거 payload는 관리자 API와 같은 `source`·`url`·`permitted_excerpt`·`fact_version`·`claims`를 사용하며 허용된 주장 근거 발췌만 남긴다. 생성된 단일 뉴스는 아직 완성 편성이 아니므로 publication job은 생성하지 않는다. 초안은 `validation_passed=false`, validation `pending`, `collection_complete=false`, `can_publish=false`로 일치시켜 저장한다. 의미·X 가중 길이·편성 완주 검증 전에는 승인할 수 없다.

## 시험과 실제 확인 구분

단위 시험은 기존 BLS fixture와 합성 생성 응답·fixture 전용 권한 검토만 사용한다. 실제 AI 이용 권한 확보나 실뉴스 모델 품질의 증거가 아니다. PostgreSQL roundtrip은 명시적 `XFOLIO_TEST_DATABASE_URL`의 무작위 격리 schema에서만 opt-in 실행하며 미설정이면 skip한다. 운영 DB나 실제 공급자 key를 사용하지 않는다.

구현은 [생성 연결 모듈](../../src/xfolio/news_workflow.py), [합성 응답](../../tests/fixtures/news_workflow/output.json), [시험](../../tests/test_news_workflow.py)에 있다. 2026-10-28 최종 실행 결과는 **19 passed**(단위 15·격리 PostgreSQL 4)이며 관련 Ruff check/format과 `git diff --check`를 통과했다. PostgreSQL 근거/초안/원장 roundtrip과 estimated/reserved/confirmed 각각의 월 예산 차단을 확인했다. 처음에는 시험 URL 미설정으로 skip했고, 이후 준비된 로컬 PG의 sandbox 접속 차단을 받아 권한이 있는 동일 격리 시험으로 재실행해 통과했다. 모의 비용은 fixture 단가이고 최신 서비스 요금 견적이 아니다.

응답은 `model=gpt-6-luna`, `status=completed`, 엄격한 정수 usage와 지정 스키마를 요구한다. 미완료·다른 모델·추가 필드·잘못된 usage는 오류로 기록하고 비용 예약을 유지한다. SQL 저장 초안은 publication job과 연결되지 않은 `unassembled:` 버전이다. 이 저장 확인을 관리자 승인·발행 가능 E2E 합격으로 보고하지 않는다.

반환 모델 이름은 현재 정확한 `gpt-6-luna` alias만 허용한다. 제공처가 날짜 snapshot으로 반환할 때 prefix만 보고 같은 가격/모델이라고 추정하지 않고 보류한다. 확인된 snapshot의 명시적 대응표는 실제 호출 전 별도 검토 사항이다. [어댑터 시험](../../tests/test_news_generation.py)은 SDK 대역으로만 수행하며 실제 유료 호출은 하지 않았다. 어댑터 18건을 포함한 최종 통합 재실행은 **37 passed**(단위/SDK 대역 33·격리 PostgreSQL 4)다. 월 총비용의 실제 확인이 부족한 상태에서 어댑터 구현을 유료 실행 허가로 해석하지 않는다.

## 남은 일

실자료별 권한 검토·유효 단가 확인, 실제 모델 adapter의 제한 준수, 의미/길이/편성 검증, reviewed 정상 E2E가 후속이다. 이 연결로 Marketaux 단일 공개 운영이나 BLS 범위 확대를 확정하지 않는다.
