## 공통 구현 계약

`src/xfolio/analysis.py`의 `analyze_synthetic`이 source ID·원문·필수 표현을 받아 Structured Outputs의 선정 여부·이유·한국어 요약·근거를 반환한다. 응답 완료, 출처 ID 일치, 근거의 원문 연속 부분 문자열, 필수 기간/수치, 보류 시 빈 요약, 새 숫자 금지, 한국어 포함을 기계 검사한다. 실패·API 오류는 보류하며 API 오류 본문/키를 출력하지 않는다. usage의 입력·출력·캐시 읽기·쓰기와 공시 단가로 비용을 추정한다. `store=False`·도구 없음·자동 재시도0·`reasoning.effort=none`이다.

`xfolio ai-preview`는 기본 무통신이고 `--run` 때도 고정 가상 자료만 분석해 `build_morning_preview`로 전달한다. 모델 결과와 원문·기준 시각 검증을 통과한 뒤에도 결과는 `synthetic=true`, `can_publish=false`, `dry_run`이다. 가상 1건 실제 연결 시험은 Luna 사용량 384입력/137출력, 약 $0.0001069, 2글 미리보기 `ready`였다. 첫 글은 두 지수, 둘째 글은 가상 뉴스와 원문 링크다. 영문 가상 기관명이 한국어 문장에 남아 문안 다듬기가 필요하다. 이것은 발행 승인이나 실기사 파이프라인 완성이 아니다.

## 같은 6건의 Mini·Luna 비교

두 모델 모두 동일한 `synthetic_summary_v2_scope_conditions` 지침, 입력, `reasoning.effort=none`, 최대 출력600, 도구 없음으로 1회씩 실행했다. 4선정·2보류의 기대값과 출처/숫자/근거 기계 검사에 각각 6/6 통과했다. 양쪽 모두 캐시 읽기·쓰기0이었다.

| 모델 | 입력/출력 토큰 | 실측 usage 단가 적용 | 6건 순차 지연 합 | 사람의 문안 대조 |

| GPT-5.4 Mini | 2,262 / 761 | $0.0051210 | 12.371초 | 수치·기간·업종 범위·조건 보류 유지. 영문 고유명사·`USD million` 표기 잔존 |

Luna의 **이 6건 비용은 약89.4% 적었다.** 표본이 짧은 가상 기사이므로 통계적 품질 우위나 실제 기사·장문 비용을 보장하지 않는다. 의미 검토는 에이전트의 원문 대조이며 운영자 승인 완료가 아니다. 이 시험 당시에는 실제 기사 공개 이용·외부 AI 전달 권한, 정정/여러 기사 충돌/기업 중요도 순위, X 문체를 더 검증하기 전 모델 변경을 보류했다. 이후 사용자 결정으로 기본 모델을 Luna로 확정했으며 실기사 품질 검증은 남았다.

## 공식 발표 직접 조회와 Web search

같은 과거 사건인 [BLS 2026-09 CPI 10월14일 발표](https://www.bls.gov/news.release/archives/cpi_10142026.htm)를 비교했다. 이는 10월23일 아침의 신규 뉴스 후보라는 뜻이 아니다.

| 방법 | 실제 관측 | 이번 OpenAI 비용 추정 | 운영상 판단 |
| --- | --- | ---: | --- |
| BLS 원문 직접 HTTP GET | HTTP 200, 1,373,525 bytes. 날짜와 12개월 3.7%·전월 0.6% 문자열 발견 | $0 | 정해진 발표 일정과 원문 URL로 직접 수집 추천. 이번 시험은 문자열 존재 확인이며 안정적인 본문 파싱·정정 감시는 미구현 |
| Luna `web_search`, `bls.gov` 제한 | 1도구 호출, BLS 원문을 인용하고 두 수치를 정확히 반환. 8,598입력/157출력, 그중 캐시 쓰기4,393 | 도구 $0.01 + 토큰 $0.001048125 = **$0.011048125** | 예외적 발견/교차 확인에만 제한 추천. 다수 검색 출처 반환이 전체 발표 포착을 보장하지 않음 |

검색 토큰 산식은 `(4,205×$0.10 + 4,393×$0.125 + 157×$0.50)/100만`이다. [Luna 단가](https://developers.openai.com/api/docs/models/gpt-6-luna)와 [Web search 도구료](https://developers.openai.com/api/docs/pricing)를 사용한 추정이며 청구서 확정액은 아니다. 응답 1회에서 검색 도구 1회가 관측됐다. 도구 호출이 늘거나 검색된 본문이 길어지면 비용도 늘어난다. 같은 공식 발표의 직접 조회는 OpenAI 비용이 없지만 HTTP 전송·파서 유지·사이트 변경 대응은 필요하다. BLS CPI의 일정은 [공식 발표 일정](https://www.bls.gov/schedule/news_release/cpi.htm)에서 확인한다.

## 판정

고정 공식 거시 발표는 일정+원문 직접 조회를 1순위로 구현하고, 검색은 누락 또는 원문 위치 확인 때만 별도 예산 안에서 사용한다. Marketaux 기업·거시 뉴스의 근거 부족 및 공개 이용 범위 문제를 이 한 건의 BLS 시험으로 해결했다고 보지 않는다. 가상 공통 AI 경로는 연결됐지만 실기사 입력은 권한·근거 검증 전까지 차단한다. **Luna 모델 선택은 확정**됐고 더 다양한 허용 표본의 사람 검토는 게시 전 품질 검증으로 남는다. 월 산식은 [월 비용](../../../docs/research/월_비용.md)에 구분해 반영한다.
