제휴안내

제휴대상

KIS Developers 오픈 API 서비스를 활용하여 제3자에게 서비스를 제공하고자 하는 법인

「자본시장과 금융투자업에 관한 법률」에 명시된 금융투자업 등에 따른 업무의 범위를 주의하시길 바랍니다. 제3자 서비스 제공 목적이 아닌 법인 소유 계좌를 통한 KIS Developers 서비스 이용은 제휴없이 사용 가능합니다.

제휴 대상 여부를 먼저 확인하시고, 대상에 해당하시면 아래 제휴 제안 등록을 통해 문의를 접수해 주시기 바랍니다.

[제휴 대상고객]

제도권금융회사 : 투자일임업, 투자자문업 (고객 대상으로 한국투자 오픈API를 활용하여 서비스를 제공하고자 하는 제도권금융회사)

  • 서비스 이용방법 : 좌측 제휴 제안 등록, 제도권금융회사(투자일임업, 투자자문업)이 아닌 경우 제휴 불가(ex. 핀테크사)

[제휴 대상이 아닌 고객]

개인고객 (개인 본인 자산으로 자기만의 전략을 통하여 매매를 하고자 하는 개인고객)

  • 서비스 이용방법 : 한국투자 홈페이지에서 서비스 신청 (신청방법 가이드 : 소개 > 서비스 이용안내)

일반법인고객 (법인 본인 자산으로 자기만의 전략을 통하여 매매를 하고자 하는 법인고객)

  • 서비스 이용방법 : 한국투자 홈페이지에서 서비스 신청 (신청방법 가이드 : 소개 > 서비스 이용안내)

제휴법인 이용고객 (제휴업체가 한투 API를 이용하여 제공하는 서비스를 이용하는 제휴업체 등록고객)

  • 서비스 이용방법 : 제휴업체의 앱 혹은 홈페이지에 접속하여 서비스 신청

제휴 유의사항

[시세 API]

  • 시세정보 API 이용의 경우, KRX 및 해외거래소와의 정보이용계약을 체결하셨는지 확인을 부탁드립니다.
  • 오픈API 서비스 개발시 거래소(코스콤)에 질의 할때는 제휴사가 한국투자증권 계좌 보유 고객에 한하여 API 시세 제공이 가능하다고 확인하였으나 최근 거래소(코스콤)에서 법인(제휴사)이 시세정보 이용시 사전에 코스콤과 정보이용계약 체결이 안 되어 있으면 API를 이용해서 제휴사 브랜드 어플리케이션(또는 앱)화면으로 시세정보를 이용하는 것도 불가하다고 통보를 받았습니다.
  • 따라서 제휴기관은 KRX 및 해외거래소 시세정보를 이용하려는 경우 KRX 또는 해외거래소와 정보이용계약이 필요합니다.

[주문 API]

  • 주문 API를 이용하고자 하실 경우, 제도권금융회사(투자일임업)여부 확인을 부탁드립니다.
  • 제도권금융회사 조회: https://fine.fss.or.kr/fine/fncco/systemFncCo/list.do?menuNo=900038
  • 제도권금융회사(투자일임업), 제도권금융회사(투자자문업), 비제도권금융회사에 따른 주문 프로세스가 상이한데, 비제도권금융회사일 경우 프로세스가 굉장히 까다롭습니다.
  • 따라서 비제도권금융회사에 해당하실 경우, 우선적으로 혁신금융서비스 신청을 하시는 것을 권유드립니다.
  • 혁신금융서비스 신청: https://sandbox.fintech.or.kr/apply/apply_service.do
