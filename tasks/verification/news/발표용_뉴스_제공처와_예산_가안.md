## 제공처와 게시 범위

아래 범위는 기존의 뉴스 제공처 1곳·관찰 기업 10개 요구를 좁히는 **변경 제안**이며, 기준 문서의 요구사항을 이미 바꾼 것은 아니다.

초기에는 **BLS 공식 CPI + SEC EDGAR의 NVIDIA·Apple·Microsoft 실적 공시**를 사건의 1차 근거로 제안한다. 같은 세 과거 사건의 `8-K Item 2.02`와 `EX-99.1`을 SEC에서 **3/3 확인**했고, [SEC는 공개 공시 재이용과 인증 없는 JSON API를 안내](https://www.sec.gov/about/webmaster-frequently-asked-questions)한다. Marketaux는 개발용 수집기가 있고 MarketNewsAPI Free는 인증 조회를 했지만, 두 곳 모두 초기 범위의 단독 공개 운영 피드로 채택하지 않는다. MarketNewsAPI는 같은 발표의 제한 조회에서 1/3만 발견돼 **Pro 월 $15 가입을 보류**한다. SEC 자동 폴링·수정/중복·아침 도착은 아직 검증·구현되지 않았다. 회사 IR 웹페이지의 일괄 자동 수집도 이용 조건상 채택하지 않는다.

아침은 S&P 500·Nasdaq-100 두 지수 요약 1글을 기본으로 한다. CPI 등 검증한 중요한 변화가 있는 날만 원문 링크를 단 최우선 뉴스 1글을 추가한다. 반복적인 AI 총평은 생략한다. 추가 기업 뉴스는 위 세 회사의 **실적 공시부터** 평가하며 **하루 최대 2글**이다. 근거가 불충분하면 0글이다. 사업 변화·기존 10개 기업과 광범위한 거시·업종 뉴스 감시는 이후 단계다. 두 지수 편입은 시점이 있는 공식 자료로 확인했으며 운영 직전 재확인한다.

지수 수집·BLS CPI 파서·가상 뉴스 미리보기·Neon의 가상 자료 왕복에 더해 **SEC 실적 공시 사실 카드 3건의 OpenAI 한국어 비게시 미리보기**를 시험했다. 실제 SEC 자동 수집기, 수집 결과의 AI 연결, 관리자 승인, 클라우드 예약, X 게시·결과 조회는 미완료다. 5운영일 관측은 후속 검증이지 내일 발표의 전제 조건이 아니다.

## 비용 재계산: 월 22거래일·최대 4글/일

계획 환산은 `1 USD = 1,815원`(환율·세금 여유 가정)이다. [X API 생성·조회 단가](https://docs.x.com/x-api/getting-started/pricing)와 **확정 모델 [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)**에 기존 월 입력704,000·출력105,600토큰 가정을 적용한다. X `$13.97` + Luna `$0.1232` = `$14.0932`, **약 25,579원/월**이다. SEC 유료 API 구독료는 0원이나 자동 수집 개발·운영 비용은 별도다. 기업 뉴스가 실제 하루 평균 1글이면 게시 X 비용 `$4.51`이 감소해 **약 17,394원**이다. 이는 매일 최대 글 수를 채운 견적과 다른 시나리오다. 세 역사적 사실 카드의 이전 Mini 실제 비용 **$0.001782**는 Luna 월 토큰 가정을 대체하는 월 측정값이 아니다.

클라우드 시나리오는 수집 484회 + 게시 큐 확인 2,904회 + 백업 30회 = **3,418 Cloud Run Jobs 실행/월**이다. `us-central1`, 매회 1 vCPU·1 GiB, 자동 재시도 0, 무료 몫을 다른 작업과 공유하지 않는 조건이다. [Cloud Run Jobs](https://cloud.google.com/run/pricing)의 최소 60초 과금, CPU 240,000 vCPU-초·메모리 450,000 GiB-초 무료, 초과 CPU `$0.000018/vCPU-초`·메모리 `$0.000002/GiB-초`를 적용했다.

[Scheduler](https://cloud.google.com/scheduler/pricing)는 결제 계정당 예약 3개 무료이며, [Neon Free](https://neon.com/pricing)는 프로젝트당 100 CU-hours·1GB이다. `0.25 CU × 11시간 × 22일 = 60.5 CU-hours`는 무료 범위 안이라는 가정이지 실제 관측이 아니다. 상시 0.25 CU로 30일 돌면 180 CU-hours여서 무료 범위를 넘는다. [Streamlit Community Cloud](https://docs.streamlit.io/deploy/streamlit-community-cloud)의 비공개 관리자 앱은 본인 로그인·가상 자료 저장을 확인했으나 실제 승인 기능은 후속이다. 이미지·레지스트리·로그·Secret Manager·전송·백업·재시도·무료 몫 공유와 계정별 X 단가는 별도다. GCP 예산 알림도 자동 지출 차단은 아니다.

**예산 제안:** 기존 확정 상한 **30,000원**은 최대 게시+전 작업 120초 시나리오부터 넘는다. 유료 뉴스 피드를 제외한 좁은 1차 범위라면 **45,000원/월을 임시 계획 상한으로 제안**한다. 전 작업 180초 가정보다 약 6,562원 남지만 미계측 항목을 보장하지 않는다. **65,000원은 현재 범위에 필수인 지출이 아니라**, 유료 제공처 재평가나 사용량 증가 시 다시 검토할 상위 시나리오다. 어떤 상한도 사용자 승인·실제 사용량 제한 구현 전에는 운영의 확정 예산이 아니다. Streamlit 비공개 관리자와 Neon의 가상 자료 왕복은 확인했으나 Cloud Run job·예약과 X API는 실행 전이라 **실제 실행 시간·청구액은 읽을 수 없다**. X는 [Developer Console의 spending limit](https://docs.x.com/x-api/getting-started/pricing)을, GCP는 [Cloud Run 대상 spend cap의 서비스별 적용 범위](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps)를 배포 시 확인한다.

비교용으로 MarketNewsAPI Pro를 추가하면 최대 게시+작업 60초는 약 52,804원, 전 작업 120초는 약 58,363원, 180초는 약 65,663원이다. **이 안은 현재 추천하지 않는다.**
