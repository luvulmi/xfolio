## 수행한 범위

사용자가 Marketaux·MarketNewsAPI·Exa 키를 `.env`에 직접 저장한 뒤 비밀값을 출력하지 않고 로딩을 확인했다. 다음을 실행했다.

- Marketaux·MarketNewsAPI 뉴스 GET **16회**, MarketNewsAPI usage GET **2회**. 최초 비교12회+Intel 발표 후4회, 조회당3기사·각2페이지. 모두 무료 한도 안의 제한 표본이다.
- Exa Auto 검색 **3회·15결과**와 캐시 전용 Contents **1회·2페이지**. 응답 `costDollars.total` 합계 **$0.023**(계획 환율 약42원), 무료 크레딧 차감/실제 청구 잔액은 콘솔 미확인이다.
- 최초 제한 환경에서 각 스크립트의 연결이 실패한 뒤 허용된 네트워크 실행으로 재시도했다. 성공 HTTP 호출 수와 전송 전 연결 실패를 구분한다. API 자동 재시도0, 별도 OpenAI 생성0·X 게시0·결제0이다.
- 기사 본문은 메모리에서 제한 구간만 검토했다. 파일에는 URL·ID·시각·문자수·요청 조건·비용/한도 등 메타데이터만 저장했다. MarketNewsAPI body는 길이만 검사하고 내용은 읽지 않았다.

## 실제 API 응답 비교

고정 UTC 창은 `2026-10-28T00:00:00Z`~`2026-10-30T08:00:00Z`다. Intel 추가 비교는 시작을 공식 발표 `2026-10-29T20:01:00Z`로 좁혔다. Exa는 같은 사건·기간의 자연어 질의를 사용했으며 기존 두 API와 질의/검색 알고리즘/상위 결과 수가 달라 통제된 순위 성능 시험은 아니다.

| --- | --- | --- | --- |
| 초기 표본 | 18행·18ID, snippet 대체로161~163자 | 18행·16ID, 페이지 경계 ID 중복. summary 일부 없음/제목 반복 | 15행·15URL, text 297~20,000자, 4건은 지정 상한20,000자 도달 |

Marketaux 본문 검색과 `+` AND, MarketNewsAPI title/summary/snippet 검색의 차이가 있다. 후자의 다중 단어 AND 의미는 명확히 확인되지 않았다. 모든 기존 질의는2페이지 뒤에도 다음 페이지가 있어 `partial`이며 시장 전체 누락률을 산정하지 않는다. Marketaux 최종 헤더 잔여92/100, 플랜명 미노출. MarketNewsAPI Free100/day·15분 지연, 추가 비교 전 usage6/잔여94였다.

### Exa CNBC와 공식 발표 대조

[CNBC](https://www.cnbc.com/2026/10/29/intel-intc-q3-earnings-report-2026-.html) 캐시5,706자에서 발행10/29 16:04 EDT·수정20:39 EDT, 조정EPS52센트, 매출16.51B, Q4매출15~16B·조정EPS25센트를 확인했다. 공식 발표의 요약 매출16.5B와는 반올림 정밀도가 다르며 공식 원표의16.51B 대조는 미완료다. 조정EPS .52와 Q4전망 범위·EPS .25는 검색으로 반환된 공식 IR 요약과 일치한다. GAAP EPS .60과 혼동하지 않는다.

CNBC 예상EPS40센트와 MarketNewsAPI Zacks39센트는 불일치한다. 집계 제공처·갱신시각이 다를 수 있어 한 값을 정답으로 선택하지 않는다. API의 발행일 필터는 본문의 당시 버전 보장이 아니다. Exa가 반환한 Intel IR `00:00Z`는 원문16:01 EDT와 다르므로 정밀도 미확정 시각으로 처리한다.

**판정:** Exa는 사건 발견과 수치/맥락 근거 확보에 유망해 개발 채택했다. 이번 결과는 제한 표본 통과 근거이며 전체 기사 품질·실시간 도착·정시 편성·공개 이용의 합격 판정은 아니다.

## 실행한 기존 두 API 시험 조건

동일 UTC 창 `2026-10-28T00:00:00Z`~`2026-10-30T08:00:00Z`를 고정한다. 10/30 실행 기준 최근 7일 안이며, 실행이 늦어지면 무료 이력 범위와 다시 대조한다. 미래 시각이나 비교 중 바뀌는 `now`는 쓰지 않는다.

| 사례 | 같은 검색 개념 | 필수 판독 |
| --- | --- | --- |
| 시장 | `Alphabet` + `stocks` | 10/29 정규장 마감인지 장전/전망인지, 지수 종류·시각, 사건 동일성 |
| 업종 | `semiconductor` | 미국 반도체 업종 사건의 주체·발행일, 시장 일반 기사와 독립된 사건 여부 |
| 기업 | `Intel` + `earnings` | Q3 실적/Q4 전망, GAAP 구분, 수치 근거가 제목 밖에 있는지 |

- Marketaux: `/v1/news/all`, search·언어 en·동일 발행창·관련도 정렬·group_similar=false, 요청당 3기사.
- MarketNewsAPI: `/v1/news`, q·category=stocks·type=news, 동일 from/to·sort=relevance, 요청당 3기사. 공식 문서는 검색 범위를 title/summary/snippet이라고 설명한다.
- 각 사례 최대 2페이지 × 3사례 × 2제공처 = **최대 12회 뉴스 조회**, 계정 한도 조회 별도. 계정 플랜·잔여 확인 후 실행하며 유료 overage는 사용하지 않는다. 401/403/429는 중단하고 다른 키로 우회하지 않는다.
- 알려진 사건을 찾는 표본이므로 독립 신규 탐지율·전체 누락률은 측정하지 않는다. 검색 의미가 같은지 확인하고 API 검색 문법 차이를 기록한다. 수치 정답을 검색어에 넣지 않는다.
- 저장: URL·출처·ID·시각·필드 존재/문자수·다음 페이지 유무·호출 수·판독 결과. 비밀값·기사 전문·전체 발췌 저장 제외. 문자열 일치만으로 사실 합격을 판정하지 않는다.
- 발견·근거 충분성·공개 권한은 별도 판정. partial 표본을 전체 수집 완료로 세지 않는다. 실패·정상 0건·관련 기사 부재·근거 부족을 구분한다.

## 게시량별 월 예산 비교

뉴스 최대2건+지수1건은 사용자 확정이며 아래1/4건은 민감도 비교다. 22게시일, 지수 1글/일, 링크 뉴스 N글/일, 결과 확인 1회/글, 환산 $1=1,815원을 사용한다. X 일반 글 $0.015·URL 글 $0.20·읽기 $0.005와 Lightsail Linux IPv4 1GB $7 / 2GB $12는 이번 공식 페이지에서 재확인했다. Owned Reads 할인은 실제 endpoint와 소유 조건 검증 전이라 적용하지 않는다.

기존 AI 추정 $0.176 대신 **비교용 월 AI 예산 $2**를 배정한다. 새 뉴스 처리 실측·운영 한도 적용을 뜻하지 않는다. 세금·환전·재시도를 위한 **10% 예비액**은 비교 가정이며 정확한 세율이 아니다. 도메인·백업·초과 전송 등 실비는 여유 안에서 별도 산정한다.
