## 입력·시각·이용 범위

- 기준 시각은 timezone-aware UTC로 고정하고 KST로 표시한다. 제품 기준은 월~금 중 한국 거래일07:50이며 CLI 진단 시각과 실제 정시 관측을 구분한다. 발행≤기준, 조회/본문 확보≤편성 완료 시각을 검사한다. 날짜만 있는 발표를 자정으로 추정하지 않는다.
- Finnhub Free general은 서버 인증 헤더로1GET, 기존 CNBC/Reuters 미국 관련성·의견/암호화폐 제외·안전한 직접 기사/Google HEAD 검사 재사용. 본문·이미지·summary 필드를 AI/DB/로그에 전달하지 않는다. redirect별 호스트/기사 경로를 검사하고 요청 상한·timeout·자동재시도0회 유지.
- BLS CPI는 기존 원문 파서 재사용. BEA RSS 자체 GDP/개인소득·소비 발표, Board monetary RSS 자체 FOMC 성명을 직접 수집한다. 기관별 고정 HTTPS 호스트/경로만 허용, redirect/외부 기고/제3자 저작권 표시/미확인 시각·절단·미지원 형식은 제외한다. RSS 발견 완료와 시장 전체 포괄을 구분한다.
- 자체 텍스트만 AI 입력에 허용한다. 원문은 메모리만 사용하고 DB는 출처/URL/발행·조회/해시/사건·요약 등90일 메타데이터를 저장한다. 원문/발췌를 추가 보관할 때는 별도7일 상한 계약을 따른다.

## 선정·오류·기발송

- 최근24h와 직전 성공 발송 이후 미전달 최대96h의 후보를 중요도순으로 선정한다. 점수·키워드·동점 순서·예시·한계는 [뉴스 중요도 기준](../../../docs/뉴스_중요도_기준.md)으로 모았다. 구현은 점수/이유/버전 저장·제목과 다른 점수 거절·HEAD12회 중요도순을 검증한다. 전체최대3건·사건당1건이며 ID/정규URL/정규제목/지원 사건 키 중복을 검사한다. [11/5 구현·실측](../../logs/2026-11-05_뉴스_중요도와_로컬_실행.md).
- 각 출처 complete/partial/failed와 제외 사유를 보존한다. 모든 필수 출처 complete인 선정0건과 수집/요약 실패를 구분한다. 일부 실패여도 정상 후보를 반환하되 상태를 낮춘다. 오류 본문/인증값은 출력하지 않는다.
- 수집·미리보기만으로 발송 완료를 기록하지 않는다. 본인 수신자 범위의 confirmed만 기발송으로 간주하고 failed/unknown은 성공으로 바꾸지 않는다. T06이 실제 성공 결과를 기록하도록 저장 경계를 제공한다. 동시 발송 점유·outbox는 T06이다.
- 새0004 migration으로 기존0001~0003을 보존한다. 중복 저장이 최초 저장/만료를 연장하지 않으며 조회 시 만료 차단·삭제를 검증한다. 운영 DB에는 적용하지 않는다.

## 공식 발표 요약과 검증

- BLS CPI 월/연 비교·기간, BEA GDP 추정 차수/분기 또는 PCE 월/연 비교·기간, FOMC 목표금리 범위/행위를 명시적으로 추출한다. 근거 원문에 없는 수치/인과/투자 조언은 허용하지 않는다. 구조화 AI 응답은 근거 ID/내용 버전과 허용 사실 문형을 코드로 대조한다.
- Responses 구조화 출력·store=false·도구 없음·timeout/자동재시도0회. 모델은 기존 gpt-6-luna 유지. 단가 유효기간·입출력 상한·월 예산 예약 후 호출하고 실패/비용 불명은 예약을 유지한다. 새 실제 가격이나 유료 호출 성공을 합성 검증으로 대신하지 않는다.
- 외부 API 없는 MockTransport/합성 fixture로4출처·절단/권리/날짜·24/96h·중복/정정·0건/부분/실패·일반 AI 차단·생성 숫자/기간/조건·예산/응답불명 시험을 수행한다. PostgreSQL에서0004 업/다운·기발송·멱등/만료를 검증한다.
- 실제 무료 자료 조회는 성공/실패와 요청시각/횟수/해시·최소 집계만 기록한다. 실제 유료 요약/제품 아침 수신·AWS 운영은 별도 인수다.
