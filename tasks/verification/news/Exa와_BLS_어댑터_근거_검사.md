## N08 수집 계약

- Exa 고정 HTTPS `/search`와 `/contents`, x-api-key 헤더, auto/news를 쓴다. 리다이렉트·자동 재시도는 끈다. 키·외부 오류 본문·요청/응답 전체를 결과/오류에 싣지 않는다.
- 기본 질의는 미국 시장·업종·10기업 우선+목록 밖 중요 사건 3범주다. version·query ID·기간·도메인·결과 상한·본문 상한을 typed 설정에 보존한다. 검색 창은 UTC [start,end]의 제공처 필터이며 날짜/미확인 시각은 후보 검사에서 별도 보류한다. 미래 창/7일 초과는 거절한다. 각 5결과·본문 20,000자는 개발 기본값이지 포괄률 보장이 아니다.
- 검색에 text를 요청하고 본문이 없는 발견 URL은 조건부 필수 Contents scope에 모아 캐시 전용(maxAgeHours=-1)으로 보완한다. URL별 statuses와 결과를 모두 대조하고 누락/실패를 partial로 남긴다. 빈 검색은 Contents를 호출하지 않으며 필수 검색 모두 완료 시 정상 0건이다.
- 같은 원문 URL/본문 버전은 한 입력으로 합치고 원매체는 URL hostname으로 표시한다. URL이 다르면 같은 사건으로 추정하지 않는다. 같은 URL에서 다른 본문/발행 표현이 발견되면 충돌을 기록해 partial로 남긴다. 새로운 본문/정정은 기존 버전을 덮어쓰지 않는다.
- API의 publishedDate는 원래 표현을 보존하되 자동 verified로 올리지 않는다. 날짜만/자정/알 수 없는 정밀도를 구별하며 원매체 기사 유형은 unknown이다. 본문은 not_assessed이고 상한 도달은 절단 의심으로 남긴다. API text가 있다는 사실은 본문 충분 판정이 아니다.
- text가 title과 정확히 같으면 title_only를 표시한다. 나머지 제목 의존·문맥·절단의 의미 판정은 별도 검토가 필요하다.
- 실행별 요청 수와 응답 USD 한도를 둔다. 다음 요청의 설정된 비용 여유를 확보한 경우만 전송하고 한도 도달·402/429·인증 실패·비용 불명/초과는 후속 요청을 중단한다. 이 여유값은 호출자가 검토할 보수적 가정이며 제공처 청구 상한이나 월 예산 원장을 보장하지 않는다. 응답 비용을 기록하고 누락값은 null로 유지한다.
- 기본값은 최대 6요청, 응답비용 $0.10, 다음 요청 여유 $0.02다. 실제 단가를 보장하는 값이 아니다. 결과의 configuration에 전체 설정을 보존하고 query_version에 질의/도메인/결과/본문 상한 fingerprint를 붙인다. 이전 레코드를 명시 주입하면 같은 본문은 최초 조회/확보를 보존하고 새 본문은 supersedes로 연결한다. 발행 표현 변화도 충돌로 보류한다.
- 수집 collection 권리 검토가 없거나 만료되면 외부 요청 전에 거절한다. storage/ai_transfer/summary_publication은 독립 상태로 유지한다. 합성 fixture도 실제 허가로 승격하지 않는다.

## N03 BLS 연결

기존 CPI 첫 PRE 설명문 파서를 재사용한다. 원래 발표 표현·America/New_York/UTC·기간·전월 계절조정/12개월 비계절조정 두 주장·근거 hash를 보존한다. 공통 레코드와 사실 payload를 연결하고 기존 CPI 전용 모델은 유지한다. 지원 문형이 아니면 충분성 부족이며 값을 추정하지 않는다. 같은 사건의 본문 변화/정정은 새 hash·supersedes·change_reason으로 보존한다. 최초 확보 시각은 같은 버전 재확인으로 바꾸지 않는다.

최신 CPI와 일정 조회는 각각 필수 scope다. 예정 발표가 지났는데 최신 본문이 해당 기간에 도달하지 못하면 partial이다. 일정 실패에도 확보한 본문은 보존한다. complete은 최신 snapshot/일정 대조만 의미하며 과거 기간 전체 발표 수집이나 커서 전진이 아니다. 입력 창 밖 최신 자료도 감사 목적으로 유지하고 후보 검사에서 제외한다.

## N09 후보 검사

순수 함수로 입력과 사실 후보를 검사하며 결과는 항상 can_publish=false·human_review_required=true다. 확인된 발행 시각·확보 cutoff·권리/만료·본문 충분성/상한/제목 의존·기사 유형·근거 hash/구간을 독립 검사한다. AI/게시 전 목적별 이용 상태를 명시한다.

주장은 claim_id·주체/행위·사건 유형·기간 또는 사건 시각·값/범위·단위·비교기준·확정/회사전망/애널리스트예상·GAAP/non-GAAP·조건·근거 구간을 가진다. 숫자 일치만으로 의미를 승인하지 않는다. 값/범위와 조건이 해당 구간에 없거나 기간/비교/회계 기준이 빠지면 거절한다. 의미 주체/기간/부정의 실제 대조는 운영자 책임이다. 시장 관련성·중요도 자동 추출/AI 생성은 이번에 추가하지 않는다.

출처를 제외한 사실 payload로 fact_version을 계산하고 사건 식별은 명시적 subject/event_type/identity를 사용한다. 같은 사건·사실은 duplicate, 사실 변화는 재검토, 승인된 근거의 정정은 hold다. 중복 기사와 동일 사건의 중요 후속 사실을 구별하며 URL이나 제목으로 사건을 자동 판정하지 않는다.

`NewsClaim`/`NewsFacts`는 parser·manual_review·ai_candidate의 사실 후보이며 관련성/중요도나 사람 승인 결과를 자동 부여하지 않는다. earnings는 GAAP/non-GAAP 필수이고 근거 구간의 정확한 표기를 대조한다(예: GAAP를 non-GAAP 내부 부분 문자열로 인정하지 않음). 숫자의 정규화된 값/범위·회사 전망/애널리스트 예상·조건을 사실 버전에 포함하고 출처/근거 위치·숫자 뒤 0의 표기 차이는 버전에서 제외한다. 승인된 source 변경은 충분성/권리 탈락보다 먼저 hold를 반환한다. 후보별 판정과 collection.status는 별개이며 partial/failed collection의 AM 전체 보류는 A04에 연결해야 한다.

## 검증과 근거

MockTransport·합성 응답·기존 BLS fixture로 정상/0건/부분 실패/비정상응답/예산/키 반향·시각/권리/근거/중복/정정을 검증한다. 외부 API와 운영 DB를 요구하지 않는다.

Exa 형식 확인: [Search](https://exa.ai/docs/reference/search), [Contents](https://exa.ai/docs/reference/get-contents). 2026-10-31 공식 문서의 POST·날짜/도메인 필터·contents·statuses·costDollars와 캐시 전용 옵션을 대조했다. 본문 반환과 공개 요약/AI 허가는 별개이며 [기존 이용 조사](../../../docs/research/뉴스_수집.md)의 미확정 상태를 유지한다.
