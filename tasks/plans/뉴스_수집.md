## 후속 공식 자료

Fed FOMC·BEA PCE·SEC 10기업 8-K 실적/M&A는 [기존 설계](../../docs/specifications/공식_발표와_공시_수집_설계.md)를 유지하되 핵심 일정에서 제외한다. SEC 착수 시 공식 법인명·CIK·표본·연락처·시작일을 대조한다. 20기업 확장은 삭제 상태다.

기존 Marketaux 수집기·BLS 파서·SEC 사실 카드는 재사용 자산과 이력이며 Exa 제품 완료가 아니다. [이전 계획](../../docs/archive/official_sources_transition/작업_계획_뉴스_수집.md). 반복 관측은 [종료](../logs/2026-10-29_반복_관측_종료.md) 상태를 유지한다.

공개 이용 확인은 이 작업에서 계속 관리한다. API 선정·기존 실측은 보관된 조사 계획과 표본 기록을 참조하며 별도 일정표를 복제하지 않는다.
