# 공식 발표·SEC 공시 수집 구현 계획

- 기준: 2026-10-30 · 상태: 범위 확정, 구현 전
- 수집은 Fed/BLS/BEA/SEC, 요약은 실적·M&A·정책·주요 지표다. SEC는 10개 기업으로 제한한다. 20기업 확장은 삭제한다.
- 기준: [요구사항](../../docs/요구사항.md) · [수집 설계](../../docs/specifications/공식_발표와_공시_수집_설계.md) · [WBS](../../docs/planning/작업_분해_WBS.md)

## 남은 작업

- [x] 10기업 구성과 FOMC·CPI·PCE·8-K 실적/M&A의 초기 범위를 확정한다.
- [ ] [확정 기업](../../docs/요구사항.md#sec-10기업)의 공식 법인명·CIK·공시 표본·감시 시작일을 대조한다.
- [ ] 기관별 최소 발표 종류·범위/커서·호출 제한·시간/정정/해시·이용 검토 계약을 구현한다.
- [ ] BLS CPI를 재사용하고 Fed FOMC 성명·BEA PCE·SEC 8-K 실적/M&A의 추출을 구현한다. 고용·GDP는 후속이다.
- [ ] source/record와 event/fact를 분리하고 단위·기간·회계/거래 상태·근거를 보존한다.
- [ ] Fed·BLS·BEA·SEC와 기업 10개의 수집 완료/정상 0건/partial/실패·수정/삭제·권리 차단을 오프라인 시험한다.
- [ ] 실제 자료→사실 후보→AI 초안→관리자 근거 대조→버전 승인→모의 결과를 연결한다.
- [ ] 요청량·처리 시간·지원하지 않는 문서와 실제 인수 범위를 기록한다.

## 재사용과 이력

BLS CPI 파서·사전 검토 기반 선정/생성·SEC 사실 카드 3건 시험은 재사용 후보이며 Fed·BLS·BEA·SEC의 제품 수집 완료가 아니다. [이전 뉴스 작업계획](../../docs/archive/official_sources_transition/작업_계획_뉴스_수집.md)과 기존 실측은 보존한다.

뉴스·지수 반복 관측은 [10/29 종료](../logs/2026-10-29_반복_관측_종료.md) 상태다. 새 문서 작성으로 재개하지 않는다. 실제 공개 게시·유료 호출·클라우드 자원 생성은 이번 요청 범위 밖이다.
