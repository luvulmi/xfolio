## 조사 목표

기획한 시장 브리핑을 어떤 기술로 구현하고 월 총비용 3만 원 안에서 운영할 수 있는지 확인한다. 제공처와 기술의 후보, 추천 이유, 비용 계산 근거를 확보해 3주차 발표에 반영한다. 5~6주차 개발 계획인 주당 15시간·총 30시간에 맞춰 구현과 운영이 단순한 구성을 우선 비교한다.

아침에는 S&P500·나스닥100 마감과 거시·정책·시장/업종 뉴스를, 추가 뉴스에는 두 지수 구성기업 중 최대 10개 관찰 기업의 중요한 실적·회사 전망·사업 변화를 다룬다. 뉴스 제공처는 1곳, 입력은 영어·한국어 허용, 출력은 한국어다. 아침 최대 3건과 기업 뉴스 하루 최대 2회, 운영자 승인 후 X 게시가 조사 기준이다.

뉴스의 별도 72시간 게시 기한·24시간 겹침 조회·휴장 예외 계산은 적용하지 않는다. 새 사실·현재 관련성·근거로 검토하고 조회 방법은 제공처 기능을 확인해 정한다. 기존 07:30 정보 기준과 최근 7일 복구 상한은 조사 조건에 포함한다.

## OpenAI 조사에서 구체화할 흐름

1. 수집한 기사에서 거시·업종·기업 소식을 분류한다.
2. 관련성과 중요도를 판단하고 선정 이유를 남긴다.
3. 영어·한국어 근거를 바탕으로 한국어 요약을 만든다.
4. 지수 자료와 선정 뉴스를 X 게시 형식으로 작성한다.
5. 생성 문장에 원문 근거를 연결하고 근거 없는 주장·수치 변형을 확인한다.
6. 운영자가 근거와 미리보기를 검토하고 승인한다.

조사에서는 AI가 맡을 판단과 Python이 맡을 수치 계산·날짜·링크·중복·한도 검사를 구분한다. 구조화 출력으로 제목·요약·근거·분류 결과를 일정한 형식으로 받을 수 있는지 확인한다. 모델은 같은 기사 샘플로 한국어 정확성·정보 누락·근거 연결·속도·비용을 비교한다. 단순 SDK 호출로 충분한지, 별도 에이전트 프레임워크가 필요한지도 실제 역할을 기준으로 판단한다. 모델의 자체 검증만으로 정확성을 보장한다고 보지 않는다.

## 비용 산정 방식

예산은 월 총 30,000원이다. 정상 계획 24,000원과 여유 6,000원은 기존 운영 추천값으로 참고하며, 실제 요금이 확인되기 전 무료 운영 또는 예산 충족을 확정하지 않는다.

| 비용 항목 | 산정할 입력 |
| --- | --- |
| 지수·뉴스 | 기본 요금, 운영일 수, 하루 조회 횟수, 조회당 요청·페이지 수, 무료 한도와 초과 요금 |
| OpenAI | 분석할 기사 수, 평균 입력·출력 토큰, 분류·생성·검증 호출 수, 모델 단가, 재생성·시험 사용량 |
| X | 발행 단위별 실제 글 수, 게시·결과 조회 횟수, 필요한 요금제·사용량 과금 |
| 실행·저장·사이트 | 고정료, 예약 실행 횟수·시간, 저장량·전송량, 관리자 사이트 운영 비용 |
| 공통 | 시험·재시도 비용, 환율·세금·수수료, 미정산 사용량 |

기업 뉴스 정기 확인은 운영일당 18회이며 매 확인이 AI 호출이나 게시를 의미하지 않는다. 아침 호와 기업 뉴스의 운영일 수는 각 달력 조건으로 따로 계산한다. 아침 최대 5개 글·기업 사건당 최대 2개 글은 추천 상한으로 최대 사용량 계산에 활용하고 실제 예시의 글 수도 함께 기록한다.

무료 구간을 적용한 정상 사용 비용과 사용량 증가·재시도를 포함한 비용을 나란히 계산한다. 비용이 미확인인 항목은 0원으로 합산하지 않는다. 예산 초과 또는 필수 권한 미확인 시 해당 원인과 대안을 제시한다.

## 조사 기록과 발표 산출물

조사 결과는 `docs/research/`에 주제별로 기록하고 이 계획서에서 연결한다. 각 후보의 공식 문서·이용 조건·가격 페이지 URL과 확인일을 남기며, 직접 확인한 사실·추정 사용량·미확인 사항을 구분한다. 접근 권한이 있으면 최소 샘플로 확인하고, 접근하지 못한 경우 문서 확인 수준임을 표시한다. 실제 X 시험 게시와 유료 결제는 별도 명시적 승인 후 수행한다.

후보 비교표는 다음 형식으로 통일한다.

| 후보 | 지원 기능 | 이용 조건·근거 | 비용 | 구현·운영 난이도 | 추천/보류 이유·미확인 사항 |
| --- | --- | --- | --- | --- | --- |
| 조사 후 작성 | — | — | — | — | — |

3주차 발표에는 다음 네 가지를 담는다.

1. 지수·뉴스·X 및 기술 후보 비교표
2. 수집 → AI → 저장·관리자 승인 → X 게시의 기술 스택 구성도
