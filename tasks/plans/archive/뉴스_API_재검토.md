- 상태: 제공처 선정·실측 조사 완료. 당시 게시량/시간 비교는 이력이며 현재 기준이 아니다.

## 목표와 범위

미국 시장·업종 주요 뉴스와 주요 기업 이슈를 월 총 50,000원 안에서 전달할 수 있는 수집 경로를 정한다. 공식 가격·요약 근거·공개 이용 조건을 먼저 비교하고, 접근 가능한 후보의 동일 사건 표본을 검토한 뒤 게시량과 개발 일정을 결정한다.

유료 구독·결제·제공처 문의 발송·외부 게시·정기 관측 재개는 이번 조사에 포함하지 않는다. API 시험은 기존 키로 제한된 조회만 수행하며 비밀값과 기사 전문은 저장하지 않는다. 공개 이용 권리가 미확정이면 조건부 후보로 표시하고 공개 운영 완료로 처리하지 않는다.

## 완료 기준

공식 근거를 가진 비교표, 표본 관측 결과, 예산 산식과 일정 대체안, 사용자 결정 또는 구체적인 미결정 사유가 기록되어야 한다. 확인 불가 항목을 허용으로 간주하지 않는다.

## 당시 확정한 방향과 제공처 검증

1. **Exa를 개발 수집 API로 채택했다.** 기존 Marketaux·MarketNewsAPI 실제 비교 뒤 추가 5곳을 조사한 결과다. 매월 $10 무료 크레딧·뉴스/날짜/도메인 필터·본문 추출을 확인했다. Firecrawl 일반 검색은 차순위이며 두 API를 동시에 제품에 구현하지 않는다. Exa 실제 응답 비교는 완료했다. 공개 요약 조건 확인은 남아 있으며 개발 채택을 공개 운영 허가로 표시하지 않는다.
2. **뉴스 하루 최대 2건 + 지수 1건**으로 확정했다. 핵심 MVP는 아침 뉴스 최대 2건, 18시 편성은 후속이다. 후속 18시를 추가해도 아침과 합산 뉴스 2건 상한을 넘지 않는다. 근거가 부족하면 0건을 허용한다. 기존 하루 최대 5글에서 3글로 축소한다.
3. **뉴스 발견은 시장·업종 중심으로 넓게**, 기존 10기업은 기업 이슈의 우선순위로 확정했다. 다른 기업도 미국 시장/업종 영향이 크고 근거가 충분하면 검토 후보로 허용한다. 목록 밖이라는 이유만으로 제외하지 않는다. 10기업 외 사건을 자동 발행하거나 SEC 감시 기업을 늘리는 결정은 아니다.
4. **뉴스 API 1개 + 기존 BLS CPI 연결**을 핵심으로 확정했다. Fed·BEA·SEC 자동 어댑터는 후속으로 옮긴다. 이들 공식 자료는 검토자가 필요할 때 수치를 대조하는 근거로 사용할 수 있으나 자동 수집 완료로 표시하지 않는다.

## 당시 60시간 안의 일정 대체안

5~6주차 각 15h 확정, 7~8주차 각 15h는 기존대로 가정한다. 외부 라이선스 회신 대기는 시간 추정 밖이다. 아래 60h에는 핵심 55h와 추가 여유 5h가 포함된다. 결함 수정 3h는 핵심 안에 이미 계산했다.

| 주차 | 구체적 작업·시간 | 완료 기준 |
| --- | --- | --- |
| 5주차 11/2~11/8 · 15h | 채택한 제공처의 설정·검증 결과 인수 2h, 출처/시각/수집 상태 계약 3h, 선택 API 어댑터·조회 범위/한도/중복 6h, 다우 포함 세 지수 3h, DB/API 입력 대조 1h | 동일 기간의 후보·출처·시각·실패 사유 저장. 설정한 조회 완주와 시장 전체 포괄을 구분. 공개 조건이 해결되지 않으면 차단 상태 유지 |
| 6주차 11/9~11/15 · 15h | BLS CPI 기존 파서 연결 3h, 제목 의존/절단/예상·실적/동일 사건 필터 및 근거 검토 4h, 아침 지수1+뉴스0~2 편성·저장 6h, DB/API 대조 잔여 1h, 여유 1h | 후보→근거 검토→한국어 초안→수치/길이 검사→저장. 실제 허용 입력과 가상 시험을 구분 |
| 7주차 11/16~11/22 · 15h 가정 | 검토 목록·상세·승인 4h, 발행 내역 API/UI 3h, worker·중복 점유/재시작 3h, 결함 수정 3h, 여유 2h | 승인한 정확한 버전만 worker가 점유. 근거 부족·권한 미확인·partial 입력은 게시 차단 |

**기존 WBS와의 차이:** Fed 3h + BEA 4h + SEC 7h + CIK 설정 1h = 15h를 후속으로 옮긴다. API 채택 재검증 2h + 단일 API 6h + 뉴스 근거 검토 4h = 12h를 추가해 핵심 58h→55h, 추가 여유 2h→5h로 바꾼다. 기존 핵심 연결 30h·발표 4h는 유지한다. 기존 BLS·세 지수·공통 계약 9h도 유지한다.

4기관 자동 수집을 모두 핵심에 유지하면서 위 API 작업까지 더하면 **핵심 70h**, 기존 최소 여유 2h를 포함하면 **72h**다. 가용 60h보다 최소 12h 늘어나므로 같은 마감의 완료를 약속할 수 없다. AWS·18시 편성·Telegram 운영 연결 등 기존 후속 작업은 이 계산에 포함되지 않는다.

## 남은 결정과 실행 경계

제공처 결정은5주차로 미루지 않고 이번에 Exa 개발 채택으로 확정했다. 5주차 2h는 조사 재수행이 아니라 설정·표본·사용 범위 결과를 제품 계약으로 인수하는 시간이다. 실제 검색 3회+Contents 1회 비용은 응답 기준 $0.023. 공개 권한 확인과 무료잔액/전체운영비 검증은 남아 있다. 공개 이용이 해결되지 않으면 해당 외부AI 입력·공개 게시는 차단한 채 허용자료/가상자료로 연결을 검증한다. 문의 초안은 완성했으며 발송은 사용자의 별도 명시 요청 후 수행한다.
