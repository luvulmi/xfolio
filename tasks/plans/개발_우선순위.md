# 개발 우선순위

- 갱신: 2026-10-30, Asia/Seoul
- 상태: Fed·BLS·BEA·SEC 10기업·세 지수 기준의 계획
- 기준: [WBS](../../docs/planning/작업_분해_WBS.md) · [단계별 범위](../../docs/planning/개발_범위와_단계.md)

## 진행 순서

계정·API·수집 설정의 준비 마감은 **11/1(일)**이며 [준비 목록](../presentations/4주차_개발_계획.md#-11월-1일까지-준비할-것)을 따른다. 기존 연결 기록과 현재 확인이 필요한 항목을 구분하며 실제 서비스 가입·키 발급 완료로 표시하지 않는다.

1. **대상·입력 확정:** N07에서 확정 10기업의 법인명·CIK·표본을 대조하고 N02로 출처·시각·개정·근거·실패 상태 계약을 연결한다.
2. **입력 구현:** N03 BLS·N04 Fed·M01 다우를 준비하고 A01 계약 대조 후 N05 BEA·N06 SEC를 연결한다. FOMC·CPI·PCE·8-K 실적·M&A는 초기 지원 확정이다.
3. **아침 검토 연결:** A04 편성과 A02 관리자에서 Fed·BLS·BEA·SEC 근거·세 지수·초안을 대조하고 승인한다. 6주차에 편성을 시작하고 7주차에 검토 화면을 연결한다.
4. **예약·모의 전송:** A03 발행 조회, A05 worker, A06 모의 전송을 연결하고 A08 결함 수정 시간을 사용한다.
5. **인수·발표:** A07 통합 인수와 C01 회귀·발표를 수행한다. 실제/모의/미완료를 구분한다.
6. **후속 운영:** B 작업은 핵심 흐름 완성 후 추가 시간과 실제 진척에 맞춰 배치한다.

N01 뉴스 API 선택은 종료했다. N03 BLS·N04 Fed는 유지하고 20기업 확장 시험만 삭제한다. 기존 BLS 시험은 공통 계약 연결에 재사용한다.

## 일정 판단

5~6주차 30h만 확정이다. 7~8주차 30h를 추가한다는 가정에서 핵심 기준 58h와 추가 여유 2h를 배치한다. 전체는 후속 운영을 포함해 기준 78h·예상 78~124h이며 가용 60h보다 기준 18h가 많다.

11/15 잔여량 재산정, 11/22 핵심 연결 점검, 11/24 기능 동결을 추천한다. 근거·승인·중복·마감·unknown·예산 검사를 줄여 일정을 맞추지 않는다.
