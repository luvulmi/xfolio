## 진행 순서

1. N01은 종료했다. Fed/BLS/BEA+SEC 경로를 채택했으므로 뉴스 API 선택 작업을 반복하지 않는다. N02에서 출처·시각·개정·근거·실패 상태 계약을 정리한다.
2. N07의 목록/설정1시간은5주차에 배치해 주요 기업10개 명단·티커-CIK·선정 기준을 고정한다. 확장시험1시간은 N06 SEC 어댑터 이후6주차에 배치한다. M01로 다우와3지수 편성·길이·부분실패 검증을 추가하며 A01 계약대조2시간은5주차에 모두 수행한다.
3. N03~N06으로 BLS CPI·Fed FOMC 성명·BEA PCE·SEC 실적/M&A의 좁은 유형을 우선 지원한다. 기관별 모든 문서·표 파싱을 완료 범위에 넣지 않는다. SEC 기업 첨부물은 이용 범위를 별도 확인한다.
4. A01/A04에서 공통 계약과 실제 코드를 대조하고4기관 입력·3지수·AM편성을 검토/승인에 연결한다.5~6주차30시간은 여기까지의 중간 목표다.
5. A02/A03/A05를7주차에 연결한다.8주차 초 A06 모의 전송 개발을 마무리하고 A07/C01로 핵심 인수·회귀·시연을 완료한다. A08 결함 여유를 새 기능에 쓰지 않는다.
6. B작업20시간은 추가 가용 시간을 확보하거나 핵심 완료 후 진행한다. 수집/운영/설정 독립 메뉴·PM·Telegram·CLI편의·AWS·실제 연동 인수를 제품 목표에서 삭제한 것은 아니다.

## 시간과 재산정

전체 기준79시간·예상79~126시간이다. 가용시간 가정은 확정30시간에 추가30시간을 더한60시간으로, 기준19시간이 부족하다.60시간 우선 배치 추천은 공식4기관·3지수·10기업과 AM 핵심 흐름59시간+여유1시간이다. 전체목표를 같은 마감에 넣는 추가시간 확보는 사용자 미확정이다.

11/15에 소스별 실제 지원과 남은 작업을 재산정한다.11/22 핵심 연결을 점검하고11/24 기능 동결을 추천한다.8주차 후반은 신규 기능 대신 인수·회귀·결함 수정·발표에 남긴다. 근거·승인 버전·중복·마감·unknown·예산 검사를 줄여 일정에 맞추지 않는다.

웹 편집·범용 표/PDF 파싱·복잡한 재무 계산과auto 활성화는 기본79시간 밖이다.20기업 실제 확대는10기업 관측 결과와 한도/중복 검증을 통과한 뒤 진행한다. 중단한 반복 관측은 자동 재개하지 않는다.
