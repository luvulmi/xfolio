선불 크레딧·무료 체험을 영구 무료 예산으로 잡지 않는다. 1GB VM이 부적합하면 무단 증설하지 않고 예산·범위를 다시 판단한다. 권한·도메인·인증이 준비되지 않으면 AWS 실제 운영 완료로 표시할 수 없다.

## 2주 안에서 제외할 것

- Streamlit 재개발, Django, Next.js SSR, 별도 공개 독자 사이트
- RDS/ECS/ALB·S3/CloudFront·Terraform, 완전 자동 CD·무중단 배포
- Redis/Celery/SQS·다중 worker·사용자 가입·다중 역할·고급 검색/차트·실시간 SSE
- 웹 문안 편집·직접 게시·자동 재생성 UI·Telegram 승인/명령·웹훅
- VM 전체 장애를 감지하는 외부 상시 모니터, AWS 실제 청구의 실시간 동기화
- 권한 미확인 기사 AI 전송·공개, 5거래일 시험 전 auto 활성화

위 항목은 포기한 최종 목표가 아니라 MVP 후속이다. 단일 VM/worker의 장애 한계와 외부 감시 부재를 운영 기록에 공개한다. 예쁜 차트보다 **버전 승인·중복 방지·불명 결과 보류·비용 차단·장애 알림**을 면접에서 재현할 수 있게 한다.

## 진행과 재계획

1주차 말에 인증된 React 화면에서 아침 후보 승인까지 연결되지 않으면 UI 장식과 부가 필터를 먼저 뺀다. 게시 정합성·권한·예산·실패 처리는 생략하지 않는다. 2주 내 목표는 **배포 가능한 reviewed MVP와 모의/제한 실제 시험**이다. 5거래일 관측·무인 auto 안정화는 7주차 이후로 분리한다.
