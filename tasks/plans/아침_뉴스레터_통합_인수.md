## 시험 계약

- 가격과 뉴스는 기존 T02/T03의 출처·기준/발행/조회시각·버전·보존 계약을 유지한다. 뉴스 발행 기준은 한국 거래일07:50이며 현재시각을 과거로 바꿔 실제 수집 성공을 만들지 않는다.
- 07:50 기준의 설정·관심 종목을 고정하고 이후 변경·중지·휴장·미확인 거래일·예산·08:10 마감을 발송 직전에 재검사한다. 한국 휴장 평일과 주말에는 발송하지 않는다.
- 격리 PostgreSQL의 합성·외부 API 모의 통합 시험과 실제 제공처 조회·유료 AI·Telegram 실제 통신·제품07:50→08:00 정시 수신을 각각 구분한다. 시험 DB는 운영 DB와 분리하며 schema별로 정리한다.
- 실제 제공처 조회의 키는 로컬 `.env`에서 프로세스 메모리로만 읽고 기록하지 않는다. 실제 Telegram 검증은 본인1:1 수신자만 사용한다. 마감 이후 운영 뉴스레터 발송을 우회하지 않는다. 필요시 명확한 시험 표시의 통신 확인을 별도 수행하며 정시 수신 인수로 계산하지 않는다.
- 유료 AI는 명시적 유효 단가·예산과 실행 설정이 있어야 한다. 없으면 보류 사유를 남기고 무료 수집·무통신 요약 경로 시험을 진행한다.
- 시작 관측: 2026-11-05 00:14:01 UTC(09:14:01 KST). 전체 세션 시작시각이나 순수 능동 공수로 소급하지 않는다. 현재 아침 마감 이후이므로 실제 정시 수신은 별도 관측이 필요하다.
