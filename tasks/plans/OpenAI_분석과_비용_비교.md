# OpenAI 분석 연결과 비용 비교

- 작성일: 2026-10-25, Asia/Seoul
- 상태: 가상 경로·비교 완료. `gpt-6-luna`를 기본 모델로 확정; 실기사 품질·운영 연동은 후속
- 관련: [가이드 적용 검토](../discussions/2026-10-24_OpenAI_가이드_적용_검토.md) · [현재 OpenAI 조사](../../docs/research/OpenAI_활용.md) · [뉴스·미리보기 계약](../verification/news/뉴스_수집과_아침_미리보기.md)

## 목표와 범위

1. 가상 뉴스의 선정·근거·한국어 문안 생성을 공통 앱 함수로 구현하고 현재 가상 미리보기에서 시험 가능하게 연결한다.
2. 동일한 직접 작성한 가상 사례로 Mini·Luna의 결과·사용량·비용을 비교한다. 한 모델의 초기 프롬프트와 다른 모델의 교정 프롬프트를 비교하지 않는다.
3. 공식 미국 거시 자료 직접 조회와 OpenAI Web search 보조 방식의 근거·호출량·비용을 비교한다.
4. 결과를 기존 월 X+AI 부분 견적과 합산하고 미확정 뉴스 이용료·권한을 분리한다.

실제 뉴스 공급처 기사·본문은 OpenAI에 전달하지 않는다. 실험에는 직접 작성한 가상 자료와 공식 공개 발표 제목/메타데이터만 사용한다. 실제 X 게시·예약·관리자 승인은 범위 밖이다.

## 작업과 완료 조건

- [x] 공통 분석 입력/출력·실패 보류·usage 계약을 정하고 가상 CLI를 연결한다.
- [x] 외부 API 없는 중요 사례 검사와 기존 전체 기능 검사를 통과한다.
- [x] 두 모델에 동일한 사례·프롬프트·한도를 적용해 실제 usage·품질 차이를 기록한다.
- [x] 직접 공식 자료와 제한된 Web search를 같은 기준일/사건으로 비교한다.
- [x] 실측 시험비와 모델 교체·검색 추가의 월 가정 비용을 재산정하고 근거를 기록한다.
