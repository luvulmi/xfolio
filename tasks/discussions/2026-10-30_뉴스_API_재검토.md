# 뉴스 API 재검토 · 미국 시장·업종·기업 뉴스

## 재검토 이유

사용자는 Fed·BLS·BEA·SEC만 수집하면 원래의 주식 뉴스 전달 취지와 어긋날 수 있다고 지적했다. 공식 발표·공시만으로는 제품 출시·업종 동향·기업 경쟁·규제 보도 등을 충분히 발견하기 어렵다. 이는 기존 기술 선택에 맞춰 콘텐츠 목표를 축소했는지 다시 살펴볼 이유다.

## 사용자가 확정한 사항

- 독자에게 전달할 우선 콘텐츠: **미국 시장·업종 주요 뉴스 + 주요 기업 이슈**. 공시만으로 제한하지 않고 시장 흐름과 기업 사건을 함께 전달하려는 목적이다.
- 전체 비용: **월 50,000원 유지**. 뉴스 API 비용을 확보하기 위해 게시 빈도·기존 비용 조정도 비교한다. 최초에는 감축안을 비교했고 이후 뉴스 최대2건을 확정했다.

## 제안과 대안

- 추천 조사 방향: 뉴스 API 1개를 주요 발견 경로로 두고, 필요한 사건에서 공식 자료로 수치·정책·공시 사실을 대조한다. 4기관 수집기와 뉴스 API를 모두 필수로 추가하면 일정이 증가하므로 1차 구현 순서도 재산정한다.
- 대안: 뉴스 API는 후보 탐색만 맡기고 허용 원문 확인 후 짧은 사실 브리핑을 만든다. 발췌만으로 설명하지 못하는 사건은 게시를 생략하거나 검토 대상으로 둔다.
- 기존 공식자료 단독안은 근거와 범위를 통제하기 쉽지만 새 콘텐츠 목표의 시장·업종 보도를 충분히 담지 못한다.

## 기존 조사에서 재사용할 근거

- Marketaux: 기존 코드·표본이 있지만 발췌 절단·제목 의존, 무료 호출량과 전 페이지 조회 문제가 있었다. 과거 일부 질의 실패를 전체 뉴스 부재로 해석하지 않는다.
- Alpaca/Benzinga: 본문 기술 후보지만 당시 뉴스 요금·사용 범위는 미확정이었다. Benzinga 사용 불가라는 사용자 전달 이력이 있으므로 Alpaca를 통한 동일 콘텐츠도 자동 대안으로 인정하지 않는다.
- MarketNewsAPI: 과거 조사에서 일반 기사 본문 부재와 별도 상업 라이선스 조건이 확인됐다. 최신 조건을 확인하기 전 무료 공개 요약에 적합하다고 추천하지 않는다.
- 기존 견적은 월 약 46,566원으로 여유가 작다. X 뉴스 게시 빈도 변경에 따른 절감과 뉴스 구독·라이선스 비용을 함께 비교한다. 이전 가격을 현재 가격으로 단정하지 않는다.

## 다음에 확인할 일

1. 뉴스 API 후보의 현재 가격·본문/요약 필드·시장/업종/기업 검색·지연·호출량·AI 입력 및 한국어 공개 요약 조건을 공식 문서로 비교한다.
2. 기존 Marketaux 재사용안과 새로운 후보를 비교하되 현재 미해결 조건은 그대로 표시한다.
3. 고정된 같은 기간의 시장·업종·기업 사건 표본으로 유용한 기사 발견 여부와 근거 충분성을 확인한다. 제목 단서 검색 결과만으로 합격하지 않는다.
4. 하루 게시량 조정안과 서버 비용을 묶어 월 5만 원 예산을 계산한다. 비용·기사 품질·구현 시간을 통과한 제공처를 선택한 뒤 기준 문서·WBS·발표 자료에 반영한다.

## 이번 공개 페이지 1차 확인

- [Marketaux 가격](https://www.marketaux.com/pricing): Monthly 탭에서 Free 100요청/일·3기사/요청, Basic $29/월·2,500요청/일·20기사/요청을 확인했다. 계획 환율 1,815원에서 Basic만 52,635원이므로 월 전체 5만 원 조건의 월결제 후보에서는 제외할 수 있다. Free의 표본 품질·허용 범위는 별도 검증 대상이다.
- [FMP 가격](https://site.financialmodelingprep.com/developer/docs/pricing): Personal Use·Annual 기본 화면에서 Starter $19/월(연결제), 월결제 비교값 $29, Financial Market News 포함 표시를 확인했다. 같은 페이지는 데이터 표시·재배포에 별도 Data Display and Licensing Agreement가 필요하다고 명시한다. 저렴한 개발 접근 가격을 공개 X 요약의 전체 비용으로 사용할 수 없다. 계정별 권한·본문·별도 계약 견적은 미조회다.
- 이번 조회는 후보를 좁히는 공개 가격 확인이다. API 응답·기사 품질·요약 권한을 새로 검증하거나 제공처를 채택하지 않았다.

### 게시 빈도 조정의 비교용 계산

기존 산식(월 22일, URL 뉴스 $0.20/글·지수 $0.015/글·확인 $0.005/글, VM $7, AI $0.176, 환율 1,815원)을 유지한 시나리오다. 현행 단가 재검증·세금·부대비용·새 뉴스 API 라이선스는 미포함이다.

| 하루 게시 구성 | API 구독 전 부분 소계 | 5만 원까지 남는 금액 |
| --- | ---: | ---: |
| 지수 1 + 뉴스 4 (기존 최대) | 약 46,566원 | 약 3,434원 |
| 지수 1 + 뉴스 2 | 약 30,194원 | 약 19,806원 |
| 지수 1 + 뉴스 1 | 약 22,009원 | 약 27,991원 |

뉴스 빈도를 줄이면 조사할 유료 가격대가 생기지만, 남는 금액 전부를 구독에 쓰면 세금·재시도·부대비용 여유가 없다. 이 표는 선택 전 비교 이력이다. 이후 사용자가 뉴스 최대2건을 확정했다.

## 후속 답변과 확정 결과

1. 사용자가 Marketaux·MarketNewsAPI 키를 직접 저장했다. 동일 기간 뉴스16회·usage2회로 실제 응답을 비교했다.
2. **뉴스 API 1개+BLS CPI+세 지수**, 핵심55h+추가여유5h의60h안을 선택했다. Fed·BEA·SEC 자동 수집은 후속이다.
3. **뉴스 최대2건/일+지수1건**으로 정했다. 아침이 핵심이며 후속18시를 추가해도 뉴스는 양 편성 합산2건이다.
4. **기존10기업 우선+목록 밖 미국 시장·업종 중요 사건 허용**을 선택했다. SEC20기업 확장은 되살리지 않는다.
5. 제공처 결정을5주차로 미루는 안을 거절하고 지금 추가 조사를 요청했다. Firecrawl·NewsAPI.ai·Exa·ScrapingBee·Firecrawl Alexandria를 추가 비교했다.
6. Exa1순위 검증을 선택하고 키를 직접 저장했다. 실제 검색3회+캐시본문1회($0.023 응답비용),15검색 결과와2URL을 검토했다.
7. 최종 사용자 답: **“Exa 개발 채택, 공개 조건 확인 후 운영 (추천)”**. 본문 근거·날짜필터·무료 예산을 이유로 개발 API를 Exa1개로 정한다. 공개 X 운영은 약관 §4.2(a)의 적용과 원자료 이용 범위를 확인한 뒤 시작한다.

## 남은 조건

- Exa의 외부 AI 추론·한국어 공개 요약·근거 보관/해지 후 게시물 조건. [문의 초안](../../docs/research/뉴스_수집.md#exa-확인-문의-초안--미발송)은 작성했으며 발송하지 않았다.
- 계정 무료 잔액·실청구와 실제 운영 질의 빈도·메모리·도메인/백업 비용. 월5만원 상한은 유지한다.
- 실제 기사 버전·자정으로 표시된 시각·절단·동일사건/보도자료 분류를 제품 어댑터로 연결한다. 이번 비교는 개발 구현 완료가 아니다.
