# 두 지수 관련 뉴스 단일 흐름

- 세션 ID: `2026-10-25_두_지수_뉴스_단일_흐름`
- 주제: Marketaux 뉴스 후보의 범위와 아침·이후 게시 편성
- 시작·최근 갱신: 2026-10-25, Asia/Seoul
- 상태: 범위 결정 완료, 운영 가능성 검증 전
- 이전 범위: [월 5만 원·Marketaux 단일 뉴스 범위](2026-10-25_예산과_Marketaux_뉴스_범위.md)

## 사용자가 확정한 사항

- Marketaux에서 **S&P 500·Nasdaq-100 두 지수와 관련된 뉴스**를 수집하고 중요도를 선별한다. 고정 5개 기업의 별도 뉴스 편성 대신 한 뉴스 흐름을 사용한다.
- 아침에는 중요 뉴스 최대 2건을 게시한다. 이후 정해진 시간마다 새 뉴스를 감시하고 중요도 기준을 통과한 새 사건을 **하루 최대 2건** 추가 게시한다.
- 기존 아침 두 지수 종가·등락률 요약 1글과 월 50,000원 상한은 유지한다. 뉴스 글에는 핵심 사실·출처·원문 링크를 넣고 적격 뉴스가 없으면 한도를 채우지 않는다.

## 제안과 적용 이유

- 지수 자체·거시/정책/시장/업종·지수에 의미 있는 구성기업 사건을 동일한 관련성·중요도 기준으로 비교한다. 단순히 구성기업 이름이 등장하거나 지수 편입만 확인됐다는 이유로 선정하지 않는다. 이는 사용자의 “두 지수 관련 중요 뉴스”를 구현하기 위한 판정 제안이다.
- 아침 정보 기준은 기존 07:30, 이후 감시는 기존 09:00~17:30의 30분 간격을 **시험용 추천값**으로 유지한다. 두 구간은 같은 기사·사건 ID를 공유해 중복 게시를 막는다. 실제 조회 겹침 폭·수록 지연·예약 시각은 실측 후 확정한다.
- BLS·SEC 직접 수집은 첫 버전의 필수 경로가 아니며 이전 기술 시험으로 남긴다.

## 미결정·검증할 사항

- Marketaux `symbols`·`entity_types`·검색어 중 어떤 조합이 두 지수 관련 중요 사건을 충분히 발견하는가. 해당 지수의 API 심볼 대응은 미확인이다.
- Free의 하루 100요청·요청당 기사 3건으로 아침과 정기 감시의 정의한 페이지를 모두 읽을 수 있는가. 이전 넓은 아침 24시간 표본은 **138페이지 필요 추산**이었으므로 5개 기업 질의를 없애도 무료 운영을 입증하지 못한다. [가격](https://www.marketaux.com/pricing) · [기존 실측](../verification/뉴스_수집과_아침_미리보기.md)
- 짧은 발췌가 주장 근거에 충분한가. 한국어 X 공개 요약·외부 OpenAI 입력·근거 보관 조건이 현재 용도에 허용되는가. [Marketaux FAQ](https://www.marketaux.com/faq) · [이용 조건 조사](../../docs/research/데이터_이용_조건.md)
- 뉴스 주제가 바뀌어도 최대 글 수는 같아 X 비용 상한은 유지된다. AI 후보 수·Marketaux 호출량·Cloud Run 실행시간과 월 총액은 다시 측정해야 한다. [월 비용](../../docs/research/월_비용.md)
