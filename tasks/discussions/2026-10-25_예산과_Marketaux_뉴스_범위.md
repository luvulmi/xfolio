# 월 5만 원 예산과 Marketaux 뉴스 범위

## 사용자가 확정한 사항

- 월 총 예산을 **50,000원**으로 변경한다.
- 뉴스 파이프라인은 **Marketaux에서 후보를 조회한 뒤 중요도를 선별**하는 단일 제공처 방식으로 단순화한다. 기존 BLS·SEC 직접 수집을 첫 제품의 필수 경로로 두지 않는다.
- 아침 뉴스는 **최대 2건**, 관찰 기업은 **5곳**, 기업 뉴스는 **하루 최대 2건**으로 계획한다. 최대치는 의무 게시량이 아니다.
- 앞서 정한 두 지수 요약 1글, 뉴스별 원문 링크, 반복 AI 총평 생략은 유지한다.

이 변경은 조사 범위가 늘어나 발표와 구현의 중심이 흐려졌다는 사용자 판단에 따른다. 조회·선별·검증·게시라는 한 흐름으로 설명할 수 있도록 범위를 좁힌다.

## 제안과 대안

- 5곳의 구체적 목록은 기존 3곳 **NVIDIA·Apple·Microsoft**에 이전 후보표의 **Amazon·Alphabet**을 더해 첫 구현 목록으로 잡았다. 두 추가 회사는 사용자가 이름을 지정한 것은 아니며, 운영 전에 최신 지수 편입과 Marketaux 커버리지를 확인한다. Alphabet의 GOOGL·GOOG는 한 회사다.
- 아침에 근거가 충분한 서로 다른 사건 2건을 중요도순으로 선택한다. 0~1건만 적격이면 그 수만 게시한다. 기업 뉴스도 같은 사건 재인용을 중복 게시하지 않는다.
- 경고선 **40,000원**은 새 상한의 80%인 운영 추천값이다. 50,000원 초과 예상 요청 차단은 확정 예산을 적용한 것이다.
- 이전 대안인 BLS CPI 직접 조회 + SEC 실적 공시 자동 수집, MarketNewsAPI 분리 연동은 기술 시험 기록으로 보존한다. 현재 제품 범위에는 두지 않는다.

## 미결정 질문

- Marketaux Free의 100요청/일·3기사/요청에서 아침과 5개 기업의 정의된 범위를 빠짐없이 조회할 수 있는가? 과거 넓은 아침 검색은 아침만 138페이지 추산이었다.
- 제공 기사 발췌와 원문 연결이 중요한 거시·기업 사건의 한국어 요약 근거로 충분한가?
- 계약상 외부 OpenAI 전달, 한국어 요약의 X 공개, 근거 보관·게시물 존치가 허용되는가?
- 실제 Cloud Run 실행 시간·X 청구가 5만 원 안에 머무르는가?
