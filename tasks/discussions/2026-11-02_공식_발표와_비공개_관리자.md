# 공식 발표 뉴스와 비공개 관리자 선택

- 세션 ID: 2026-11-02-official-news-private-admin
- 시작·최근 갱신: 2026-11-02, Asia/Seoul (시각 미기록)
- 상태: 사용자 선택 확정·기획서 반영. 공급자 인수·실제 운영은 대기.

## 제안과 대안

Exa의 공식 검색/LLM 기능과 기사 이용권을 구분해 조사했다. NewsAPI.ai의 2026-10-07 약관은 유료 외부 AI·보관·파생 요약을 더 명시적으로 허용하나 원매체 권리를 제공하지 않으며 월 $90부터다. 현 예산을 유지하려면 재사용 근거가 있는 공식 발표로 출처 범위를 좁히는 안을 추천했다.

AWS는 Lightsail + Tailscale의 PC/휴대폰 접근과 EC2 + Session Manager의 PC 터널을 비교했다. 기존 서버 목표를 유지하면서 관리 화면을 비공개로 만드는 전자를 추천했다. 어느 안도 데이터 이용 조건을 대신 충족하지 않는다.

## 사용자가 확정한 사항

1. 비동기 질문 답변: **“Exa + 공식 발표 요약으로 시작 (추천)”**. BLS·BEA·Federal Reserve Board의 자체 텍스트/수치, 제3자 자료 제외. 일반 언론사 뉴스보다 범위가 좁고 0건인 날이 있음을 안내한 후 선택했다.
2. 비동기 질문 답변: **“Lightsail + Tailscale, PC·휴대폰 접속 (추천)”**. 관리자만 본인 기기로 접근, 예약 worker는 독립 실행.
3. 종목 검색·확인·추가 요구는 기존 결정 유지. 마스터 기반 검색과 코드별 기본/시세 확인, 앱 DB 관심 목록 저장 방식의 실현 가능성을 확인했다.
4. 위 사항을 정한 후 `docs/프로젝트_기획서.md`에 개요·기능/화면·기술/인프라·일정·QA/운영·부록을 총정리하도록 요청했다.

## 미결정 질문과 외부 확인

제품 선택 질문은 해소했다. KIS 서비스 신청·인증 기본/가격 실응답, AWS/Neon/Telegram 처리·보관 조건, 새 비용 실측은 남은 외부 인수다. 공식 자료 수집과 Tailscale 구축을 추가한 공수는 재추정이며 7~8주차 가용 시간과 초과분 일정은 보장되지 않는다.

## 후속 사용자 조정 · 같은 날

사용자는 “난 뉴스도 다루고싶은데”라고 공식 발표 한정 범위를 재검토했다. 이어 **“일반 뉴스 제목·링크 + 공식 발표 AI 요약으로 시작”**을 명시 선택했다. 위 최초 공식 발표 한정 선택을 대체하는 최신 결정이다. Lightsail/Tailscale 선택은 유지한다.

일반 뉴스 원제·매체·시각·원문 링크와 공식 발표 AI 요약을 합쳐 최대3건, 일반 기사 본문 AI 요약·번역은 초기 제외다. 공식 발표는 RSS/API/공식 페이지에서 직접 수집하고 Exa는 일반 뉴스 탐색 후보로 재검토한다. Exa 제외 자체에 대한 최초 질문에는 승인하지 않고 뉴스 포함을 요청했으므로 전체 Exa 제거로 기록하지 않는다. 일반 뉴스 제공처·비용·개인 전달/보존 허용은 인수 전이다.

사용자 요청으로 기존 HTML 스타일을5메뉴·Telegram 미리보기로 갱신하고 가상 오전/장중/마감·예외 메시지를 기획서에 추가한다. 자료 권한 문제는 기관별 재사용 조건 적용과 KIS/일반 뉴스 제공처 용도 확인으로 해결하며 비공개화만으로 대체하지 않는다.
