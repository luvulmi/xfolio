## 사용자 요청과 확정한 조사 범위

사용자는 로컬 SQLite·Streamlit 구성의 PC 의존성을 줄이고 DB 서버와 관리자 사이트를 최대한 무료로 배포할 방법을 조사해 달라고 요청했다. 접속 화면만 배포할지 질문한 뒤 **DB·관리자 페이지·수집·게시 예약까지 전부 클라우드**를 선택했다. 이유는 로컬 PC에서만 작동하는 제약을 없애기 위해서다.

최초 조사 요청은 10/24의 같은 Windows PC 한정 배치를 재검토하는 범위였다. 이후 사용자가 **추천 작업 진행**을 요청해 Neon Free·Streamlit Community Cloud·Cloud Run Jobs·Cloud Scheduler를 전환 목표로 선택하고 계획·가상 시험 준비를 진행했다. 신규 계정이 없다는 답변 뒤 사용자가 직접 Neon·Streamlit 가입/로그인과 `.env`의 DB URL 등록을 완료했다. 실제 결제·약관 동의·보안 권한 부여·커밋·X 게시 권한은 해당 단계에서 별도로 적용한다.

## 제안과 대안

추천은 **Neon Free PostgreSQL + Streamlit Community Cloud 비공개 앱 + Cloud Run Jobs + Cloud Scheduler**다. 현재 Python·Streamlit을 유지하고 공통 DB만 PostgreSQL로 전환한다. 브라우저·로컬 PC·관리자 앱의 절전과 무관하게 예약 작업이 실행되는 구조다. 현재 실행량 가정과 무료 한도·부대 비용·대안별 공식 근거는 [배포 조사](../../docs/research/저장소와_관리자_화면.md#2026-10-25-무료-클라우드-전환-조사)에 모았다.

- 호스팅 비용은 무료 한도 내 월 $0을 목표로 할 수 있지만 실제 계정·배포·측정으로 확정하지 않았다. OpenAI·X·뉴스 유료 사용료는 별도다.
- Supabase Free는 DB·Auth 통합 대안이며, 관리자를 Streamlit 비공개 앱으로 운영하는 초기 구성에서는 Neon의 무료 용량·자동 재개 방식이 더 단순하다는 판단이다.
- GitHub Actions는 저빈도 시험 대안이다. 비공개 저장소 Free의 분 수와 예약 지연·누락 때문에 현재 5분 게시 큐 확인을 그대로 무료 운영한다고 보장할 수 없다.
- Oracle Always Free VM은 서버 한 곳에서 구성할 대안이지만 자원 확보·유휴 회수·OS/HTTPS/백업 관리 부담 때문에 우선 추천하지 않는다.

## 미결정 질문

10/25 사용자가 배포에 필요한 변경의 선별 커밋·`luvulmi/xfolio` push를 명시 승인했다. 실제 사이트 배포·OIDC·운영 예약 완료 여부는 별도 검증을 따른다.

1. Google 전용 프로젝트·결제 계정의 실제 사용 조건과 무료 범위·과금 통제를 확인한다. 이번 선택을 무제한 과금 승인으로 해석하지 않는다.
2. 추천 조합은 전환 목표로 선택했다. 실제 사이트·컨테이너·예약 검증 뒤 운영 완료 여부를 판정한다.
3. 관리자 비공개 앱의 허용 계정·승인 권한, DB 백업 보관 위치, 리전과 데이터 이전 방법.
4. 무료 한도 내 실제 실행 시간·DB 활성 시간·네트워크 사용량과 예약 지연을 시험한 뒤 현재 운영 시각을 만족하는지.
