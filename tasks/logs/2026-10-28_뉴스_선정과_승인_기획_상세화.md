## 검증

- 현재 변경/신규 Markdown 16개(기존 별도 작업 변경분 포함)를 읽기 전용 검사했다. UTF-8·BOM 없음·코드 펜스 짝·로컬 링크 172개·JSON 예시 6개 파싱이 통과했다.
- 뉴스 기본 사례 12건·화면 인수 시나리오 12건·기존 API 8개·저장 단위 8개를 확인했다. 동결 후 새 근거 허용 문구와 같은 보류 버전 재승인 허용의 충돌을 제거하고 교차 검토했다.
- 최종 병렬 검토에서 합성 자료의 승인 차단과 reviewed 성공 시험 입력의 충돌을 찾아 정리했다. 합성 제품 경로는 dry_run/차단 시험, 상태·예약 계층은 격리 테스트 더블/모의 adapter, 전체 reviewed 정상 E2E는 권한 확인 실자료 fixture로 구분한다. fixture 미확보 시험은 대기 처리하며 synthetic 차단을 해제하지 않는다.
- `git diff --check` 종료 코드 0. Git의 LF→CRLF 변환 안내는 있었고 공백 오류는 없었다. 신규 사례 파일명 오기를 통합 과정에서 한국어 파일명으로 수정하고 참조 존재를 재검사했다.
- 문서 변경만 수행했으므로 pytest/Ruff·제품 build·모델 호출·X 가중 길이·실제 외부 발송은 이번 검증 범위가 아니다. 사례 통과율이나 구현 완료를 주장하지 않는다.
