# 4주차 발표 작성과 개발 우선순위

**후속 범위 변경:** 아래는 발표 주차 정정 시점의 문서 작성 기록이다. 이후 같은 날 [풀스택 MVP·18시 뉴스·Telegram](../discussions/2026-10-28_풀스택_MVP와_18시_뉴스_편성.md)으로 확정해 발표·일정·우선순위 내용을 다시 갱신했다. 기존 Streamlit/GCP 설명은 새 제품의 현재 선택이 아니다.

- 수행일: 2026-10-27~28, Asia/Seoul
- 요청: weekly 발표를 확정 기획·구체적 개발 일정·진행 상황/차주 계획/시행착오와 계정 준비 중심으로 작성. 사용자가 **4주차로 정정**해 3주차 자료를 복원하고 4주차 자료·대본을 별도로 작성
- 범위: 발표·대본·계획·목차 수정. 애플리케이션 구현·새 계정/키 생성·외부 API 호출·배포·실제 게시·커밋·푸시는 수행하지 않았다.

## 실제 변경

- 기존 3주차 기술 조사·발표 대본 2개는 이번 작업 전 커밋 `86c3850`의 내용으로 복원했다. Git blob과 파일 바이트 일치로 복원을 확인했다.
- [4주차 개발 계획](../presentations/4주차_개발_계획.md)을 요청한 세 항목과 계정 준비표로 작성했다. 큰 흐름은 세로 Mermaid, 결정·미확정·진행 상태·주차별 산출물은 표로 요약했다. 기술·비용의 긴 설명은 기준 문서 링크로 연결했다.
- [4주차 별도 대본](../presentations/4주차_발표_대본.md)을 같은 순서로 작성하고 예상 질문을 갱신했다. 관리자 배포와 예약 플랫폼 미선택, Marketaux 개발 선택과 공개 운영 판정의 차이를 설명했다. 차주는 5주차의 Neon·아침 dry_run·승인 연결로 명시했다.
- 발표 파일 작성 후 [개발 우선순위](../../docs/planning/작업_분해_WBS.md)를 새로 만들었다. 계정/키 준비→뉴스 입력/권한→예약 방식→Neon 저장→아침/AI→승인→추가 뉴스→X→예약/복구→통합 검증의 의존성과 완료 조건, 관련 코드·문서를 명시했다.
- [개발 일정](../../docs/planning/작업_분해_WBS.md)을 최신 Marketaux·Luna·Neon/Streamlit 범위로 갱신했다. 기존 30시간 계획을 유지하고 5~6주차를 각각 15시간으로 재배분 제안했다. 이전 SEC 중심안·로컬 전용 설명을 현재 작업처럼 다루지 않는다.
- [스터디 일정](../../docs/스터디_일정.md)의 3주차 항목은 복원하고 **4주차 발표 항목**을 이번 요청으로 보강했다. 주차별 날짜는 유지했다. [작업 목차](../README.md)와 [로그 목차](README.md), 개발 계획의 발표·기록 링크를 새 경로로 연결했다.

## 근거와 상태 구분

- 코드에서 아침 가상 `selection`이 현재 1건이고 `publish.py`는 구현 전인 것을 확인해, 뉴스 2건·실제 승인·X 게시를 남은 작업으로 넣었다.
- 계정표는 기존 실제 호출·배포·push 기록을 근거로 작성했다. X 계정·콘솔·게시용 인증은 준비 증거가 없어 확인 필요로 표시했다. 실제 비밀 값을 읽거나 유효성 API를 재호출하지 않았다.
- 기존 관측 문서의 지연·누락을 시행착오로 요약했다. 기존 미커밋 관측 문서·JSON 파일은 이번 작업에서 수정하지 않았다. 5거래일 관측을 완료로 표시하지 않는다.
- GitHub Actions는 제안이고 Cloud Run은 보류 상태다. 사용자의 최종 선택이나 실제 예약 배포로 표시하지 않았다. 7개 운영 저장 단위와 세부 시간은 구현 계획 초안이다.

## 검증

- 주차·경로 변경 후 3주차 파일 2개가 HEAD와 바이트 단위로 같고 스터디 일정의 3주차 본문도 이전과 같음을 확인했다. 복원 파일을 포함한 Markdown 10개·로컬 링크 125개·앵커 2개, UTF-8/BOM·공백·코드 펜스·비밀 값 패턴·15+15시간 배분 검사와 `git diff --check`를 통과했다. Mermaid 코드 블록 확인은 별도 렌더러의 화면 검증과 구분한다.
- `.venv/Scripts/python.exe -m xfolio status` 종료0으로 수집/가상 미리보기 구현과 실기사 AI·승인·X 게시 미구현이라는 현재 CLI 상태를 확인했다. 외부 API를 호출하지 않았다.
- 문서 수정만으로 제품 테스트 통과나 운영 기능 완료를 주장하지 않는다.
