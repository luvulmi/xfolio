## 이용 조건 판정

[최신 공개 공식 근거6개](../verification/assets/market/KIS_인수_공식근거_2026-11-03/README.md)를 URL·조회시각·해시와 보존했다. 고객 약관은11/2와 동일한19,534 bytes/SHA256다. 개인 프로그램 이용·제3자 제공 금지·키 보호·부하/유량 제어·게시 수수료 기준은 명시돼 있다. 제14조10년은 회사 거래기록 보존 조항이며 고객 시세1년 보관의 허가 근거가 아니다.

초기 조사에서는 본인만 접근하는 관리자/프로그램의 개인 이용 근거와 특정 AWS/Telegram 경유·보관기간의 명시 여부를 구분해 적용 판단을 남겼다. 이 초기 부분 완료 판정은 아래 사용자 결정으로 완료로 변경했다. 계정별 요금·신청 별도 조건을 실제 확인한 것으로 바꾸거나 공급자 개별 허가를 취득했다고 기록하지 않는다. [항목별 명시/해석·최종 채택](../../docs/research/데이터_이용_조건.md#113-t01-재확인적용-조건).

공식 유량 공지 검색 색인과 직접 페이지의 본문 노출이 달라 일반18/s·모의1/s를 이번 계정 확정 한도로 쓰지 않았다. 신규 고객/로그인 제한 공지가 있어 운영 전 별도 대조한다. 이번 저빈도5회 성공은 한도 시험이 아니다.10/27 종료/10/29 필드 삭제 공지 대상에도 이번 두 조회 API는 없었다.

## 검증

- 합성/무통신: 휴장·주말·마감 전·합성 특수 마감·시간대·누락/중복/오래된 행·가격 형식·인증 실패/만료·HTTP429/KIS 유량 코드·timeout·일부 실패·분할/락·비밀 제거/실전모의 주소 검사를 추가했다. 실측 JSON 재생은 실제 표본의 무통신 회귀로 구분한다.
- 초기 집중 시험:32건 통과/5건 setup 오류는 sandbox 임시 폴더 쓰기 제한 때문이었다. `--basetemp .cache/pytest-t01-first`로 바꾼 재실행37건 통과. 이후 분할/실표본 재생·후속 인증 중단4건을 보강했다.
- 초기 `uv` 기본 cache 쓰기 제한은 Git 제외 `.cache/uv`로 경로를 지정해 해결했다. `.git` 쓰기와 공식 HTTPS 읽기/인증은 도구 승인 절차를 거쳤다. 자동 승인 거절은 없었다.
- 초기 Ruff의 naive datetime 시험은 aware 기준시각에서 시간대를 제거해 거절을 검사하도록 바꾸고 단일 행 검색을 `next`로 정리했다. XKRX 생성 시 사용하지 않는 과거 점심시간 필드 경고가 있으며 마감시각만 이용한다. 점심 필드는 제거하고 스케줄을 조회했다.
- 전체 `uv run --no-sync pytest -q --basetemp .cache/pytest-t01-final --tb=short`: **667 passed·48 skipped·18 warnings**,106.47초·종료0. 기존 격리 PostgreSQL 등 선택 시험48건은 미설정 skip, 경고는 기존 Authlib1건·XKRX 생성17건이다. sandbox 실행은 기존 API 구간 정체로 중단하고 이전 socketpair 제한 기록을 확인한 뒤 승인된 제한 밖에서 성공했다. 운영/외부 API를 호출하는 시험으로 확대하지 않았다.
- 전체 회귀 중 최종 검토에서08시에는 오늘의 `opnd_yn=Y`가 아직 완료일이 아니라는 교차검증 경계를 보완했다. 최신 완료일까지의 개장일만 비교하고, 잘못된 날짜/플래그/사건 필드는 고정 오류로 처리했다. 실제 시세를 재조회하지 않았으며 관련 최종 집중 시험을 별도로 실행했다.
- 최종 `uv run --no-sync pytest tests/test_kis_market_probe.py -q --basetemp .cache/pytest-t01-latest --tb=short`: **45 passed·18 warnings**,23.51초·종료0. 이 집중 실행이 최종 보완4건을 포함하며 앞선 전체667건과 합산해 별도 전체 실행 건수로 표현하지 않는다. 경고18건은 XKRX 생성의 과거 점심 필드 경고다.
- `uv run --no-sync ruff check .`·`uv run --no-sync ruff format --check .`: 통과·295파일·각 종료0. `uv run --no-sync xfolio status`: 종료0, 기존 legacy 상태 출력 보존.
- 문서19개·상대 링크280개/제목 앵커·UTF-8/BOM/코드 블록·공식 근거6개 해시·실제3종목×2일/5회 집계·설정된 비밀6개 값의 미포함·`.env` ignore/무추적·`git diff --check`: 통과. 비밀 값 자체는 출력하지 않았다. 원본 공개 자료의 bytes/해시를 보존했다.
