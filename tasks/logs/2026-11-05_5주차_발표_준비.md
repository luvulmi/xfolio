## 이번 문서 작업에서 실행한 검증

- 변경 Markdown의 상대 링크·UTF-8/BOM·코드 블록, 발표일11/8 일요일·기준일11/5·예정일11/6 관계, SVG XML을 검사했다.
- 기존 설치 Chrome을 Playwright로 실행해 SVG를1280×410으로 렌더링했다. 텍스트가 캔버스 안에 있는지 검사하고 실제 이미지를 열어 한글·글자 겹침·화살표·색상·상태 표시를 확인했다. PNG와 검사 도구는 Git 제외 `.cache/weekly-week5/`에만 두었다.
- 최초 Playwright 기본 브라우저는 설치 경로에 실행 파일이 없어 실패했다. 새 설치 없이 기존 Chrome 실행 경로를 지정한 재실행으로 렌더링을 통과했다.
- `git diff --check`를 실행했다. 제품 동작이 바뀌지 않아 Python/UI 기능 시험은 반복하지 않았으며 발표에 기재한1,040건 등은 위 기존 수행 기록의 수치다.
- 실제 외부 API·유료 요약·Telegram 송신·예약 변경·배포·커밋·푸시는 수행하지 않았다.
