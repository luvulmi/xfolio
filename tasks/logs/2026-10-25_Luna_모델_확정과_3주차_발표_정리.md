- 발표 자료를 XFolio 결과물 소개 → Market/News를 함께 보여 주는 전체 Mermaid 기술 스택 → Luna 월 비용의 세 부분으로 재구성하고 대본·예상 질문을 갱신했다.

- 최대 게시 기준 X `$13.97` + Luna `$0.1232`로 월 약 **25,579원**을 추산했다. Cloud Run 작업 3,418회가 모두 120초/180초이면 각각 약 **31,138원/38,438원**이다. 실제 실행 시간·X 청구는 미측정이고 45,000원은 예산 변경 제안이다.
- Luna의 동일 가상 6건 기계 검사는 6/6이지만 SEC 공시 사실 카드 3건의 기존 시험은 Mini로 수행했다. Luna의 실공시 문안 검증과 X 게시 연결은 남았다.
