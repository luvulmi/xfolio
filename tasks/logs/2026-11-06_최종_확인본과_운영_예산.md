## 번역 오류 수정과 비용 기록

이번 승인 후 첫 번역 검증은 `TITLE_TRANSLATION_SCHEMA_INVALID`였다. 기존 코드가 영어 원제의 숫자와 한국어 제목의 숫자만 직접 비교해, `since April`→`4월 이후`라는 정상 변환도 새 숫자 추가로 차단하는 문제를 외부 호출 없이 재현했다. [검사 코드](../../src/xfolio/ai/title_translation.py)는 전체 영문 월명과 한국어 숫자 월을 대응시키고, 일반 수치와 월을 각각 순서대로 대조하도록 수정했다. 월/수치 변경·추가·일반 수치 순서 변경은 차단한다. 약어·숫자의 다른 표기·복잡한 날짜 재배열은 여전히 차단될 수 있고 의미/고유명사 품질을 완전히 판정하지 않는다.

수정·단위 검증 후 별도1회로 실제 응답을 확인했다. 입력454·출력298토큰, 기존 보수적 원화 단가로 **원장 확정 추정액0.5775원**이다. 실제 카드 청구액을 확인한 값은 아니다. 원제/ID/버전/순서·3건·한국어/단일 행·수치·링크를 대조하고 번역 의미를 확인했다. 공식 가격을 다시 읽고 이번 검증의 메모리 설정에만 단가 유효기간10분을 부여했으며 원래 runtime의 만료 설정은 보존했다.

앞선 `RESULT_UNKNOWN`1건과 이번 수정 전 schema 실패1건은 usage를 확인하지 못했으므로 각각9.9원, **총19.8원 예약**을 유지했다. 실패액을0원이나 실제 청구19.8원으로 바꾸지 않았다. 자동 재시도는 없었으며 수정 후 검증은 새 시도 파일로 구분했다. 최종 메시지를 보내는 단계에서는 AI를 호출하지 않았다.

## 기획 예산

사용자의 명시 요청 범위에서 [기획서](../../docs/프로젝트_기획서.md#6-예상-운영-예산-및-비용-관리)에 **`6. 예상 운영 예산 및 비용 관리`**를 추가하고 기존 부록만7번으로 이동했다. 1~5장과 기존 부록 내용은 그대로다.

- 정상 월22거래일·아침1회·ETF최대10·뉴스최대3, Linux2GB Lightsail $12·무료 Neon/Tailscale·소량AI를 가정한다.
- 환율USD1=2,000원·부가세10%는 견적 가정이다. 서버26,400원+스냅샷 누적20GB 2,200원+AI1,000원=29,600원, 예비비10%를 더해 **32,560원→계획액33,000원**, 예상30,000~35,000원이다. 기존 상한50,000원을 유지한다.
