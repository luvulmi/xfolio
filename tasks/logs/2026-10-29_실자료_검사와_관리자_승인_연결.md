## 변경

인증·HTTPS 변경 11파일을 `ca37785`(`fix: 로컬 HTTPS 연결 지연 수정과 실제 Google 인증 검증`)로 커밋했다. 별도 공급자·지수 관측 변경은 해당 커밋에서 제외했다. 이번 요청에는 push를 실행하지 않았다.

`news_validation.py`는 CPI-U 월간 계절조정·연간 비조정 두 주장만 지원한다. 기간·값·단위·방향·비교 기준을 정해진 두 문형과 정확하게 대조한다. 같은 숫자를 유지한 부정·새 인과·예측·권유는 거절한다. 생성 입력에도 허용 문형을 전달한다. [OpenAI 공식 문서](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)의 구조화 출력 성공과 의미 정확성의 구분을 유지했다.

발표일(미국 동부)과 BLS URL을 포함한 완성 글을 NFC로 정규화한다. 이번 문형의 ASCII·한글·고정 URL만 [X 가중 규칙](https://docs.x.com/fundamentals/counting-characters)에 맞춰 계산하고 280 초과를 거절한다. 이모지/일반 URL을 추정 계산해 합격시키지 않으며 지원하지 않는 문자는 보류한다.

`news_edition.py`는 단일 BLS CPI 조회의 범위·원본 버전·시각을 collection run으로 보존한다. 생성 원초안을 수정하지 않고 새 편성 버전/hash와 job을 같은 트랜잭션에 저장한다. 17:30 발행 기준·17:45 동결·18:00 예약·18:10 만료, 수집 완료·권한·근거·중복 편성을 검사한다. 같은 계정/날짜/PM의 재생성으로 기존 승인/보류를 대체하지 않는다. 기존 8API에서 목록·상세·허용 근거·가중 글자 수와 승인 상태를 조회한다. 승인 때 권한 만료·실제 근거·수집 결과·의미/길이를 다시 검사한다.

## 실제 자료와 대역 구분

사용자가 월 누적 비용은 “아직 확인 필요”라고 답해 유료 Luna 호출을 보류했다. 22:15 KST경 BLS 공개 HTML을 1회 조회해 모의 생성→실제 격리 PostgreSQL→관리자 API 목록/상세를 확인했다. 완성 글은 **170 가중 글자**였다. 실제 시각이 PM 동결 마감 이후였으므로 `PM_FREEZE_DEADLINE_PASSED` 상태로 남았고 dry_run/synthetic 승인 시도는409였다. 모델/usage/비용은 모의 값, API 세션은 시험 전제이며 실제 자료·실제 DB와 구분해 JSON에 표시했다. 시험 schema는 정리했다.

정상 승인 경로는 고정 BLS HTML·모의 모델·명시적 권한/non-synthetic 전제를 넣은 격리 시험이다. 실제 Google는 직전 작업에서 검증했고, 이번 생성→승인 E2E에서는 Google 대역과 통제한 시각을 사용한다. 새 실제 모델 품질·Marketaux 뉴스 선정/완주·AWS·X 외부 게시의 완료 근거가 아니다.

- `frontend/` build 성공·UI **10 passed**. 실제 HTTPS/FastAPI/PostgreSQL Playwright **2 passed**. 정상 경로는 CPI 생성→의미/길이→편성→화면 승인→예약 유지/새로고침→철회를 확인했고, 별도 synthetic 차단·CSRF/Origin·로그아웃도 유지했다.
