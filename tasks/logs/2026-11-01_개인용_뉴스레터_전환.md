## 실제 표본·외부 조건

[KIS 공개 마스터 3종목](../verification/market/국내_ETF_API_표본_검증.md)은 코드·명칭·ISIN 모두 일치했다. 가격 응답이 아니다. 공식 현재가/일별 REST 요청 계약을 확인했다. 초기 sandbox DNS 조회 실패 후 허용된 읽기 전용 네트워크 실행으로 마스터 조회를 완료했고 TLS 검증은 유지했다.

알려진 KIS 환경변수와 루트 .env/.env.local에 설정이 없었으며 비밀 값은 출력하지 않았다. 사용자가 계좌 있음/Open API 신청 필요라고 답했으므로 실제 종가/장중 API 호출과 이용 허용 범위는 **대기**다. 일요일 결과로 장중 시세를 인수하지 않았다. 약관 본문은 비로그인 페이지 조회로 확보하지 못했다. 권리 미확인은 제품 전송 허용으로 처리하지 않는다.

- 공개 마스터 실측: 세 종목 일치, 출처·UTC 확보시각·ZIP SHA256·인증 시세 미검증 플래그 저장.
- `uv run --no-sync --python .venv\Scripts\python.exe ruff check .`: 통과.
- `uv run --no-sync --python .venv\Scripts\python.exe ruff format --check .`: 274개 파일 통과.
- `uv run --no-sync --python .venv\Scripts\python.exe pytest -o faulthandler_timeout=60`: **571 passed, 48 skipped, 1 warning**, 67.47초. 새 마스터 검사3건 포함. 48건은 PostgreSQL 조건부 시험이며 새 DB 인수로 해석하지 않는다. 기존 Authlib jose 사용 중단 예정 경고1건은 이번 변경 범위 밖이다.
- 변경/신규 Markdown의 상대 링크636개·BOM 없는 엄격 UTF-8·`git diff --check`: 통과. 발표 이름 변경으로 깨진 연결과 기준 문서 이동의 앵커도 보정했다.
- 기본 uv 실행은 sandbox 캐시 접근 오류로 중단했다. 저장소 전용 UV_CACHE_DIR와 기존 .venv Python을 지정해 검사 실행을 이어갔다.
- sandbox 전체 pytest는 기존 FastAPI TestClient 구간에서 진행되지 않아 중단하고 로컬 실행으로 다시 검증했다. 실제 시세/외부 발송 시험을 실행한 것은 아니다.
