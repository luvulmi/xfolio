## 검증

- 변경 Markdown 12개: 엄격 UTF-8 디코딩·BOM 없음·대체 문자/의도하지 않은 일본어 문자 검사 통과.
- 변경 문서의 상대 링크 대상 파일/디렉터리 존재 검사 통과. 외부 URL과 페이지 내 앵커 검사는 포함하지 않았다.
- `git diff --check` 종료 코드 0. 변경 diff를 검토해 초기 3메뉴·AM 최대 4글·후속 범위·현행 구현 구분을 확인했다.
- 코드·migration·OpenAPI·HTML/PNG 변경 없음. 제품 기능 시험·브라우저 화면 시험·외부 API 호출·게시·커밋은 수행하지 않았다.
