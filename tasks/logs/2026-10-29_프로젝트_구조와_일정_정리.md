## 변경

- 일정·문서 구조·코드 구조를 3개 하위 작업으로 병렬 검토하고 부모 작업에서 이동·전역 참조 갱신을 통합했다.
- 5~6주차30시간은 중간 목표로 수정했다. 뉴스 선행6h+핵심30h+확장20h+최종검증/발표4h=기준60h, 예상60~96h. 추가30h와11/24 기능 동결은 가정이며 사용자가 확정한 시간으로 표시하지 않는다.
- 검증 문서17개를 market/news/admin/ai/integration으로 재분류하고 관측 JSON8개를 assets 주제 폴더로 이동했다. 관찰 기업 문서는 archive로, 2주 개발 범위는 개발_범위와_단계로 이름을 바꿨다. 총27개 이동, 원본 삭제 없음.
- 뉴스·월 비용의 과거 조사/추천은 archive의 별도 이력으로 분리했다. 현재 뉴스 문서에는 Benzinga 제외와 대안 미확정을 남겼다.
- 폴더별 목차와 프로젝트 구조 지도를 작성하고 tasks 진입 목차를 현재 작업 중심으로 줄였다. 코드·설정·기존 Streamlit 배포 진입 경로와 로컬 데이터·비밀·생성물은 보존했다.
- SEC 실험의 기본 산출물 경로를 새 assets 위치로 갱신했다. 중지된 뉴스/지수 자동화2개의 참조 경로만 변경했고 PAUSED 유지 응답을 확인했다.

## 검증

- Markdown132파일의 UTF-8/BOM, 상대 링크1060개와 이동27개의 대상/원위치 존재를 검사해 오류0건을 확인했다. 이후 결과·목차 링크 추가도 최종 재검사했다.
- `uv run pytest`: 390 passed, 29 skipped, 1 warning. 격리 PostgreSQL 미설정 시험을 건너뛰었고 기존 Authlib deprecation 경고1개가 있다. 실제 외부 게시/클라우드 인수 시험이 아니다.
- Ruff check 통과. format은 길어진 SEC 기본 산출물 경로1건을 줄바꿈 수정한 뒤208파일 통과했다. 중간 uv 기본 캐시 쓰기 오류는 작업공간 `.cache/uv`를 지정해 해소했다.
- `uv --cache-dir .cache/uv run xfolio status` 통과. 최종 `git diff --check` 확인. 제품 import·frontend·DB schema는 변경하지 않아 브라우저/DB 인수를 반복하지 않았다.
- 자동화2건의 새 경로와 PAUSED 상태 유지 응답을 확인했다. 재활성화·외부 API 관측을 실행하지 않았다.

뉴스 제공처·공개 이용 조건 결정, 추가 가용 시간 확인, WBS 순서의 구현. 이번 정리는 제품 기능 구현·외부 API 시험·관측 재개·공개 게시가 아니다.
