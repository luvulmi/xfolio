# 2026-10-25 OpenAI 가상 분석·비용 비교

- [계획](../plans/archive/OpenAI_분석과_비용_비교.md) · [검증 결과와 원본 링크](../verification/ai/OpenAI_분석과_제공처_비교.md) · [월 비용](../../docs/research/월_비용.md)

공통 가상 분석 함수와 `xfolio ai-preview`를 연결했다. 단일 가상 뉴스로 Luna 실제 호출 후 두 지수 글+뉴스 글의 `dry_run`을 확인했다. 같은 직접 작성한 가상6건을 Mini·Luna에 각각 전송해 모두 4선정/2보류 및 6/6 기계 검사 통과를 기록했다. 실측 모델 비교비는 Mini $0.0051210, Luna $0.0005432다.

BLS 2026-09 CPI 보관 원문은 직접 HTTP 200으로 조회했고, `bls.gov` 제한 Web search 1회도 3.7%·0.6%와 원문 인용을 반환했다. 검색은 도구+토큰 약 $0.011048125로 추정했다. 월 X 최대 게시비를 유지하면 Luna로 바꾸는 조건부 부분 견적은 27,176원→25,579원이며 검색을 하루2회 추가하면 표본 길이 가정상 약26,461원이다. 기업 뉴스를 억지로 최대2건 채우지 않고 평균1건만 게시하면 Mini 기준 약18,990원이다. 모델·검색의 실운영 채택은 미확정이다.

추가 실험 12모델 호출+가상 연결1호출+Web search1응답의 공시 단가 기반 소비 추정은 $0.016819225다. BLS 직접 조회는 OpenAI 사용량0이며 뉴스·X 별도 청구액은 이 추정에 넣지 않았다. 키·실기사 본문은 결과 파일에 기록하지 않았다. 코드는 커밋하지 않았다.

검증: 전체 `uv run --offline pytest` **223 통과**. 캐시 단가 처리의 예외 유형을 정리한 뒤 관련 7건을 재실행해 통과했다. `uv run --offline ruff check .`, `uv run --offline ruff format --check .`, `uv run --offline xfolio status`, `uv run --offline xfolio ai-preview --model gpt-6-luna`도 통과했다. 변경 문서 링크·UTF-8 BOM·등록 키 문자열의 결과 파일 유출 검사에서 문제를 찾지 못했다. 실기사 AI 입력 권한·사람 문안 평가·BLS 파서/정정 감시는 후속이다.
