# 개인 Telegram 알림의 API 권한·정책 조사

- 수행일: 2026-11-02, Asia/Seoul
- 상태: 공개 근거 조사·후속 선택·기획서 반영 완료. KIS 외부 전달/보관 인수는 대기, 일반 언론사 요약은 초기 제외로 결정했다.
- 대상: KIS 국내 ETF 시세·Exa 기사·OpenAI 요약·BLS CPI·Telegram 본인1:1 전달. 이메일 대안도 비교했다.

## 확인 결과

- Telegram은 사용자 선행 대화 후 봇 메시지를 지원한다. 본인 동의 자동 알림 기능에 별도 방송 제휴를 요구하는 근거는 찾지 못했다. 개인정보/스팸/제3자 권리·호출 한도 준수는 필요하다.
- KIS 공식 고객 약관을 직접 확보했다. 제5조③은 자체 프로그램 등 개인 업무 시세 사용을 허용하고 제3자 제공을 금지한다. 본인 알림에는 허용 근거가 있으나 Telegram/AWS 경유를 명시한 별도 허가는 확인하지 못했다. 일반 법인 제휴 요건을 개인에게 그대로 적용하지 않았다.
- Exa의 공식 문서상 LLM context/본문/요약 기능과 약관상 허용 예외를 함께 확인했다. API/LLM 활용 전면 금지라고 해석하지 않았고, 원매체의 본문 AI 입력·요약 전달·보관까지 포함하는 포괄 허가도 확인하지 못했다.
- BLS 자체 텍스트/수치는 public domain 안내에 따라 이용 근거가 있다. 제3자 사진/삽화/로고/외부 기사는 구별한다.
- OpenAI Services Agreement와 API 데이터 제어 문서를 확인했다. 출력 권리·기본 학습 미사용과 원문 입력 권한은 별개다. 기본 학습 미사용은 무보존을 뜻하지 않는다.
- 저작권법 제30조와 대법원 2004도5350을 확인했다. 사적 이용/사실과 표현 구분을 모든 기사·외부 처리·계약의 포괄 면제로 적용하지 않았다.
- 이메일도 원자료 이용권과 서버 처리/저장 문제가 남으므로 정책 회피 수단으로 추천하지 않았다.

## 검증과 한계

문서 변경만 수행했다. 관련12개 Markdown의 상대 링크138개·엄격 UTF-8/BOM·원문 SHA256·`git diff --check`를 검사해 통과했다. 제품 테스트는 재실행하지 않았다. 사용자의 계정별 추가 계약·신청 시 최신 약관·원매체별 기사 목록은 아직 확인하지 못했다. 공개 문서 조사 완료와 운영 이용 허가 취득을 구분한다.

- Exa Search/Contents의 검색·기관 경로 필터·AI context/summary 기능과 원자료 권리를 분리했다. BLS·BEA·Board 공식 재사용 정책을 확인했다.
- KIS 마스터의 이름/코드와 기본조회 `CTPF1002R` 입력 계약을 확인했다. 기본3종 공개 표본을 다시 읽었으며 인증 API는 호출하지 않았다. 상품유형300만으로 해외 ETF 판정은 불가하다고 명시했다.
- Lightsail + Tailscale Serve와 EC2/SSM 대안을 공식 문서로 비교했다. 사설 관리자 접근과 AWS/Neon/Telegram 처리 권한을 구분했다.
- 사용자가 **Exa + 공식 발표 요약**, **Lightsail + Tailscale PC/휴대폰 접근**을 선택했다. [결정 기록](../discussions/2026-11-02_공식_발표와_비공개_관리자.md)에 보존했다.
