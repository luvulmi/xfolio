## 변경

기존 7종 자료를 6개 기준 문서에서 보완했다. 별도 요구사항/IA/추적표를 만들지 않고 요구사항 FR 10개·NFR 5개와 수용 조건·요구/구현 상태를 정의하고 기존 WBS·화면·검증 근거를 연결했다. WBS 작업 ID·공수·시간 가정은 유지했다.

API 출처와 수집 요약에 핵심 Exa/BLS를 반영하고, Exa 설정 요청 완료와 공식기관 페이지/기업 완주를 구분했다. official 프로필을 Exa 공통 확정값처럼 사용하던 표현을 정리하고 결정 담당·완료 조건을 입력 책임 문서에 모았다. 4글 전환은 reserved_count 0~4·post position 1~4 두 제약 변경과 running 수집 행의 별도 변경을 구분했다.

시스템의 현행 상태·목표 배포 경계와 수집/승인/전송 3개 시퀀스를 정리했다. IA 계층·업무 이동·현행 hash 경로와 목표 경로를 구분하고 읽는 순서를 목차에 추가했다. 기존 사용자 변경을 보존했으며 코드·migration·OpenAPI·이전 와이어프레임·외부 서비스 설정은 변경하지 않았다.

## 검증

- 현행 API 8경로·OpenAPI snapshot 일치·8테이블 DDL 검사: 기존 .venv Python으로 pytest 3개 통과. Authlib 폐기 예정 경고 1건.
- 14개 문서의 상대 링크/앵커 212개: 누락 0건. UTF-8 엄격 디코딩·BOM 없음·대체문자 없음 확인.
- FR-01~10/NFR-01~05 중복 없음·WBS 연결·기존 핵심 56h+여유 4h와 A01 두 제약 변경을 확인했다.
- Mermaid 10.9.3 + headless Edge: 물리 ERD·논리 참조·상태도·IA·시스템·배포·시퀀스 3개, 총 9개 모두 렌더링 성공. PNG를 직접 확인했다. 제품 브라우저/API 인수와 별개다.
- `git diff --check`: 통과. 코드·migration·OpenAPI·시연 자산은 diff 없음.
- 렌더러 다운로드와 headless Edge는 sandbox DNS/임시 프로필 제한으로 첫 시도가 실패했으며, 허용된 별도 실행으로 재검증해 통과했다. 의존성 manifest는 변경하지 않았다. 문서 작성/검증용 임시 스크립트는 정리했다.
