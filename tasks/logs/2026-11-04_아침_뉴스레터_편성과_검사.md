## 실제 변경

T02 국내 종가·관심종목과 T03 선정 뉴스 전체0~3건을 `MorningInputs` → `build_morning` → `MorningEdition`으로 연결했다. KRW 가격·원종가 등락률·기준/비교 거래일·실제 가격시각 미제공·예정 마감/조회시각·출처를 표시한다. 일반 뉴스는 원제/매체/발행시각/링크, 공식 발표는 근거와 대조한 한국어 AI 요약을 붙인다. 소수 가격은 보존하고 최대10종목이어도 뉴스는 전체3건이다.

정상 뉴스0건·뉴스 일부/전체 실패·가격 일부/전체 실패·등락률 미확인을 구별한다. 정상 자료가 남으면 부분 편성, 모두 없으면 실패다. 작업 중 공유 문서에 갱신된11/4 사용자 정책을 확인해 한국 휴장 평일/주말을 정상 건너뜀으로 처리했고 개장 미확인도 전체 발송을 막도록 반영했다. 기존 사용자 문서 수정은 보존했다.

`check_send`는08:00 이상08:10 미만·설정/종목 revision·중지/비활성·개장 여부·단일 private 수신자·월 예산·보존 만료·전송 상태를 검사한다. `NewsletterStore.check`는 현재 DB 관심목록·개장일·가격 정정·뉴스confirmed/unknown·원본 만료/삭제를 추가로 검사한다. 이 함수는 점유/송신을 하지 않으며 실제 설정/원장 조회와 outbox 원자성은 T05/T06의 연결 범위다.

신규0005 `newsletter_editions`는 수신자+KST 날짜+morning 유일 키·동시 생성 잠금·불변 trigger·원본 만료 이내90일 저장/삭제를 제공한다. 기존 AM 승인/0001~0004를 변경하지 않고 원문 근거를 영속 본문에 복제하지 않는다. 같은 입력은 최초 편성을 반환하고 다른 입력 덮어쓰기는 거절한다. 준비만으로 성공 발송/기발송 뉴스 이력을 만들지 않는다.

`uv run xfolio newsletter-preview`와 `--scenario zero/partial/failed`, `--inputs-file`, `--context-file`, `--prepared-at`, `--save`, `--json`을 추가했다. 기본은 합성 무통신 미리보기다. 파일 입력은 실제 현재 시각이 기본이며 과거 재생은 명시한 시각으로 검사한다. DB 저장은 명시 API DB와 기존 T02/T03 원본이 필요하다. 어떤 옵션도 Telegram 송신을 하지 않는다. [합성 표본5종](../verification/assets/integration/t04_morning_2026-11-04/README.md)을 보존했다.
