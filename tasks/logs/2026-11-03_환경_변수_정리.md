# 현재 환경 변수 정리와 KIS 설정 준비

- 날짜: 2026-11-03, Asia/Seoul.
- 요청: 사용하지 않는 환경 변수 삭제와 KIS 변수 추가.
- 범위: 루트 `.env`·`.env.example`·README와 작업 기록. 제품 KIS 어댑터/인증·주문·발송 기능은 구현/호출하지 않는다.

## 변경

- `.env.example`에서 X4개·`EXA_API_KEY`·`MARKETAUX_API_TOKEN`·`MARKETNEWSAPI_KEY`·`OPENAI_MODEL`·`XFOLIO_DATABASE_URL` 총9개를 제거했다. 이 중 로컬 `.env`에 존재하던8개도 제거했다. Exa 항목은 로컬에 없었다.
- `KIS_APP_KEY`·`KIS_APP_SECRET`은 빈 항목으로, `KIS_BASE_URL`은 공식 실전 REST 주소 `https://openapi.koreainvestment.com:9443`으로 추가했다. [공식 설정](https://github.com/koreainvestment/open-trading-api/blob/main/kis_devlp.yaml) · [현재가 예제](https://github.com/koreainvestment/open-trading-api/blob/main/legacy/rest/current_price_samle.py).
- 기존 OpenAI·Finnhub·Telegram·관리자/Google·API/DDL/격리 시험의13개 변수 값을 메모리 비교로 보존했다. 결과16개 변수 이름이 예시와 일치한다. 실제 키/토큰/DB 접속 문자열·계정 값은 기록하지 않았다.
- KIS 현재가 조회 준비에 계좌번호·HTS ID·고정 access token은 추가하지 않았다. 해당 변수는 후속 시세 어댑터의 설정 계약이며 아직 읽는 제품 코드는 없다. Open API 신청·키 입력·인증 시세/이용 조건 인수는 후속이다.
- [README](../../README.md#현재-환경-변수와-kis-준비)에 새 설정과 기존 변수의 제외 이유를 기록하고 루트의 X 키 입력/검사 안내는 이전 조사 문서 링크로 교체했다. 기존 실험/Streamlit 코드는 보존하므로 별도 재실행 시 이전 변수의 수동 지정이 필요하다. API DB를 기존 preview DB로 복사하지 않는다.

## 검증

- 로컬 dotenv를 값 비출력으로 파싱했고 정리 전후 유지 대상13개 값의 동일성·결과16개 이름/예시 일치·삭제 대상 부재·KIS2개 빈 값/공식 주소를 확인했다. `.env`는 Git ignore·무추적 상태다.
- 공유 파일 내 비밀 미포함 검사는 공개 localhost 주소를 잘못 포함한 최초 검사식을 비밀 필드로 좁혀 수정 후 통과했다. 로컬 변수 값은 출력하지 않았다. 임시 정리 스크립트는 실행 후 삭제했다.
- `uv run --no-sync ruff check .`·`uv run --no-sync ruff format --check .` 통과. `uv run --no-sync --env-file .env xfolio status`도 종료 코드0으로 실행돼 정리된 `.env`의 로딩/CLI 실행을 확인했다. status 내용은 기존 구현 이력이며 KIS 인증 성공을 뜻하지 않는다.
- 관련 Markdown6개·상대 링크149개·UTF-8/BOM·코드 블록·비밀 미포함과 `git diff --check`를 검증했다. 설정/문서 정리이며 새 제품 기능/테스트를 추가하지 않아 전체 pytest를 반복하지 않았다. 직전 코드 회귀 결과는 [Finnhub 검증](2026-11-03_Finnhub_선정_검증.md)이다.
