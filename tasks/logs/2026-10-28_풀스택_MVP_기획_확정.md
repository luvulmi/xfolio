- 수행일: 2026-10-28, Asia/Seoul
- 요청: React/TypeScript·FastAPI·PostgreSQL·Docker/AWS로 기획 변경, 감시한 중요 사건을 18시에 최대 2건 발행, 중요 오류/한도를 Telegram으로 알리고 2주 개발 범위로 정리
- 결과 범위: **문서 재구성**. 새 의존성 설치·앱 구현·서비스 생성·배포·키 조회·Telegram/X 발송·커밋/푸시는 하지 않았다.

## 비용·확인 근거

[AWS VM 번들](https://docs.aws.amazon.com/lightsail/latest/userguide/amazon-lightsail-bundles.html), [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage)·[429 대기](https://core.telegram.org/bots/api#responseparameters), [APScheduler](https://apscheduler.readthedocs.io/en/3.x/faq.html), X·Luna 단가를 공식 문서로 확인했다. 키나 실제 공급자 API는 호출하지 않았다.

기존 최대 X+Luna $18.656 + AWS 1GB $7에 계획 환산 1,815원을 적용하면 소계 46,566원이다. 2GB $12면 55,641원으로 상한을 넘는다. [비용 문서](../../docs/research/월_비용.md)에서 도메인·백업 등 미산정을 명시하고 전체 5만 원 충족 판정은 보류했다.

## 검증과 남은 조건

- 이번 문서 범위 30개에서 로컬 링크 342개·앵커 9개, UTF-8/BOM·공백/개행·코드 펜스·비밀 값 패턴과 `git diff --check`를 확인했다. 변경 문서로 들어오는 기존 앵커 참조 10개도 통과했다.
- 계약의 API 8개·저장 단위 8개, 1주차 2+3+3+3+3+1=15h·2주차 3+3+2+3+3+1=15h, 비용 46,566/55,641/46,885원 산식을 검산했다. 3주차 발표 파일 2개가 HEAD와 바이트 단위로 같음을 확인했다. Mermaid는 코드 펜스를 검사했으며 별도 렌더러의 시각 검증은 수행하지 않았다.
- 준비가 필요한 X 인증·Telegram bot/chat·AWS/도메인, 뉴스/지수 공개/AI 권한과 메모리 적합성을 실제 완료로 표시하지 않았다.
- 코드 미변경이므로 제품 테스트 통과나 새 기능 구현 완료를 주장하지 않는다.
