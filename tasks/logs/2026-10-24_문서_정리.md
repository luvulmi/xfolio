# 문서 구조와 한글 파일명 정리

- 작업일: 2026-10-24, Asia/Seoul
- 사용자 최종 확정: docs는 기준·참고 자료, tasks는 계획·검증·수행 결과로 구분. 문서 파일명은 한글, 폴더명은 영어 snake_case 사용

## 변경

- docs 루트는 프로젝트 개요·요구사항·기술 구성·운영 정책·스터디 일정으로 정리했다.
- 주차별 기술 조사를 주제별 research/로 통합하고 지수·비용의 이전 비교는 archive/으로 분리했다.
- plans/·verification/·logs/·presentations/·discussions/를 분리하고 지수 구현 계약은 검증 문서로 옮겼다.
- 사용자가 날짜를 변경한 3주차 발표 원문을 기준으로 이동했다. 발표 내용과 그림, 기존 논의·검증 근거를 보존했다.
- 실험 Python 파일은 scripts/experiments/로 이동했다. 앱 코드·실험 코드 내용은 변경하지 않았다.
- AGENTS.md와 brain·weekly의 저장 위치·파일명·목차 규칙을 갱신했다. 도구 인식 파일명·코드 파일명은 유지했다.
- OpenAI·SQLite의 상세 실험 결과를 조사 문서에서 검증 문서로 모으고 조사에는 연결 링크를 남겼다.
- yfinance 오전 시험의 계획·증거 저장 경로를 새 구조로 갱신했다. 자동화 파일을 다시 읽어 예약 시각·상태·대상 대화 등 다른 설정이 유지됐고 프롬프트는 경로만 바뀌었음을 확인했다.

## 검증

- Markdown 49개 파일의 UTF-8·BOM 없음, 내부 링크317개·앵커의 존재를 확인했다. 이전 경로는 논의의 기존 세션 ID·과거 파일명 변경/삭제 이력에만 남겼다.
- 이동한 실험 코드2개·SVG2개의 내용을 보존했고, 사용자가 편집한 3주차 발표 원문은 링크 변경 외에 수정하지 않았다. 합친 설계·지수·비용·게시 모드 이력의 원문 본문 보존도 확인했다.
- brain·weekly는 skill-creator의 quick_validate.py를 각각 통과했다. 검증용 PyYAML은 `uv run --with`로 사용했으며 앱 의존성에는 추가하지 않았다.
- `uv run pytest`: **40 passed**. 이동한 OpenAI 모의 요청 실험과 SQLite 중복 키·승인 버전·롤백·백업 복원 실험도 통과했다. SQLite는 샌드박스 임시 폴더 접근 실패 후 허용된 권한 재실행으로 확인했다.
- `uv run ruff check .`: 통과. `uv run ruff format --check .`: 61개 파일 통과. `git diff --check`: 통과. `uv run xfolio status`: 지수 CLI 구현 상태 정상 출력.
- 일회성 이동 스크립트·검증 스크립트·백업 파일은 검증 후 제거했다.

실제 오전 관측은 여전히 **0/5**다. 다음 예약은 2026-10-27 07:50 KST이며 정리 작업으로 시험 성공을 추가하지 않았다. 실제 외부 게시·커밋·푸시는 수행하지 않았다.

## 폴더명을 영어로 변경

사용자 후속 요청에 따라 한글 파일명은 그대로 두고 폴더명만 변경했다.

- docs: `research/`, `archive/`
- tasks: `plans/`, `verification/`, `logs/`, `presentations/`, `discussions/`
- 그림·원본 관측 자료: 각 용도의 `assets/`

파일39개의 위치를 변경했고 파일명과 경로 외 내용은 보존했다. AGENTS.md·brain·weekly의 경로와 명명 규칙, 문서 목차·상대 링크, yfinance 예약 시험의 문서·근거 저장 경로를 함께 갱신했다. 예약 시각·상태·판정 조건은 유지했다. Markdown49개·내부 링크317개·앵커와 영어 폴더명을 검사했다. 앱 코드·의존성은 이번 폴더명 변경에서 수정하지 않았다.
