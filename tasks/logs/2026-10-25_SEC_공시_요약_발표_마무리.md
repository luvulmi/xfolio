## 수행 결과

- NVIDIA·Apple·Microsoft의 알려진 과거 실적 발표를 SEC `8-K Item 2.02`·`EX-99.1`에서 각각 확인했다. MarketNewsAPI의 앞선 제한 조회 1/3과 달리 이 세 사건은 SEC에서 3/3 확인됐다. 두 수치는 전체 발견율 비교가 아니다.
- SEC Submissions API·공개 공시 재이용 안내와 자동 요청의 declared User-Agent·속도 제한을 확인했다. 연락처 설정이 없어 실제 3사 자동 폴링은 실행하지 않았다. Apple·Microsoft 회사 페이지의 자동 수집·콘텐츠 재이용 제한을 확인해 회사 IR 일괄 크롤링 제안을 철회했다.
- 공시에서 직접 대조한 짧은 사실 카드 3건으로 OpenAI `gpt-5.4-mini` 한국어 비게시 초안을 생성했다. 3/3 기계 검사 통과, 실제 사용량 720 입력·276 출력 토큰, 계획 단가 기준 합계 $0.001782(약 3.23원)이다. 회사 원문 전문·일반 기사 본문은 모델에 보내지 않았고 X에도 게시하지 않았다. [결과 JSON](../verification/assets/sec_fact_card_preview_20261025.json)
- 처음 제공처를 BLS CPI + 세 회사 SEC 실적 공시로 좁히는 **발표용 변경 제안**으로 정리했다. SEC 자동 발견·수정/중복·관리자 승인·Cloud Run 예약·X 게시 연동을 완료했다고 표시하지 않았다.
- X 공개 계획 단가와 클라우드 공식 가격으로 최대 게시 월 27,176원, 모든 job 2분 약 32,735원·3분 약 40,035원의 조건부 견적을 유지했다. GCP/X 계정 연결 및 실제 Cloud Run/Streamlit 배포가 없어 실행 시간과 청구액은 미측정이다. 45,000원은 임시 변경 제안이며 확정 상한 30,000원을 조용히 변경하지 않았다.
- 발표 자료·별도 대본·예상 질문과 기술·조사·비용 기준 문서를 갱신했다.
