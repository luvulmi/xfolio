## 변경과 인수

기존 Exa 검색 3회·15결과와 캐시 Contents 1회·2 URL의 메타데이터, 입력 책임·API/ERD·기존 모델을 대조했다. 응답 비용 합계 $0.023을 인수했으며 무료 잔액·실제 청구·공개 요약/AI/보관 허가 확인과 구분했다. 기사 전문은 기존 원본에 없으므로 새로 보관하거나 복원하지 않았다. 공개 권리의 pending_review 상태를 유지한다.

[news_input.py](../../src/xfolio/news/input.py)에 `news_common_input_v1`/`news_common_collection_v1`을 추가했다.

- 제공처 exa/bls, 원매체·원문 URL·기사 유형을 분리하고 인증 URL을 거절한다.
- 발행 시각의 원래 문자열/시간대/정밀도/확인 여부, 최초 조회/확보와 마지막 재확인을 보존한다. 날짜만 있는 값을 자정으로 만들지 않고 미확인 자정은 신뢰 시각으로 승격하지 않는다.
- 본문 길이·요청 상한·절단·제목 의존·충분성·근거 구간·판정 기록을 분리한다. 본문 길이나 요청 성공만으로 충분 판정하지 않는다. 본문의 공백을 그대로 유지한 SHA256과 개정·사건 참조를 검사한다.
- synthetic/data_origin, 용도별 권리·검토/만료 메타데이터를 검증한다. 입력 검사 통과가 의미 승인이나 게시 허가를 부여하지 않는다.
- 필수 scope별 요청 결과와 발견 입력 참조를 교차 검증한다. 설정 요청 완주에 따른 정상 발견 0건, 기존 버전만 발견, partial/failed를 구별하고 부분 실패의 발견 근거를 보존한다. 모르는 비용은 0으로 바꾸지 않는다.

[test_news_input.py](../../tests/news/test_news_input.py)에 합성 본문과 기존 Exa 메타데이터를 쓰는 63개 시험을 추가했다. 소켓 연결을 차단하며 AP 297자·상한 20,000자 4건·동일 URL 2,273/5,706자·미확인 발행 정밀도·응답 비용을 대조한다. 실자료에 없는 기사별 최초 조회/확보 시각을 만들어내지 않았다. 기준 문서·목차·README에서 새 수집 모델과 미구현 통합 경계를 구별했다.

## 실제 검증

| 명령/검사 | 결과 |
| --- | --- |
| `uv run pytest tests/news/test_news_input.py -q` | 63 passed |
| `uv run pytest -q` | 456 passed, 29 skipped, 1 warning (54.86초) |
| `uv run ruff check .` | 통과 |
| `uv run ruff format --check .` | 237 files already formatted |
| `uv run xfolio status` | 종료 코드 0 |
| 변경 Markdown 상대 링크·UTF-8·BOM, `git diff --check` | 통과 |

skip 29건은 `XFOLIO_TEST_DATABASE_URL`이 필요한 PostgreSQL 통합 시험으로 이번에는 실행하지 않았다. 기존 CPI/PM의 실행 가능한 회귀는 통과했으며 DB 시험까지 인수했다고 표시하지 않는다. 기존 Authlib `jose` deprecation 경고 1건은 남아 있다.

uv 기본 캐시 쓰기 제한은 작업공간 `.cache/uv`로 해결했고 pytest temp는 `.venv/pytest_tmp`를 사용했다. 첫 전체 실행과 단일 API 진단은 sandbox의 `_fallback_socketpair` accept에서 대기해 종료했다. 이전 동일 진단 기록을 확인하고 도구 승인을 받은 제한 밖 실행으로 전체 회귀를 완료했다. 제품 코드의 우회나 의존성 변경은 하지 않았다.
